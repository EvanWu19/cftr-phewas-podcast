Ep1 — Track A: Benchmarking splice variant prediction algorithms using massively parallel splicing assays

Eight widely used splice-effect predictors — HAL, S-Cap, MMSplice, SQUIRLS, SPANR, SpliceAI, Pangolin, and ConSpliceML — get graded against real experimental ground truth instead of against each other or against skewed clinical variant sets. Smith and colleagues assembled 3,912 SNVs across 33 exons in six genes (POU1F1, MST1R, FAS, WT1, BRCA1, MLH1), combining massively parallel splicing assay (MPSA) and saturation genome editing (SGE) data with a manually curated clinical set. SpliceAI and Pangolin came out as the most consistent performers, but agreement between tools was only moderate (median pairwise r = 0.58), performance was much weaker for exonic than intronic variants, and — the sharpest finding — a tool's classification for 10–14% of variants at two genes flipped depending on which isoforms were included in the gene annotation file it was run with. CFTR was not part of this benchmark, so the buildable artifact for Runyu is an annotation-sensitivity checker: rerun SpliceAI on a CFTR VUS list under two annotation sets (default MANE vs. an extended GTF built from CFTR's GTEx exon-junction usage) and flag any variant whose call changes.

Plain-English glossary

  • Splice-disruptive variant (SDV) — a genetic change that breaks correct exon/intron recognition, causing exon skipping, intron retention, or activation of a cryptic (normally unused) splice site.（中文：破坏正确外显子/内含子识别的变异，导致外显子跳过、内含子保留或隐蔽剪接位点被激活。）
  • Essential/canonical splice site — the near-invariant GT/AG dinucleotides at intron boundaries that the splicing machinery recognizes first.（中文：内含子边界处几乎恒定的GT/AG二核苷酸，是剪接机器最先识别的位点。）
  • Exonic splicing silencer/enhancer (ESS/ESE) — short sequence motifs inside an exon, away from the splice site itself, that respectively weaken or strengthen recognition of a nearby splice site.（中文：外显子内部、不在剪接位点本身的短序列基序，分别削弱或增强附近剪接位点的识别。）
  • MPSA (massively parallel splicing assay) — an experiment that synthesizes thousands of variants of one exon into plasmid "minigenes," transfects them into cells, and reads out spliced outcomes by RNA sequencing.（中文：将某外显子的成千上万个变异版本合成到质粒微型基因中并导入细胞，通过RNA测序读出剪接结果的实验方法。）
  • Saturation genome editing (SGE) — like an MPSA, but CRISPR/Cas9 edits the endogenous genomic locus directly rather than a plasmid, so the readout reflects native chromosomal context.（中文：与MPSA类似，但用CRISPR/Cas9直接编辑内源基因组位点而非质粒，结果更接近天然染色体环境。）
  • PSI (percent spliced-in) — the fraction of transcripts from a locus that correctly include a given exon.（中文：某位点转录本中正确包含特定外显子的比例。）
  • Gene model annotation / masking — the reference file (which transcripts/isoforms exist) a splice predictor is run against; "masking" is SpliceAI/Pangolin's default behavior of suppressing scores that would strengthen an annotated site or weaken an unannotated one.（中文：剪接预测器运行所依据的参考文件（存在哪些转录本/异构体）；"掩蔽"是SpliceAI/Pangolin的默认行为，即抑制会增强已注释位点或削弱未注释位点的得分。）
  • Isoform — one of potentially several distinct mature mRNA/protein products that a gene can produce via alternative splicing.（中文：一个基因通过可变剪接可能产生的多种不同成熟mRNA/蛋白质产物之一。）
  • Transcriptome-normalized sensitivity — a tool's sensitivity for true SDVs measured at the score threshold where it calls a fixed fraction (e.g. 10%) of a random genomic background set as disruptive, so tools with different score scales can be compared fairly.（中文：在某评分阈值下——该阈值使工具将随机背景集中固定比例（如10%）标记为异常——衡量工具对真实SDV的敏感度，从而公平比较评分范围不同的工具。）

Full citation

Smith et al. (2023). Benchmarking splice variant prediction algorithms using massively parallel splicing assays. Genome Biology. PMID: 38129864 · PMCID: PMC10734170

Methods / tools to lift

  • SpliceAI / Pangolin — deep-learning splice-effect predictors; best overall concordance with MPSA ground truth in this benchmark.
  • MMSplice, SQUIRLS, HAL, S-Cap, SPANR, ConSpliceML — the other seven benchmarked predictors, each with different intended prediction tasks (acceptor/donor probability vs. exon-inclusion change).
  • Transcriptome-normalized sensitivity — the normalization approach used to compare tools fairly across different score scales via a shared genome-wide call rate.
  • GTEx junction-usage estimation — the method used to flag genes (~18% of protein-coding genes genome-wide) with expressed alternate splice sites missing from default annotations.

Where it lands + buildable artifact

Serves the Karen Raraigh / variant interpretation track. MVP: a CFTR annotation-sensitivity checker — pull CFTR's GTEx exon-junction usage, build an extended GTF including any alternate junctions above a usage threshold, rerun SpliceAI on a CFTR VUS list under default MANE vs. the extended annotation, and output a short list of variants whose call or masking status flips. Difficulty: S–M.

What to verify first

  • Whether CFTR has documented alternate splice junctions in GTEx at meaningful usage levels — a lookup, not an assumption.
  • Whether MPSA/SGE assay cell lines (largely engineered or cancer lines) generalize to airway epithelium, the tissue relevant to CFTR splicing.
  • Whether any existing splice-scoring step in variant classification workflows documents its masking setting and annotation source.
  • That a correct SDV call is not the same as a pathogenicity call — dosage sensitivity and qualitative (e.g. dominant-negative) effects vary by gene and aren't captured by a single genome-wide threshold.

ALEX Today we're reading "Benchmarking splice variant prediction algorithms using massively parallel splicing assays," by Smith and colleagues, published in Genome Biology in 2023. 今天我们读的是Smith等人2023年发表在《Genome Biology》期刊上的论文《用大规模平行剪接检测法为剪接变异预测算法做基准测试》。This is a Track A pick — variant interpretation and harmonization, the track that feeds directly into the Karen Raraigh collaboration. 这是Track A的选题——变异解读与协调统一，这条线直接服务于与Karen Raraigh的合作项目。The short version: eight popular splice-effect predictors, including SpliceAI, get graded against real experimental data instead of just against each other. 简单说：论文用真实实验数据，而不是让工具互相比较，来给八款常用的剪接效应预测器打分，其中就包括SpliceAI。

JORDAN Before we get into it, can you set up a couple of terms for me? 在深入之前，能先给我讲讲几个术语吗？First — what's a splice-disruptive variant, an SDV? 第一，什么是剪接干扰变异（splice-disruptive variant，SDV）？

ALEX A gene's coding sequence is stored in exons, separated by introns that get spliced out before the mRNA is translated. 基因的编码序列存储在外显子（exon）里，外显子之间由内含子（intron）隔开，内含子会在mRNA翻译之前被剪接掉。The splicing machinery recognizes short sequence motifs — mainly the "GT" and "AG" dinucleotides right at the intron boundaries — called the essential splice sites. 剪接机器识别的是内含子边界处的一小段序列基序——主要是内含子两端紧邻的"GT"和"AG"两个碱基——被称为必需剪接位点（essential splice site）。A splice-disruptive variant, or SDV, is any change that breaks this recognition and causes an exon to be skipped, an intron to be retained, or a cryptic — meaning normally unused — splice site to be activated instead. 剪接干扰变异（SDV）指的是任何破坏这种识别、导致外显子被跳过、内含子被保留、或激活了原本不使用的隐蔽剪接位点（cryptic splice site）的变异。

JORDAN And variants further from those two boundary bases — can they still disrupt splicing? 那些离这两个边界碱基更远的变异呢——它们也能破坏剪接吗？

ALEX Yes, that's a lot of what this paper is about. 是的，这正是这篇论文关注的核心问题之一。Inside the exon or deeper in the intron there can be exonic splicing silencers and enhancers — short motifs that help or hurt the recognition of a nearby splice site without being the splice site itself. 外显子内部或内含子更深处可能存在外显子剪接沉默子和增强子（exonic splicing silencer/enhancer）——它们不是剪接位点本身，却能帮助或削弱附近剪接位点的识别。These are much harder to predict than the canonical GT/AG dinucleotides. 相比典型的GT/AG二核苷酸，这些区域的变异效应要难预测得多。

JORDAN How did they get ground truth for that, if it's not something you can just look up in a clinical database? 如果这不是能在临床数据库里直接查到的东西，他们是怎么获得金标准数据的？

ALEX They used massively parallel splicing assays, MPSAs — experiments where thousands of variants of a single exon are synthesized on a plasmid library, minigenes, and pushed through cells simultaneously, then RNA sequencing reads out which isoform each variant produced. 他们使用了大规模平行剪接检测（massively parallel splicing assay，MPSA）——这是一种实验方法，把某个外显子成千上万种变异版本合成到质粒文库（也就是"minigene"微型基因）中，同时导入细胞，再用RNA测序读出每个变异实际产生了哪种转录本。For one gene, BRCA1, they also used saturation genome editing, SGE — instead of a plasmid, CRISPR/Cas9 edits the endogenous genomic locus directly, so the readout reflects the real chromosomal context. 对于BRCA1这一个基因，他们还用到了饱和基因组编辑（saturation genome editing，SGE）——不是用质粒，而是直接用CRISPR/Cas9编辑内源基因组位点，因此读出的结果更接近真实染色体环境下的效应。The outcome measure in both cases is percent spliced-in, PSI — the fraction of transcripts that include the exon correctly. 两种方法测量的结果指标都是外显子正确剪接入转录本的比例，即PSI（percent spliced-in，剪接入比例）。

JORDAN Okay — so why do we need this at all, if there are already eight tools out there doing this job? 好——那如果外面已经有八款工具在做这件事，为什么还需要这项研究呢？

ALEX Because those eight tools were mostly validated against clinical variant sets, and those sets are badly skewed. 因为这八款工具大多是拿临床变异集来验证的，而这些数据集存在严重的偏倚。The paper found that reported clinical splice variants in MLH1 covered only 1.6% of the possible single-nucleotide changes near its exons, and 59.5% of those reported variants sat within 10 base pairs of a splice site. 论文发现，MLH1基因中已报告的临床剪接变异只覆盖了其外显子附近可能单核苷酸变化的1.6%，而在这些已报告变异中，有59.5%都落在剪接位点10个碱基以内。Training sets used by some of these predictors were even more concentrated there — 94.6% of the SQUIRLS training variants and 88.9% of the S-Cap pathogenic training set were within that same 10 base-pair window. 一些预测器所用的训练集更加集中在这个区域——SQUIRLS训练集中94.6%的变异、S-Cap致病训练集中88.9%的变异，都落在这10个碱基的窗口内。So a tool can look excellent on paper while never really being tested on the harder, more distant cases — deep exonic or deep intronic variants — that clinicians actually struggle to classify. 因此，一款工具在纸面上看起来很出色，实际上却从未真正在临床医生最难分类的那些情况——外显子深处或内含子深处的变异——上得到过检验。MPSAs give near-total coverage of a target region regardless of clinical ascertainment, so this benchmark can finally test the hard cases at scale. 而MPSA能对目标区域实现近乎完全的覆盖，不受临床发现偏差的影响，因此这次基准测试终于可以大规模检验这些困难病例了。For context on the CF side, the equivalent concern is that a splice call for a CFTR VUS trained mostly on canonical-site examples might be far less trustworthy the moment the variant sits mid-exon. 放到CF领域的语境里，类似的担忧是：一个主要基于典型剪接位点样本训练出的splice预测，一旦用在CFTR外显子中段的意义未明变异（VUS）上，其可信度可能会大打折扣。

JORDAN What exactly did they build, and which tools made the cut? 那他们具体构建了什么、又选了哪些工具来测试？

ALEX They assembled 3,616 variants from four MPSA studies covering five genes — POU1F1, MST1R, FAS, WT1, and BRCA1's intronic and synonymous positions from the SGE data — plus a manually curated set of 296 clinical MLH1 variants pulled from 77 publications, giving 3,912 SNVs total across 33 exons in six genes. 他们汇总了来自四项MPSA研究、覆盖五个基因的3616个变异——POU1F1、MST1R、FAS、WT1，以及来自SGE数据的BRCA1内含子和同义位点变异——再加上从77篇文献中人工整理出的296个MLH1临床变异，总共得到六个基因、33个外显子上的3912个单核苷酸变异（SNV）。ALEX pushes back here: it's a strikingly small gene set — six genes — to generalize a benchmark from, and CFTR is not among them, so any transfer to CFTR splice calls is an extrapolation, not a direct validation. 这里ALEX要提出一点质疑：用来做这次基准测试泛化的基因集相当小——只有六个基因——而CFTR并不在其中，因此把这个结论迁移到CFTR的剪接预测上，属于外推而非直接验证。They tested eight predictors: HAL, S-Cap, MMSplice, SQUIRLS, SPANR, SpliceAI, Pangolin, and ConSpliceML — and also built a background set of 500,000 randomly drawn genomic SNVs to estimate each tool's genome-wide call rate. 他们测试了八款预测器：HAL、S-Cap、MMSplice、SQUIRLS、SPANR、SpliceAI、Pangolin和ConSpliceML——同时还构建了一个包含50万个随机抽取基因组SNV的背景集，用来估算每款工具在全基因组范围内的调用率。

JORDAN And how did it go — did SpliceAI live up to the reputation? SpliceAI表现如何——配得上它的名声吗？

ALEX Modestly, with real caveats. 总体不错，但也有明显的局限。Agreement between the eight tools themselves was only moderate — a median pairwise correlation of 0.58, ranging all the way from 0.04 to 0.97 — and agreement between any given tool and the actual MPSA measurements was similarly modest, a median Pearson's r of 0.53. 八款工具彼此之间的一致性只是中等水平——两两相关系数的中位数为0.58，范围从0.04到0.97都有——而任一工具与实际MPSA测量结果之间的一致性也同样中等，皮尔逊相关系数中位数为0.53。SpliceAI and Pangolin, which share a similar architecture, correlated almost perfectly with each other, r equals 0.97, so they're not fully independent evidence of anything. SpliceAI和Pangolin架构相近，两者之间的相关性几乎完美，r值高达0.97，因此二者并不能算作彼此独立的证据。On classification performance, measured as area under the precision-recall curve, prAUC, tools did far better on intronic variants than exonic ones — a median prAUC of 0.773 for introns versus just 0.419 for exons — even though the two regions had a similar overall fraction of disruptive variants. 从分类性能来看，用精确率-召回率曲线下面积（prAUC）衡量，各工具在内含子变异上的表现明显好于外显子变异——内含子的prAUC中位数为0.773，而外显子只有0.419——尽管两个区域中实际存在的干扰性变异比例相近。When they normalized for genome-wide call rate — comparing sensitivity at the score threshold where each tool flags the same 10% of the background set — SpliceAI, ConSpliceML, and Pangolin came out as the consistent leaders, at 87.3%, 85.8%, and 79.9% sensitivity respectively. 当他们按全基因组调用率做归一化处理后——也就是在每款工具都把背景集中相同的10%标记为异常的评分阈值下比较敏感度——SpliceAI、ConSpliceML和Pangolin稳定地领先，敏感度分别为87.3%、85.8%和79.9%。

JORDAN Was there also a threshold problem, separate from which tool you pick? 除了选哪款工具之外，是不是还存在一个阈值选择的问题？

ALEX Yes — and it's arguably the more practical headache. 是的——而且这可以说是更棘手的实际难题。To turn any continuous score into a yes/no call, you need a cutoff, and the authors searched for the cutoff that maximized Youden's J on each dataset separately. 要把任何一个连续型分数转化为"是/否"的判定，都需要一个截断值，作者在每个数据集上分别搜索了能最大化Youden's J统计量的截断点。For most tools, the optimal threshold varied enormously across exons and genes — for HAL and ConSpliceML, optimized thresholds spanned nearly the tool's entire scoring range depending on which exon you looked at. 对大多数工具来说，最优阈值在不同外显子和基因之间差异极大——对HAL和ConSpliceML而言，取决于所看的是哪个外显子，最优阈值几乎可以覆盖该工具评分范围的全部区间。Even for SpliceAI and Pangolin, which were more stable, the optimal thresholds tended to run lower than what the tools' own authors recommend by default. 即便是相对稳定的SpliceAI和Pangolin，它们的最优阈值往往也低于工具作者默认推荐的数值。The POU1F1 exon 2 case is a nice illustration of why a single threshold is hard: the exon has two competing acceptor sites producing an alpha isoform, which is the dominant, functional transactivator making up at least 97% of normal expression, and a beta isoform with dominant-negative activity that causes disease when overexpressed. POU1F1外显子2的例子很好地说明了为什么单一阈值很难适用：这个外显子有两个相互竞争的受体位点，分别产生alpha异构体——占正常表达量至少97%、是主要的功能性转录激活因子——和beta异构体，后者具有显性负效应，一旦过度表达就会致病。A variant that nudges splicing toward beta can be pathogenic even at a low expression level, which is a qualitative, isoform-specific kind of danger that a single genome-wide score threshold isn't built to capture. 一个把剪接推向beta异构体的变异，即便在很低的表达水平下也可能致病，这是一种定性的、异构体特异性的风险，而单一的全基因组评分阈值并不是为了捕捉这种情况而设计的。

JORDAN You mentioned annotation and masking earlier as a catch — what's that about? 你之前提到过注释和掩蔽（masking）是个陷阱——具体是怎么回事？

ALEX SpliceAI and Pangolin both take a gene annotation file as input, and by default they apply a "mask" that suppresses any score that would strengthen an already-annotated splice site or weaken an unannotated one, on the logic that neither should be pathogenic. SpliceAI和Pangolin都需要一份基因注释文件作为输入，默认情况下它们会启用"掩蔽"（mask）功能，抑制那些会增强已注释剪接位点或削弱未注释剪接位点的得分，理论依据是这两种情况都不应致病。That logic breaks when the "unannotated" splice site is actually real but just missing from the reference annotation. 但当那个"未注释"的剪接位点其实是真实存在的、只是恰好没有被收录进参考注释时，这套逻辑就失效了。For two of their test genes, POU1F1 and WT1, both of which have real, biologically important alternative isoforms, changing which isoform was included in the annotation flipped the classification of 10 to 14% of variants — including known pathogenic ones. 在他们测试的两个基因——POU1F1和WT1——中，两者都存在真实且具有重要生物学意义的可变剪接异构体，仅仅改变注释文件中收录了哪个异构体，就使10%到14%的变异分类发生了翻转——其中包括已知的致病变异。Using GTEx RNA-seq junction data, they estimate this could affect roughly 18% of all protein-coding genes genome-wide — genes with an expressed alternate splice site that simply isn't in the default annotation SpliceAI ships with. 利用GTEx的RNA测序剪接位点数据，他们估计这个问题在全基因组范围内可能影响到大约18%的蛋白编码基因——这些基因存在一个有表达的替代剪接位点，只是没有出现在SpliceAI默认自带的注释文件中。

JORDAN So — does this change anything about the CFTR variant work, or the Liz registry project? 那——这对CFTR变异研究工作、或者Liz负责的注册库项目有什么影响吗？

ALEX This one lands squarely on the Karen collaboration — variant interpretation — not the registry side. 这项研究直接对应的是Karen的合作方向——变异解读——而不是注册库那一侧。CFTR itself wasn't in this benchmark, so we can't say its splice calls are unreliable, but the annotation-sensitivity finding is a concrete, checkable risk: if CFTR has expressed alternate isoforms or exons not represented in whatever gene model a splice-effect tool is run with, its SpliceAI or Pangolin scores for nearby VUS could be silently wrong in either direction. JORDAN One more thing before we get to the caveats — even if a tool correctly flags a variant as splice-disruptive, is that the same as knowing it's pathogenic? 在讲注意事项之前还有一件事——即便一款工具正确地把某个变异标记为剪接干扰性变异，这是否就等同于知道它是致病的？
