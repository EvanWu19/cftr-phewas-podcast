Ep4 (Track C — registry QC, 2 of 2): A published, age-banded plausible-range table from a real ECMO registry

Zaaqoq, Fox, and colleagues (2026, ASAIO Journal) give an institutional account of the ELSO Registry's data-quality and integrity program — a voluntary international ECMO registry established in 1989. Rather than proposing a new statistical flagging method, the paper publishes its actual operating rules: a two-tier hard/soft numeric-limit system for mandatory fields (admission weight, height, BMI, blood pressure, blood gas values) split by age band (neonate, pediatric, adult), a mandatory Data Entry Exam before anyone can submit data, quarterly data freezes for reproducible snapshots, and a random-sample center-level compliance audit by an independent contractor. The paper is honest that "accuracy is generally high, it can vary" without reporting a specific measured error rate. The transfer to Track C is vocabulary and an upstream design pattern, not a flagging algorithm: the published age-banded hard/soft limits are a zero-training-data external reference point to benchmark any downstream statistical threshold against. Buildable artifact: an Age-Banded Hard/Soft Range Bench.

  • Data freeze — a quarterly snapshot of the entire registry dataset, archived so any analysis pulling from that snapshot can be exactly reproduced later.（中文：注册库每季度对整个数据集进行的快照，存档以便日后任何基于该快照的分析都能被精确复现。）

Methods / tools to lift

  • Two-tier age-banded hard/soft numeric limits — published exact cutoffs for admission weight, height, and BMI by neonate/pediatric/adult band, plus cross-field logic checks (e.g. diastolic > systolic BP triggers hard rejection).
  • Mandatory Data Entry Exam — a certification gate before any individual is authorized to enter data, aimed at upstream human-error prevention rather than downstream statistical correction.
  • Quarterly data freeze — an archived, versioned snapshot mechanism supporting reproducible analysis.
  • Random-sample, independently-contracted center audit — a compliance-focused (not record-value-accuracy-focused) audit design, useful as a methodological contrast.

Where it lands + buildable artifact

Pipeline stage: (e) vocabulary/framework, primary — the two-tier hard/soft limit design as a point-of-entry prevention layer upstream of, and complementary to, any downstream spline/mixed-model statistical flagging. (a) candidate generation, secondary — the published age-banded numeric thresholds as a zero-training-data external sanity baseline. Buildable artifact: an Age-Banded Hard/Soft Range Bench — given any longitudinal anthropometric dataset tagged with patient age, report what fraction of records would fail the hard limit vs. merely trip the soft limit under ELSO's published thresholds alone.

Error types covered / not covered: Covers gross, static implausible values (unit-conversion-scale errors, data-entry blunders) at the point of entry via explicit numeric bounds. Does not cover carry-forward errors (same value repeated across visits), small digit-transposition errors that still land within bounds, or real-clinical-event-vs-data-entry-error disambiguation, since it is a static range check only, not a longitudinal/trajectory-aware model.

What to verify first

  • Whether ELSO's age-band cutoffs, tuned to a critically ill ECMO population's characteristic body composition and admission patterns, transfer cleanly to a general pediatric or adult population.
  • That "accuracy is generally high, it can vary" is read as a qualitative claim, not a measured figure — no specific error rate is reported in the available material.
  • That a compliance-focused, center-level random audit is understood as distinct from a record-level, value-accuracy random audit, and isn't treated as answering the same evaluation question.
  • Whether cross-field logic checks (e.g. diastolic vs. systolic BP) suggest additional relationship-based checks worth adding beyond single-field range checks for anthropometric data specifically.
