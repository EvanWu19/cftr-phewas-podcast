Ep3 (Track C, #1) — The Data Quality Vocabulary Paper: Weiskopf & Weng 2013

Weiskopf and Weng (2013, JAMIA) is the foundational vocabulary paper for EHR data quality assessment — not a new method, but a literature review that built a shared taxonomy from 95 articles found via a 2012 PubMed search plus ancestor-reference chasing. They identify five dimensions (completeness, correctness, concordance, plausibility, currency) and seven assessment-method categories (gold standard, data element agreement, element presence, data source agreement, distribution comparison, validity checks, log review), built inductively rather than borrowed from an existing framework. Completeness (64%) and correctness (60%) dominated the literature; plausibility, the dimension most relevant to implausible-value flagging, appeared in only 7% of articles, and its associated method, validity checks, was one of the rarest (7 of 95). Gold-standard comparison was the single most common method (37/95) despite the authors' own warning that genuine gold standards for EHR data essentially don't exist. The classification was performed by a single coder — a flagged limitation, with no inter-rater agreement reported. The buildable artifact: a one-page QC-dimension crosswalk mapping every existing/proposed height-weight flagging rule to which of the five dimensions it actually addresses, making coverage gaps visible.

Plain-English glossary

  • Concordance — whether elements within a record, or between a record and another source, agree with each other. (中文：一致性，指记录内部的多个元素之间、或记录与另一个数据源之间是否互相吻合。)
  • Currency — whether a data value still reflects the patient's actual state at a given point in time (also called timeliness/recency). (中文：时效性，指某个数据值在特定时间点是否仍然反映患者的真实状态，也称为及时性或新近性。)
  • "Fitness for use" — Juran's definition of quality: data are adequate or inadequate relative to a specific intended use, not good or bad in the abstract. (中文："适用性"，Juran对质量的定义：数据相对于某个具体的预期用途而言是充分还是不充分，而不是抽象意义上的好坏。)
  • Gold standard (in DQ assessment) — an external reference dataset assumed to represent ground truth, used for comparison; genuinely trustworthy gold standards are rare for EHR data. (中文：金标准，一个被假定代表真实情况、用于比较的外部参照数据集；对EHR数据而言，真正可信的金标准很少见。)
  • Plausibility — whether a data value makes sense given other knowledge about what it measures (e.g. a biologically implausible range). (中文：合理性，指某个数据值结合其所测量对象的其他已知信息来看是否说得通，例如是否落在生物学上合理的范围内。)
  • Secondary use / reuse (of EHR data) — using clinical data collected during patient care for a different purpose, such as research, than the one it was originally collected for. (中文：二次利用，指把在临床诊疗过程中收集的数据用于研究等其原始收集目的以外的用途。)
  • Validity check — an assessment method that determines whether individual data values "make sense" (e.g. range checks). (中文：有效性检查，一种评估方法，用于判断单个数据值是否"说得通"，例如范围检查。)

What to verify first

  • This is a 2012-vintage search; treat it as the vocabulary's origin point, not its current state — tomorrow's Kahn 2016 paper explicitly reorganizes these same five dimensions.
  • Single-coder classification with no reported inter-rater agreement — category boundaries (e.g. concordance vs. plausibility) may be less sharp in practice than the definitions suggest.
  • Any mapping of a specific flagging rule onto one of these five dimensions is a framing exercise against this external taxonomy — it says nothing about what a specific registry's current cleaning rules actually check.

Pipeline stage

Error types covered / not covered

The taxonomy is a classification scheme, not a detector — it doesn't itself flag any error type. It does clarify which dimension a given error type belongs to: e.g. an implausible single value is a plausibility issue; a value contradicting a prior visit's trajectory is more of a concordance issue; a missing expected measurement is a completeness issue, not a plausibility one.
