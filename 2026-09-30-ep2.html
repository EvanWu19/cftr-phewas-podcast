Feasibility of Converting EMR Data to OMOP CDM and Utilizing OHDSI Analysis Tools in Japan

A short (two-page) conference proceedings report from the National Cancer Center Hospital East in Japan, documenting an end-to-end feasibility run of converting EMR data for 8,387 breast cancer patients into the OMOP Common Data Model and standing up OHDSI's standard toolchain — vocabulary mapping (SNOMED-CT, RxNorm, LOINC), the Data Quality Dashboard, and ATLAS for cohort analysis. This episode is abstract-only: the paper has no PMCID and is closed access, so everything summarized here comes from the structured abstract. The team mapped 7,259 terms into OHDSI's standard vocabulary and successfully ran ATLAS reports on observation period and drug use, but flagged real friction in software installation, general vocabulary mapping, race-data mapping specifically, and anticancer drug specification selection — none of which are quantified in the abstract. The episode leans on this as a case study to teach the OMOP/OHDSI/ATLAS/DQD toolchain conceptually, and lands on a buildable artifact: a public-data (Synthea) sandbox rehearsal of the same conversion-and-QC pipeline, serving the AI-tooling/career priority as a method-only exercise.

Plain-English glossary

ATLAS — OHDSI's web application for defining patient cohorts, building characterizations, and running standardized analyses against an OMOP database.（中文:OHDSI提供的网页应用,用于定义患者队列、构建特征描述,并对OMOP数据库运行标准化分析。）

Data Quality Dashboard (DQD) — an open-source OHDSI tool that runs a large, versioned battery of automated conformance and plausibility checks against an OMOP-converted dataset.（中文:OHDSI的开源工具,对已转换为OMOP格式的数据集运行一整套版本化的自动化一致性与合理性检查。）

LOINC — a standard vocabulary for identifying laboratory tests and measurements, one of OMOP's adopted standard vocabularies.（中文:用于标识实验室检测和测量项目的标准词表,是OMOP采用的标准词表之一。）

OHDSI (Observational Health Data Sciences and Informatics) — the open international collaborative that builds and maintains OMOP CDM and its open-source tooling.（中文:构建并维护OMOP CDM及其开源工具生态的开放国际协作组织。）

OMOP CDM (Common Data Model) — a standardized relational schema for observational health data, mapping every clinical concept to a single standard vocabulary code so the same analysis can run identically across sites.（中文:用于观察性健康数据的标准化关系型模式,将每个临床概念映射到统一标准词表编码,使同一分析可在不同站点上以完全一致的方式运行。）

RxNorm — a standard vocabulary that normalizes drug names and formulations, one of OMOP's adopted standard vocabularies.（中文:用于规范药品名称和剂型的标准词表,是OMOP采用的标准词表之一。）

SNOMED-CT — a broad standard vocabulary covering clinical findings, diagnoses, and procedures, one of OMOP's core adopted vocabularies.（中文:广泛覆盖临床发现、诊断和操作的标准词表,是OMOP核心采用的标准词表之一。）

Synthea — an open-source tool that generates configurable, fully synthetic patient populations with no privacy constraints, commonly used to sandbox EMR/OMOP pipelines.（中文:一款开源工具,可生成可配置、完全合成、无隐私限制的患者群体,常用于EMR/OMOP流程的沙盒测试。）

Vocabulary mapping — the process of matching every locally coded or free-text clinical concept in a source EMR to its equivalent standard concept ID in an OMOP-adopted vocabulary; the main source of friction in any OMOP conversion.（中文:将源EMR系统中每个本地编码或自由文本的临床概念,匹配到OMOP采用词表中对应标准概念ID的过程;是任何OMOP转换中摩擦的主要来源。）
