Show notes — Track B — 2026-08-05

LLM-augmented semantic embeddings enable cross-lingual mapping of medical procedure terms — Guillen-Ramirez H, et al. Scientific Reports, 2026.

Blurb

MAP-CARE (Multilingual Approach for Procedures in Clinical and Retrieval Embeddings) is a four-step, open-source pipeline for aligning national medical procedure classifications that have no official mapping between them: sanitize each source term, translate and contextually augment it with an open-source LLM run locally via Ollama (one-shot prompting, rule-based output cleanup), embed the augmented English text into a 1024-dimensional vector with the mxbai embedding model, and store everything in ChromaDB for nearest-neighbor cross-lingual retrieval. Applied to Switzerland's CHOP and Germany's OPS procedure classifications, translation fidelity was rated "equal" by human experts in 68.6% of 494 spot-checked terms (Cohen's Kappa 0.34, "fair"), direct LLM-judged CHOP-to-OPS matching hit 25.7% exact / 29.1% near / 35.6% partial / 9.5% mismatch (only 9.5% mismatch at the most granular six-digit level), and in a head-to-head retrieval benchmark the mxbai embedding hit ceiling performance (Acc@1/Acc@5 = 1.000) in English-to-English retrieval, beating specialized biomedical encoders like SapBERT and CODER. For us this lands on AI-tooling for the career track (with a data-quality side-benefit): the transferable piece isn't the specific classifications but the pipeline shape itself — sanitize, LLM-translate-and-augment, embed, store — which generalizes to harmonizing any locally coded or legacy clinical vocabulary against a chosen target terminology.

Plain-English glossary

  • CHOP (Swiss Classification of Operations and Procedures) — Switzerland's national hierarchical procedure classification, descended from ICD-9-CM, published in French/German/Italian.（中文：瑞士手术与操作分类——瑞士的国家级层级化操作分类体系，源自 ICD-9-CM，以法、德、意三语发布。）
  • OPS (Operationen- und Prozedurenschlüssel) — Germany's national procedure classification, an adaptation of the International Classification of Procedures in Medicine.（中文：德国手术与操作编码——德国的国家级操作分类体系，改编自国际医学操作分类。）
  • SNOMED CT — the international standardized clinical terminology, with hierarchical structure and rich synonymy, used here as a pragmatic (not gold-standard) bridge between CHOP and OPS.（中文：一套国际标准化临床术语体系，具有层级结构和丰富的同义词，本文用它作为 CHOP 与 OPS 之间的一座实用性（而非黄金标准）桥梁。）
  • UMLS (Unified Medical Language System) — a meta-thesaurus linking many biomedical vocabularies together to support interoperability.（中文：统一医学语言系统——一套将众多生物医学词汇表整合链接、以支持互操作性的元词库。）
  • Multiaxial coding — a single procedure code that implicitly encodes several independent dimensions at once (e.g. anatomical site, method, approach, material).（中文：多轴编码——单个操作编码同时隐含编码多个独立维度（如解剖部位、方法、入路、材料）。）
  • OHDSI Usagi — an open-source tool for semi-automated mapping of source vocabulary terms to standard concepts (here, to SNOMED CT).（中文：OHDSI 的 Usagi 工具——一款开源工具，用于将源词汇表术语半自动映射到标准概念（本文中映射到 SNOMED CT）。）
  • One-shot prompting — giving a large language model a single worked example inside the prompt, with no parameter fine-tuning, to guide its output format.（中文：一次性提示——在提示词中给大语言模型提供一个已完成的示例，不做任何参数微调，以引导其输出格式。）
  • Cohen's Kappa — a statistic measuring agreement between two raters beyond what would be expected by chance; 0.34 here is conventionally interpreted as "fair" agreement.（中文：科恩卡帕系数——衡量两位评分者之间超出偶然一致水平的一致性的统计量；本文中的 0.34 按惯例解释为“一般”水平的一致性。）

Methods / tools to lift

  • Sanitize → LLM-translate-and-augment → embed → vector-store pipeline shape — the core reusable architecture, vocabulary-agnostic.
  • mxbai embedding model — high-dimensional, small-memory-footprint embeddings tuned for retrieval tasks via an instruction prefix.
  • ChromaDB — open-source vector database for nearest-neighbor cross-lingual/cross-classification retrieval.
  • Rule-based LLM-output cleanup — deterministic post-processing to strip boilerplate/conversational text from raw LLM translations.
  • OHDSI Usagi — semi-automated concept mapping to SNOMED CT, usable as a pragmatic (not gold-standard) validation bridge.

Where it lands + buildable artifact

Serves: AI-tooling / career (data-quality side-benefit). MVP (paste-ready): Given a CSV of source terms in any language plus a target vocabulary reference, run the sanitize → LLM-translate-and-augment → embed → vector-store pipeline, then retrieve ranked candidate matches per term against the target vocabulary with an embedding-similarity score and a confidence tier, for human mapping review (not automated replacement). Input: source-term CSV + target vocabulary. Difficulty: M.

What to verify first

  • Translation fidelity ceiling — even expert human review only reached "fair" interrater agreement (κ=0.34); any adaptation needs its own source-vocabulary-literate spot-check, not a one-time automated pass.
  • SNOMED-bridge validity — the SNOMED-mediated evaluation itself was only acceptable in 55.3% of cases; treat any concept-based bridge (SNOMED or OMOP) as a pragmatic proxy, not a gold standard.
  • Best-case bias in cross-language numbers — CHOP's internal French/German/Italian cross-language accuracy benefits from all three sharing one underlying structure; the harder CHOP-to-OPS numbers are the more honest estimate for a from-scratch harmonization task with no shared structure.
