A scoping review, not a new detector: Ozonze, Habli, and Simpson screened 1,841 articles (PubMed/Web of Science/Scopus, 2011–2021) down to 23 published EHR data-quality-assessment (DQA) programs — 14 deployed, 9 prototypes — and inductively built a five-category, 24-feature taxonomy (DQ-Task, DQ-Measurement, Target-Data, DQ-Mechanism, DQ-Report) for describing them. Completeness (15/23 programs) and value conformance (12/23) dominate; plausibility and consistency checks, which require real domain knowledge, are rarer. The review is candid that most of these 23 programs aren't evaluated adequately against each other or a shared benchmark. One entry — Daymont et al.'s R-based pediatric growth-data toolkit — is directly in this podcast's lineage (growthcleanr). The buildable artifact for Runyu is documentation, not code: a lightweight DQ-Task specification template applying the review's five-field schema to any external method under consideration for the anthropometric outlier work.

Plain-English glossary

  • Data quality dimension (Kahn framework) — categories of "wrong" a value can be: completeness (is it present), value conformance (does it match expected format/range/codes), plausibility (atemporal: believable on its own; temporal: believable given neighboring values in time), consistency (do related fields agree).（中文：Kahn框架下数据"错误"的类别：完整性（是否存在）、数值一致性/规范符合性（是否符合预期格式/范围/编码）、合理性（非时序：单独看是否可信；时序：结合时间上相邻的值来看是否可信）、一致性（相关字段是否吻合）。）
  • Common data model (CDM) — a shared schema (e.g. OMOP, Sentinel CDM, i2b2, openEHR) that lets EHR data from different institutions be queried the same way.（中文：一种共享的数据模式（如OMOP、Sentinel CDM、i2b2、openEHR），使不同机构的EHR数据能以相同方式被查询。）
  • PRISMA-ScR — the standard reporting guideline for scoping reviews.（中文：范围综述的标准报告规范。）
  • ETL (extraction, transformation, loading) — the process of mapping source data's schema onto a target common data model.（中文：把源数据的模式映射到目标通用数据模型的过程，包括抽取、转换、加载三步。）
  • DQ-Task / DQ-Measurement / Target-Data / DQ-Mechanism / DQ-Report — the paper's five-category taxonomy: what to assess; how to measure it; how input data is accessed/modeled; the software qualities (configurability, usability, scalability, performance, security) that make a tool usable; how results are disseminated.（中文：论文提出的五大分类框架：评估什么；如何测量；输入数据如何访问/建模；使工具可用的软件特性（可配置性、可用性、可扩展性、性能、安全性）；结果如何反馈传达。）
