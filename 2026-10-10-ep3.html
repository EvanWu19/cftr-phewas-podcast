Plain-English Glossary

  • Carry-forward error — when a stale value from a previous visit is copied into the current record instead of a fresh measurement being entered.（中文：沿用旧值错误，指上一次就诊的旧数值被直接复制到本次记录，而没有重新测量。）
  • Decimal-place shift — a data-entry error where a value is typed with the decimal point in the wrong position (e.g., 3.5 kg entered as 35 or 0.35).（中文：小数点位移，指录入时小数点位置出错，例如把 3.5 公斤输成 35 或 0.35。）
  • Digit transposition — a data-entry error where two digits of a correct value are swapped in order (e.g., 24.6 typed as 42.6).（中文：数字颠倒，指正确数值中两个数字的顺序被打反，例如把 24.6 打成 42.6。）
  • Data-entry error — any mistake introduced when a value is typed or recorded into a system, as opposed to a true underlying clinical change.（中文：数据录入错误，指数值被输入系统时产生的错误，而非真实的临床变化。）
  • EHR (electronic health record) — the software system clinicians use to document and store patient data, including the fields where values like weight are typed in.（中文：电子健康档案，即临床人员用来记录和存储患者数据的系统，体重等数值就是输入到这类系统的字段中。）
  • Implausible value — a recorded data point that is statistically or clinically unlikely to be real, used as a general registry/EHR data-quality term, not a claim about this paper's definition.（中文：不合理值，指记录下来的数值在统计或临床上不太可能是真实的，这是注册库/电子健康档案数据质量的通用术语，不代表这篇论文具体使用的定义。）
  • Unit confusion — a data-entry error where a value is entered in the wrong unit (e.g., pounds entered into a kilograms field, or vice versa), typically producing a value off by roughly a factor of 2.2.（中文：单位混淆，指数值用错了单位录入，例如把以磅为单位的数值填进公斤字段，通常导致数值相差约 2.2 倍。）
  • Weight-based dosing — calculating a medication dose as an amount per unit of body weight (e.g., mg/kg), common in pediatrics, which makes an inaccurate recorded weight a direct safety concern.（中文：按体重给药，指按每单位体重计算药物剂量（如毫克/公斤），在儿科很常见，这也使得体重记录不准确直接成为用药安全问题。）
