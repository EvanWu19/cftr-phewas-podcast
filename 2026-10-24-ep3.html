Ep3 (Track C — registry QC, 1 of 2): A kappa score for how well your mapping actually worked

Declerck and colleagues (2026, JMIR) evaluate how well lung-cancer clinical data from Ghent University Hospital, part of the Belgian Federated Health Innovation Network (FHIN), maps into the OMOP Common Data Model — not by building a new flagging tool, but by rigorously measuring consistency (Cohen's kappa against a reference data dictionary) and completeness (patient/record counts before and after mapping) across 12 data categories. Structured, automated-mapping categories like histology and lab tests scored near-perfect kappa; manually mapped categories like TNM staging scored high means but large standard deviations, hiding real variable-level trouble; "Gender" and "Smoking status" scored zero outright, the latter from an unstructured free-text field combining smoking, drug use, and alcohol into one unparseable blob. The transfer to Track C isn't a flagging mechanism but an evaluation methodology — and the paper's weakest category, "Unit" (kappa 0.372), directly names the kind of unit-recording inconsistency anthropometric QC cares about most. Buildable artifact: an OMOP Mapping Conformance Scorecard.

Plain-English glossary

  • Cohen's kappa — a statistical measure of exact-match agreement between an assigned value and a reference value, used here per variable to assess mapping consistency against a reference data dictionary.（中文：一种衡量分配值与参考值之间精确匹配一致性的统计指标，本文用它在变量层面评估映射结果与参考数据字典之间的一致性。）
  • Completeness (data quality dimension) — whether the number of patients/records that entered a mapping or transformation process came out the other side intact, as opposed to silently dropped.（中文：进入映射或转换流程的患者/记录数量，是否完整地从流程另一端出来，而不是在中途被悄悄丢失，这是一个数据质量维度。）
  • Consistency (data quality dimension) — whether the concept code actually assigned to a variable matches what a reference standard says it should be, an exact-match agreement question.（中文：实际分配给某个变量的概念代码，是否与参考标准所规定的代码一致，这是一个精确匹配的一致性问题，也是一个数据质量维度。）
  • ETL (extract, transform, load) — the general pipeline of pulling raw data from a source system, reshaping it to fit a target structure, and loading it into that target; each step can introduce errors.（中文：将原始数据从源系统抽取出来、重新整形以适配目标结构、再加载进目标结构的通用流程；这三个步骤中的每一步都可能引入错误。）
  • OMOP Common Data Model (OMOP CDM) — a standardized set of tables and terminologies (built on SNOMED CT, LOINC, ICD-10) letting health data from different source systems be expressed the same way and compared across institutions.（中文：一套标准化的数据表结构和术语体系（建立在SNOMED CT、LOINC、ICD-10之上），使不同源系统的健康数据能以相同方式表达并在机构间比较。）

Methods / tools to lift

  • Per-category Cohen's kappa with SD — unweighted mean kappa across each category's variables, reported alongside the standard deviation to avoid a single reassuring scalar hiding variable-level trouble.
  • Pre/post-mapping patient and record counts — the completeness-assessment method, comparing counts before and after ETL to catch silent data loss.
  • Rabbit-in-a-Blender — the open-source ETL pipeline tool used to transform raw hospital data into OMOP CDM 5.4.

Where it lands + buildable artifact

Pipeline stage: (d) evaluation, primary — Cohen's-kappa-plus-completeness-counts measures mapping conformance without needing a classifier ground truth beyond the reference dictionary itself. (e) vocabulary/framework, secondary — the per-category kappa-with-SD format is reusable for flagging exactly which variable categories most need rework, and the "Unit" category's poor score names the unit-recording-inconsistency problem anthropometric QC cares about most. Buildable artifact: an OMOP Mapping Conformance Scorecard — define a small reference-mapping dictionary for key variable categories including units, compute per-category kappa with SD, flag categories below a threshold as review priorities.

Error types covered / not covered: Covers categorical/coding mismatches, granularity mismatches (e.g. 4-digit vs. 5-digit ICD-10 codes mapping to different OMOP concepts for the same clinical reality), unstructured/free-text field loss, and missing-record mismatches across source systems. Does not cover continuous numeric implausible-value errors — unit conversion, digit transposition, decimal shift, carry-forward — since the evaluated variables here are categorical mapping targets, not continuous anthropometric measurements.

What to verify first

  • Whether Cohen's kappa against a hand-built reference dictionary is a trustworthy evaluation metric when the dictionary itself is incomplete or evolves mid-project, as it did here.
  • Whether a unit-mismatch QC signal catching ICD coding-granularity mismatches generalizes to catching raw numeric unit errors (pounds vs. kilograms, centimeters vs. inches) in continuous anthropometric fields specifically.
  • Whether a kappa-based evaluation approach requires a similarly large, carefully hand-curated reference set that may not yet exist for a given registry's anthropometric fields.
  • That a high kappa against a reference dictionary is read as mapping conformance, not as proof of clinical correctness, given the dictionary's own documented gaps (e.g. "Gender").
