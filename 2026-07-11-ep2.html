Ep2 — Track B: the independent audit as a shippable product

2026-07-11 · Track B — AI for registry/bioinformatics, tool-development lens

Blurb

Marco Salas et al. did the benchmark the vendor was never going to run: 25 Xenium spatial-transcriptomics datasets (1.2B reads, 6M cells), compared against eight other platforms, with every dataset re-segmented by a common algorithm first so the comparison isn't secretly a comparison of vendor software. Then a huge sweep across four tasks — segmentation, preprocessing, imputation, tissue-domain identification — shipped as a repo with per-tool conda recipes. We are not reading this for the tissue. We're reading it for the genre (an independent audit of somebody else's defaults, published in Nature Methods, now the field's decision tree) and for one QC trick worth stealing outright: they built an empirical false-positive rate out of negative control probes — things they knew must be zero. Where it lands: AI-tooling / career. The buildable artifact is nullmarker-qc: a library that scores any dataset against a domain-declared list of things that should be impossible, plus a mode that reports how much each processing knob moves the downstream answer.

Plain-English glossary

  • Cell segmentation — drawing boundaries around individual cells so each detected transcript can be assigned to one; an upstream, invisible, hyperparameter-laden step that silently determines every downstream number.（中文：细胞分割，为每个细胞画出边界以便分配转录本；这是一个上游的、看不见的、充满超参数的步骤，会悄然决定所有下游结果。）
  • Cell-by-gene matrix — the table (cells × genes) that all downstream analysis expects; the product of segmentation.（中文：细胞×基因矩阵，所有下游分析所期待的那张表，是分割的产物。）
  • DAPI — a fluorescent dye that binds DNA, used to stain and locate cell nuclei.（中文：DAPI 是一种与 DNA 结合的荧光染料，用于给细胞核染色定位。）
  • Imputation (spatial) — predicting expression of genes you didn't measure, by borrowing structure from a reference single-cell dataset.（中文：插补，借助参考单细胞数据集，预测未被测量基因的表达。）
  • In situ sequencing (ISS) — reading transcripts while they remain in place in the tissue section, via probe hybridization + repeated imaging cycles.（中文：原位测序，让转录本留在组织切片原位，通过探针杂交和多轮成像来读取。）
  • Negative control probe — a probe designed against a sequence that should not exist in the tissue; anything it detects is by definition noise. The key idea of the episode.（中文：阴性对照探针，针对组织中本不应存在的序列设计；它检测到的一切按定义都是噪音 —— 本集的核心思想。）
  • Negative marker purity (NMP) — the fraction of a cell's detected reads that a reference says its cell type should not express; a ground-truth-free segmentation quality metric (but not assumption-free).（中文：阴性标志物纯度，指一个细胞检测到的读数中，参考数据认为其细胞类型"不应表达"的比例；这是一个无需真值、但并非无需假设的分割质量指标。）
  • Nucleus expansion — growing the nuclear boundary outward by a fixed radius to try to capture the cytoplasm; Xenium's default is 15 µm, but the data implies ~5.6 µm is right.（中文：核扩张，把细胞核边界向外固定扩张以试图涵盖细胞质；Xenium 默认 15 微米，但数据显示约 5.6 微米才合适。）
  • Panel — the pre-chosen set of a few hundred genes an in situ platform can measure; here 210–392 genes.（中文：探针组，原位平台事先选定的几百个可测基因；本文中为 210–392 个。）
  • Spatial transcriptomics (SRT) — measuring gene expression while retaining the physical location of each measurement in the tissue.（中文：空间转录组学，在测量基因表达的同时保留每次测量在组织中的物理位置。）
  • Spatially variable feature (SVF) — a gene whose expression depends on where you are in the tissue, rather than being uniformly on or off.（中文：空间可变特征，指表达取决于组织中所处位置的基因，而非均匀开启或关闭。）
  • Tissue domain — an anatomically or functionally coherent region of tissue, identified from the data and compared here against expert manual annotation.（中文：组织区域，指解剖或功能上连贯的组织区块，本文由数据识别并与专家人工标注比对。）
  • Transcript / read (in situ) — a single detected mRNA molecule, carrying x, y, z coordinates, a gene identity, and a quality value.（中文：转录本/读数，指一个被检测到的 mRNA 分子，带有 x、y、z 坐标、基因身份和质量值。）

Methods / tools to lift

  • Negative-control-probe empirical null — the transferable idea. They used control probes (which cannot be spatially variable) to directly measure each SVF algorithm's false-positive rate. Build your error bar out of things you already know are zero.
  • Negative marker purity (NMP) as a reference-based, boundary-free quality score — powerful, but it inherits every error in the reference. Ground-truth-free ≠ assumption-free.
  • The fairness control — re-segmenting every platform's data with one common algorithm (Cellpose) before comparing, so the cross-platform comparison isn't a proxy comparison of vendor segmentation software. This single control is the paper in miniature.
  • Sensitivity-analysis-dressed-as-recommendation — the preprocessing sweep's real output is which knobs matter: normalization method, library-size constant, whether you scale, number of PCs. Everything else was noise. The "best" workflow (library-size norm to 100 → log → scale → kNN on all PCs, 16 neighbors → Louvain) is less durable than the ranking of knob importance — several top workflows omitted log-transform entirely, and the authors say plainly there is no universal best.
  • Named tools — Cellpose (deep-learning nucleus/cytoplasm segmenter); Baysor (read-based segmenter that assigns transcripts by local density + composition, no expansion needed); Watershed / MESMER / Clustermap (alternative segmenters); SSAM and Points2Regions (segmentation-free methods that find molecular signatures without drawing cells); Banksy / SPACEL / STAGATE / DeepST / SpaGCN (domain-identification algorithms); Scanpy (v1.9.1, the analysis backbone).
  • The winner that barely mattered — Cellpose nuclei + Baysor read assignment, no expansion, beat everything. But co-processing showed the same cell populations as the default. Honest conclusion: the default is adequate for the coarse answer and wrong for the fine one. Report that, don't bury it.
  • Naive baselines survive — simple spatial binning made it into the final domain-identification recommendation alongside Banksy and SPACEL, against five published deep-learning methods. Always run the stupid baseline.

Where it lands + buildable artifact

Lands on: AI-tooling / career (senior RWE × genomics tooling).

nullmarker-qc (difficulty: M) — MVP one-liner: A two-mode library — (1) purity: give it a table plus a YAML spec of "null markers" (domain-declared field/value combinations that should be approximately impossible for a given class of record) and it returns a per-class purity score and a ranked list of worst-offending records; (2) sensitivity: give it a processing pipeline plus a grid of choices and it reports, one number per knob, how much the downstream answer moves — so you know which preprocessing decisions are load-bearing and which are decoration.

Portfolio-legible in a way a one-off analysis never is: it's the thing you point at when someone asks what you build.

What to verify first

  • Reference-dependence. A purity metric is only as good as the list of things you declared impossible. In any clinical/registry setting that list must come from clinicians and domain knowledge, not from the data itself — otherwise you've built a beautiful circle.
  • Benchmark generalization. This is mouse-brain-heavy and platform-version-specific. The authors state plainly they tested only a subset of popular methods, so their top performer may not be the best available.
  • Environment rot. A repo of conda recipes decays. If we build a sweep harness, pin and containerize on day one or the sensitivity analysis is unreproducible within a year.
  • The 3D blind spot. 1.8% of cells carried mixed signal from z-overlapping cells, which every 2D algorithm silently merges. Analogue: what dimension of our data is present in the raw file and thrown away by the standard tool?
  • No registry-internals claims. This is an external method. The null-marker list is exactly the artifact a domain owner would supply.

JORDAN Then give me just enough biology to follow the plot. 那就给我刚好够用的生物学，能跟上情节就行。

ALEX Spatial transcriptomics means measuring which genes are expressed while keeping track of where in the tissue each measurement came from. 空间转录组学（spatial transcriptomics）的意思是：在测量基因表达的同时，记录每一次测量在组织中的位置。 Xenium is a commercial instrument from 10x Genomics that does this by in situ sequencing — in situ 就是"原位"，意思是分子从未离开组织切片。 You choose a panel of a few hundred genes ahead of time, hybridize probes to their transcripts, amplify, and image the tissue over many cycles. 你事先选定一个几百个基因的探针组（panel），让探针与它们的转录本杂交、扩增，然后对组织进行多轮成像。 The raw output is a point cloud: for every detected transcript you get an x, a y, a z, a gene identity, and a quality value. 原始输出是一团点云：每一个被检测到的转录本都带有 x、y、z 坐标、基因身份，以及一个质量值。

JORDAN A point cloud is not cells. 点云不是细胞。

ALEX And that is the entire problem. 而这正是全部问题所在。 To get from transcripts to a cell-by-gene matrix — the table that everything downstream expects — you have to draw boundaries around cells. 要从转录本走到细胞×基因矩阵 —— 也就是所有下游分析所期待的那张表 —— 你必须在细胞周围画出边界。 That step is called cell segmentation. 这一步叫做细胞分割（cell segmentation）。 Xenium's default approach stains nuclei with DAPI — DAPI 是一种与 DNA 结合的荧光染料，用来把细胞核标出来 — finds the nuclei, and then expands the boundary outward by a fixed 15 micrometers to try to capture the cytoplasm. Xenium 的默认做法是用 DAPI 把细胞核染出来，找到细胞核，然后把边界向外固定扩张 15 微米，试图把细胞质也包进来。 Every transcript inside that boundary gets assigned to that cell. 落在这个边界内的每一个转录本，都被归给那个细胞。 So segmentation is an upstream, invisible, hyperparameter-laden decision that silently determines every number you report afterwards. 所以细胞分割是一个上游的、看不见的、充满超参数的决策，它悄无声息地决定了你之后报告的每一个数字。

JORDAN That's the shape I recognize. 这个形状我认得。 That's a preprocessing choice that eats the analysis. 这就是一个会把整个分析吞掉的预处理选择。

ALEX Exactly, and hold that thought, because it's the transferable one. 完全正确，先记住这个念头，因为它就是可迁移的那一个。 Two more terms. 还有两个词。 Negative control probes: probes designed against sequences that should not exist in the tissue, included on the panel on purpose. 阴性对照探针（negative control probe）：针对组织中本不应存在的序列设计的探针，被故意放进探针组里。 Anything they detect is definitionally noise. 它们检测到的任何东西，按定义就是噪音。 And spatially variable features — genes whose expression depends on where you are in the tissue, as opposed to genes that are just uniformly on or off. 还有空间可变特征（spatially variable feature）—— 指表达水平取决于你在组织中所处位置的基因，与那些只是均匀开启或关闭的基因相对。

JORDAN Why did anyone need to write this paper? 为什么会有人需要写这篇论文？ The vendor ships software. 厂商本来就自带软件。

ALEX That's exactly the gap. 这正是那个空白。 A commercial platform arrives with a default pipeline, and the default pipeline is validated by the people selling the platform. 一个商业平台带着一套默认流程出场，而这套默认流程是由卖平台的人自己验证的。 Their incentive is to demonstrate that the instrument works, which is not the same as characterizing when and how it fails. 他们的动机是证明这台仪器能用，而这与"刻画它在什么时候、以什么方式失败"完全不是一回事。 Meanwhile the field had eight or nine competing platforms and no neutral comparison, so every buyer was choosing on marketing. 与此同时，这个领域有八九个互相竞争的平台，却没有一个中立的比较，于是每个买家都只能靠营销材料来做选择。 And every published downstream result silently inherited whatever the default pipeline decided. 而每一篇发表的下游结果，都在无声中继承了默认流程所做的决定。 Nobody knew how much of the published biology was an artifact of a fifteen-micrometer expansion parameter that someone picked as a round number. 没有人知道，已发表的生物学结论里有多少其实是某人随手取了一个整数、把扩张参数定成十五微米所产生的假象。

JORDAN So the contested thing was never the instrument. 所以争议点从来不是仪器本身。 It was the defaults. 而是那些默认值。

ALEX The defaults, and the absence of anyone independent willing to do the boring work of turning every knob. 是默认值，以及缺少一个独立的、愿意去做"把每个旋钮都转一遍"这种枯燥工作的人。 That's the genre I want you to notice. 这就是我希望你注意到的那个体裁。 This is not a new-method paper. 这不是一篇提出新方法的论文。 It is an audit, and it got into Nature Methods, and it produced a decision tree that the whole field now cites. 这是一次审计，它进了《Nature Methods》，并且产出了一棵整个领域现在都在引用的决策树。 Auditing somebody else's defaults is an underrated way to become the person a field routes questions through. 审计别人的默认设置，是一条被严重低估的路径，能让你成为整个领域把问题转过来问的那个人。

JORDAN So what did they actually do? 那他们到底做了什么？

ALEX They ran the benchmark that the vendor was never going to run. 他们做了那个厂商永远不会做的基准测试。 Twenty-five Xenium datasets from fourteen experiments — 1.2 billion reads, 6 million cells, panels ranging from 210 to 392 genes. 二十五个 Xenium 数据集，来自十四次实验 —— 12 亿条读数、600 万个细胞，探针组规模从 210 到 392 个基因不等。 Baseline quality: 81% of reads above quality value 20, an average of 186.6 reads per cell, and 76.8% of reads assigned to a cell under the default segmentation. 基线质量：81% 的读数质量值高于 20，平均每个细胞 186.6 条读数，在默认分割下有 76.8% 的读数被分配给了某个细胞。 Then they compared Xenium against eight other spatial platforms — MERSCOPE, MERFISH, CosMx, Molecular Cartography, Visium and others — and crucially, they re-segmented every dataset with the same algorithm first, so the comparison isn't secretly a comparison of vendor segmentation software. 然后他们把 Xenium 与另外八个空间平台做了比较 —— MERSCOPE、MERFISH、CosMx、Molecular Cartography、Visium 等等 —— 而关键在于，他们先用同一个算法把所有数据集重新分割了一遍，这样比较的就不会暗地里变成"厂商分割软件之间的比较"。 That control is the paper in miniature. 这一个对照，就是整篇论文的缩影。

JORDAN And then a sweep. 然后是一次网格扫描。

ALEX A large one, across four tasks. 一次很大的扫描，横跨四个任务。 Segmentation: six method families — Watershed, MESMER, Cellpose, Baysor, Clustermap, and naive binning — each crossed with expansions of 1, 2, 5, 10 and 15 micrometers, and Baysor further crossed with scale parameters, minimum-molecules-per-cell, and prior-confidence values. 分割：六个方法族 —— Watershed、MESMER、Cellpose、Baysor、Clustermap，以及朴素的分箱 —— 每一个都与 1、2、5、10、15 微米的扩张量交叉，Baysor 还额外与尺度参数、每细胞最少分子数和先验置信度交叉。 Preprocessing: normalization method, library size, log-transform on or off, scaling on or off, number of principal components, number of neighbors, clustering algorithm. 预处理：归一化方法、文库大小、是否取对数、是否标准化、主成分数量、近邻数量、聚类算法。 Then seven imputation methods, and five tissue-domain-identification algorithms scored against expert manual annotation from the Allen Brain Atlas. 然后是七种插补方法，以及五种组织区域识别算法，用 Allen Brain Atlas 的专家人工标注作为评分标准。 The whole thing ships as a repo with per-tool conda recipes, because every one of these tools has an incompatible environment. 整套东西作为一个代码仓库发布，为每个工具单独提供 conda 配方，因为这些工具里的每一个都有互不兼容的运行环境。

JORDAN Before results — what's the design choice you'd argue with? 在讲结果之前 —— 你会跟哪一个设计选择较劲？

ALEX Their headline segmentation metric. 他们的核心分割指标。 They score a segmentation by two things: what fraction of reads got assigned to a cell, and something they call negative marker purity. 他们用两件事给一次分割打分：有多少比例的读数被分配到了细胞，以及一个他们称为"阴性标志物纯度"（negative marker purity, NMP）的量。 Negative marker purity asks: for each cell type, what fraction of its detected reads are genes that a reference single-cell dataset says that cell type should not express? 阴性标志物纯度问的是：对每一种细胞类型，它检测到的读数中有多大比例是"参考单细胞数据集认为这类细胞不应该表达"的基因？ It's a beautiful metric — it needs no ground-truth boundaries, just a list of things that should be zero. 这是一个很漂亮的指标 —— 它不需要真值边界，只需要一份"应该为零"的清单。 But it inherits every error in the reference. 但它继承了参考数据集里的每一个错误。 If the reference single-cell data is wrong about what a cell type expresses, the metric is confidently wrong, and it will punish a correct segmentation. 如果参考单细胞数据对某类细胞的表达谱判断有误，这个指标就会自信地出错，并且会惩罚一次正确的分割。 It's ground-truth-free but not assumption-free, and those are very different things. 它不依赖真值，但并非不依赖假设，而这两者截然不同。

JORDAN Results. 结果。

ALEX The geometry first, because it's damning and simple. 先说几何，因为它既致命又简单。 Mean nuclear radius in their data is 5.06 micrometers, which implies an ideal expansion of about 5.64 micrometers to capture the cell body. 他们数据中细胞核的平均半径是 5.06 微米，据此推算，要涵盖细胞体，理想的扩张量约为 5.64 微米。 The vendor default is 15. 而厂商的默认值是 15。 The default over-expands by nearly a factor of three, which means it is systematically stealing transcripts from neighboring cells. 默认设置的过度扩张接近三倍，这意味着它在系统性地把邻近细胞的转录本偷过来。 And different cell types have different optimal expansions, so no single number is right. 而且不同细胞类型的最佳扩张量各不相同，所以任何单一数字都不对。 The winner was Baysor — a read-based method that assigns transcripts by local density and composition — used with the nuclear segmentation as a prior. 优胜者是 Baysor —— 一种基于读数的方法，依据局部密度和组成来分配转录本 —— 并且以细胞核分割作为先验。 Cellpose to find the nuclei, Baysor to assign the reads, no expansion at all. 用 Cellpose 找细胞核，用 Baysor 分配读数，完全不做扩张。

JORDAN And how much did that actually change the biology? 那这实际上改变了多少生物学结论？

ALEX Almost nothing, and I love that they said so. 几乎没有改变，而我很欣赏他们把这一点说出来了。 When they co-processed Baysor cells and default nuclear cells, the identified populations were the same. 当他们把 Baysor 分出的细胞和默认核分割的细胞放在一起处理时，识别出的细胞群体是相同的。 Baysor got higher counts per cell and mild differences in abundance, but you did not discover new cell types by fixing segmentation. Baysor 每个细胞的计数更高、丰度上有轻微差异，但你并没有因为修好了分割而发现新的细胞类型。 The honest conclusion is: the default is adequate for the coarse answer and wrong for the fine one. 诚实的结论是：默认设置对粗粒度的答案是够用的，对精细的答案则是错的。 That is a much more useful finding than "our method wins." 这比"我们的方法赢了"要有用得多。

JORDAN What about the preprocessing sweep? 那预处理扫描呢？

ALEX The best workflow was library-size normalization with the target size set to 100, then log-transform, then scaling, then a k-nearest-neighbor graph on all principal components with 16 neighbors, then Louvain clustering. 最佳流程是：以目标文库大小 100 做文库大小归一化，然后取对数，然后标准化，然后在所有主成分上构建 16 近邻图，最后用 Louvain 聚类。 But — and this is the sentence I'd frame — some of the top-performing workflows omitted log-transformation entirely. 但是 —— 这句话我想裱起来 —— 一些表现最好的流程完全省略了对数变换。 The authors write that there is no universal best way to process these datasets. 作者写道，处理这类数据集不存在一种普适的最佳方式。 What the sweep actually identified was which knobs matter: normalization method, the library size constant, whether you scale, and the number of principal components. 这次扫描真正识别出来的，是哪些旋钮重要：归一化方法、文库大小常数、是否标准化，以及主成分的数量。 Everything else was noise. 其余的都是噪音。 That's a sensitivity analysis dressed as a recommendation, and the sensitivity analysis is the durable part. 这是一次披着"推荐"外衣的敏感性分析，而敏感性分析才是耐用的那部分。
