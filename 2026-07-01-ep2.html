Track B — Intronomics-MIP: a reproducible snakemake amplicon pipeline (read for the pattern)

Blurb. Scapolatiello et al. (2025, BMC Research Notes) present Intronomics-MIP, a snakemake pipeline that turns intron-targeted amplicon sequencing into a clean per-sample allele table, chaining Cutadapt (primer/adapter trimming) → FLASH (paired-end read merging) → SeekDeep (clustering reads into true alleles vs sequencing error). Its stated use is species identification and population genomics in teleost fish — cryptic species, species complexes, hybridization, and population structure without prior labels — using multilocus intron polymorphisms as high-information, multiple-allelic markers. The topic is fish; the transferable object is the workflow pattern. It lands on the AI-tooling / career lane (portfolio infrastructure): a reproducible, containerized, config-driven amplicon-to-allele-table skeleton is exactly the shape you'd want for any targeted-resequencing project, including CFTR amplicon panels, and it sits directly upstream of the Track A variant-classification worklist by producing the normalized HGVS variant list that worklist consumes. Abstract-only for us today (no PMCID, no OA full text) — flagged on-air; no accuracy or runtime numbers were available.

Plain-English glossary.

  • Amplicon sequencing — PCR-amplifying chosen regions and sequencing them deeply, rather than sequencing the whole genome.（中文：扩增子测序，先用 PCR 扩增选定区域再深度测序，而非全基因组测序。）
  • Cryptic species — populations that look identical but are genetically distinct lineages.（中文：隐存种，外观相同但遗传上是独立谱系的种群。）
  • DADA2 — a modern amplicon denoiser (named as the missing benchmark comparison).（中文：DADA2，一种现代扩增子去噪工具，被点名为本文缺失的基准比较对象。）
  • Denoising / allele calling — distinguishing true sequence variants from PCR/sequencer errors; the make-or-break step.（中文：去噪／等位判定，把真实序列变异与 PCR／测序仪错误区分开，是成败关键的一步。）
  • Haplotype — a set of variants inherited together on one chromosome; an intron amplicon reads out as a haplotype.（中文：单倍型，同一条染色体上一起遗传的一组变异；一个内含子扩增子读出的就是一个单倍型。）
  • HGVS — the standardized notation for writing a variant unambiguously.（中文：HGVS，变异命名的标准化书写规范。）
  • Indel — an insertion or deletion; length variation that denoisers handle unevenly.（中文：indel，插入或缺失，一种长度变异，各去噪器对其处理能力参差不齐。）
  • Intron — a non-coding stretch inside a gene, spliced out before translation; more polymorphic because under weaker selection.（中文：内含子，基因内部一段非编码序列，翻译前被剪接掉；因选择压力较弱而更具多态性。）
  • Multiple-allelic marker — a marker with many possible states at one locus (vs a two-state SNP), carrying more discriminating information.（中文：多等位标记，一个位点有多种可能状态（相对于只有两态的 SNP），携带更多区分信息。）
  • Polymorphism / SNP — a position where sequence differs across individuals; a SNP is the single-nucleotide, two-state case.（中文：多态性／SNP，序列在个体间存在差异的位置；SNP 是单核苷酸、两态的那一类。）
  • snakemake — a Python-ecosystem workflow manager: declare steps as rules, it builds the dependency graph, runs in order, resumes on failure, parallelizes, and records provenance.（中文：snakemake，Python 生态的工作流管理器：把步骤声明为规则，它构建依赖图、按序运行、失败可续跑、自动并行、并记录来源。）
  • Teleost — ray-finned bony fish, the large group most familiar fish belong to.（中文：硬骨鱼（teleost），辐鳍亚纲硬骨鱼，多数常见鱼类所属的大类群。）

Full citation. Scapolatiello A, Boscari E, Schiavon L, Vitulo N, Congiu L. Intronomics-MIP: a snakemake pipeline for analyzing multilocus intron polymorphisms in species identification and population genomics. BMC Res Notes. 2025. PMID: 40325430 · DOI: 10.1186/s13104-025-07264-6

Methods / tools to lift.

  • snakemake declarative-rule architecture — restartability, free parallelism, executable provenance, config/code separation.
  • Cutadapt — adapter and primer trimming from reads.
  • FLASH — merging overlapping paired-end reads into one sequence per fragment.
  • SeekDeep — clustering merged reads into true alleles vs sequencing error (the denoising step; consider benchmarking against DADA2).
  • The reusable primitive: a containerized amplicon → denoise → tidy-allele-table skeleton, parameterized by config.

Where it lands + buildable artifact. Serves AI-tooling / career (portfolio infrastructure). Paste-ready MVP: snakemake CFTR-amplicon-to-HGVS skeleton — input raw paired-end amplicon FASTQs covering CFTR regions; rules run primer trimming → paired-end merging → denoising/allele-calling → emit a tidy per-sample table of called variants normalized to canonical HGVS; each rule in its own pinned container for bit-for-bit reproducibility; parameters (primers, quality/denoising cutoffs) live in config. Input: paired-end CFTR amplicon FASTQs. Difficulty: M. Sits upstream of the Track A CFTR ACMG/AMP criteria worklist (feeds it the normalized HGVS variant list).

What to verify first.

  • Abstract-only today: inspect the actual repo for pinned tool versions, per-rule containers, and clean config/code separation before adopting.
  • Indels: confirm the denoising/calling step handles insertions and deletions, not just substitutions — clinically important CFTR variants include indels.
  • Transfer: re-validate the denoiser on human clinical amplicons (different primers, depth, quality) — fish validation doesn't carry over automatically.
  • Denoising threshold is dataset-dependent (depth × error rate): too loose inflates false alleles, too strict erases real rare haplotypes — keep it in config and tune per dataset.
  • No performance numbers in the abstract: reproduce the shipped example end-to-end before trusting output.
  • External analytic pipeline only — says nothing about any registry's internal data.

"无需事先知道物种的群体结构"——这能带来什么？ ALEX: It means you can hand the pipeline a bag of samples you can't confidently label and still recover which ones cluster together. 意思是你可以把一堆无法自信标注的样本交给这个流程，仍能还原出哪些样本聚在一起。 That's the unsupervised-clustering flavor of population genetics: let the marker variation define the groups instead of assuming the groups up front. 这就是群体遗传学里"无监督聚类"的味道：让标记的变异去定义分组，而不是事先假定分组。 Detecting hybridization is the same idea pushed one step — an individual whose markers straddle two clusters is a candidate hybrid. 检测杂交是同一思路再推一步——一个标记横跨两个聚类的个体，就是候选杂交个体。 JORDAN: Why is species identification even hard enough to need a pipeline? 物种鉴定这件事，难到需要一整条流程吗？ ALEX: Harder than it sounds, and that difficulty is the whole motivation. 比听起来难，而这份难度正是全部动机所在。 Many organisms are impossible to tell apart by eye — larvae, processed food products, fragments, and genuinely cryptic species that are separate lineages wearing the same body plan. 许多生物用肉眼根本无法区分——幼体、加工过的食品、残片，以及那些真正的隐存种：披着同一体型、却是彼此独立谱系的物种。 In fisheries that matters commercially and legally, because seafood mislabeling and protected-species substitution are real problems that a molecular test has to catch. 在渔业里这在商业和法律上都重要，因为海产品贴错标签、以及用受保护物种冒充替代，都是真实存在的问题，需要一个分子检测来抓出来。 The scientific gap the note targets is not a new marker idea — intron markers existed — but the lack of a standardized, shareable way to go from reads to answers. 这篇简报瞄准的科学空白，不是一个新的标记想法——内含子标记早已存在——而是缺一条标准化、可共享的、从读段到答案的路径。

相比一个依次调用这三个工具的 shell 脚本，它实际上解决了什么？ ALEX: Three things, and they're the same three that separate portfolio-grade tooling from a one-off script. 三件事，而它们正是把"作品集级工具"和"一次性脚本"区分开来的那三件事。 One: restartability — if the third step fails on sample 400, snakemake resumes from there instead of recomputing the first two steps for all 400 samples. 一：可续跑——如果第三步在第 400 个样本上失败了，snakemake 会从那里继续，而不是为全部 400 个样本重算前两步。 Two: parallelism for free — the dependency graph tells it which samples are independent, so it fans them across cores or a cluster without you hand-writing the scheduling. 二：自动并行——依赖图告诉它哪些样本互相独立，于是它把它们铺开到多核或集群上，无需你手写调度。 Three: provenance — the rules plus a config file are an executable record of exactly what was run, which is the difference between "trust me" and "here's the graph." 三：来源可溯——规则加上一个配置文件，是"到底运行了什么"的一份可执行记录，这就是"相信我"和"这是图，你自己看"之间的区别。 The config-versus-code separation matters most: parameters like primer sequences and quality cutoffs live in a config file, so re-pointing the pipeline at a new project is a config edit, not a code rewrite. 配置与代码分离最为重要：引物序列、质量阈值这类参数放在配置文件里，所以把流程重新对准一个新项目只是改配置，而不是重写代码。 The pipeline chains three named tools. 这个流程串联了三个具名工具。 Cutadapt trims adapters and primers off the reads.
