Ep1 (Track A) — 2026-10-06

Blurb

Chen YA et al.'s 2025 Human Genomics paper runs 164,549 high-review-status ClinVar variants through ANNOVAR, SnpEff, and VEP and asks a simple question with an uncomfortable answer: how often do three widely used annotation tools agree on the HGVS string and coding-impact call for the exact same variant? On raw RefSeq/Ensembl transcript sets, HGVSc concordance across all three tools is just 9.33%/7.22%; restricting to ClinVar-selected (mostly MANE-aligned) transcripts raises it to 58.52% HGVSc / 84.04% HGVSp / 85.58% coding impact — better, but not solved. The loss-of-function category, which drives the heaviest-weighted ACMG criterion (PVS1), has the worst tool-ClinVar agreement of any functional category, and re-running ACMG classification on the discrepant-PVS1 subset downgraded a majority of originally pathogenic/likely-pathogenic calls (55.9%–67.3% across tools). This lands directly on the Karen Raraigh collaboration: CFTR variant interpretation depends on matching notation across CFTR2, ClinVar, CFTR-France, and gnomAD, and CFTR's own poly-T/TG repeat-tract alleles sit squarely in the paper's flagged repeat-notation minefield. Buildable: a cross-tool HGVS/coding-impact reconciliation check scoped to CFTR, restricted to MANE transcripts, flagging only discordances that would change a PVS1-relevant category.

Plain-English glossary

  • HGVS nomenclature (g./c./p.) — the Human Genome Variation Society's standard for writing a variant as a string at the genomic ("g."), coding-DNA ("c."), or protein ("p.") level.（中文：HGVS命名法（g./c./p.），人类基因组变异学会制定的标准，用于在基因组、编码DNA或蛋白质三个层级上书写变异的字符串表示。）
  • Transcript isoform / accession (NM_, NR_, ENST) — a specific annotated version of a gene's RNA product (RefSeq "NM_"/"NR_" or Ensembl "ENST" accessions); the same genomic change can yield a different HGVS string depending on which transcript it's described against.（中文：转录本异构体／编号（NM_、NR_、ENST），基因RNA产物的某一特定注释版本；同一个基因组变化，根据所依据的转录本不同，可能产生不同的HGVS字符串。）
  • MANE / MANE Select / MANE Plus Clinical — the Matched Annotation from NCBI and EMBL-EBI project; MANE Select is one RefSeq-Ensembl-agreed transcript per gene, and MANE Plus Clinical adds extra transcripts needed to capture clinically important variants MANE Select alone would miss.（中文：MANE／MANE Select／MANE Plus Clinical，NCBI与EMBL-EBI的匹配注释项目；MANE Select为每个基因指定一个RefSeq与Ensembl一致的转录本，MANE Plus Clinical则补充那些仅靠MANE Select会漏掉的临床重要变异所需的转录本。）
  • Left- vs. right-alignment (VCF vs. HGVS 3' rule) — VCF shifts indels as far toward the genome's start as possible (left-align); HGVS shifts them toward the transcript's 3' end instead (the 3' rule); in repetitive sequence these can land on different coordinates for the same change.（中文：左对齐与右对齐（VCF与HGVS的3'规则），VCF对插入缺失变异采用尽量向基因组起始方向移动的左对齐方式；HGVS则采用向转录本3'端移动的"3'规则"；在重复序列区域，二者可能为同一变化给出不同坐标。）
  • Loss-of-function (LoF) — the functional category covering frameshift, nonsense, and splice-donor/acceptor variants, generally presumed to abolish normal gene function.（中文：功能缺失（LoF），涵盖移码、无义及剪接供体/受体变异的功能类别，通常被认为会破坏基因的正常功能。）
  • PVS1 (ACMG/AMP criterion) — the "very strong" pathogenic evidence code applied specifically to loss-of-function variants; the single heaviest-weighted criterion in ACMG/AMP variant classification.（中文：PVS1（ACMG/AMP证据标准），专门适用于功能缺失变异的"极强"级别致病性证据代码，是ACMG/AMP变异分类体系中权重最高的单一标准。）
  • Repeat-region notation hierarchy — the HGVS-recommended priority order (substitution, deletion, inversion, duplication, insertion) used by normalization tools to describe a variant in a repetitive sequence stretch, which does not always match ClinVar's own repeat-unit-counting convention.（中文：重复区域记法优先级，归一化工具用于描述重复序列区域变异时所遵循的HGVS推荐优先顺序（替换、缺失、倒位、重复、插入），该顺序并不总是与ClinVar自身的重复单元计数惯例一致。）

Methods / tools to lift

  • ANNOVAR / SnpEff / VEP three-way comparison design — running the same variant set through all three major annotators and diffing both the HGVS string and the SO-normalized coding-impact call, rather than trusting any single tool's output.
  • MANE-restricted transcript scoping — restricting cross-tool comparison to MANE Select/Plus Clinical transcripts specifically, which closed most (not all) of the concordance gap in this study.
  • VariantValidator / Mutalyzer HGVS normalization — free, scriptable tools for validating and normalizing a variant string against current HGVS recommendations, including repeat-region notation.
  • ACMG reclassification on the discordant subset — rather than stopping at "tools disagree," the authors re-ran full ACMG criteria specifically on the PVS1-discrepant variants to quantify real classification impact.

Where it lands + buildable artifact

Serves Karen Raraigh / CFTR variant interpretation and harmonization directly — CFTR notation has to match across CFTR2, ClinVar, CFTR-France, and gnomAD, and CFTR's poly-T/TG repeat tract sits in the paper's flagged repeat-notation trouble spot. Buildable: a cross-tool HGVS/coding-impact reconciliation check for CFTR variants, restricted to MANE Select/Plus Clinical transcripts, flagging only discordances that would change a PVS1-relevant category (see picks.json for the full MVP). What to verify first

  • Which exact MANE release CFTR2 and ClinVar's own records are effectively aligned to, since a version mismatch between reference sources could reproduce this paper's discordance one layer upstream.
  • Whether the LoF/PVS1 mismatch rate is any better or worse for CFTR specifically than the ClinVar-wide average reported here, given CFTR's structural and splice-variant composition.
  • Whether VariantValidator's and Mutalyzer's repeat-notation priority hierarchy actually lines up with how CFTR2 currently represents the poly-T/TG tract alleles.
