Ep3 — A critical assessment of ChatGPT for structured extraction from clinical notes

Huang, Yang, Rong, and colleagues (NPJ Digital Medicine, 2024) evaluate ChatGPT-3.5 (gpt-3.5-turbo-16k) on extracting TNM stage and histological diagnosis from 774 real TCGA lung-cancer pathology reports, scored field-by-field against expert-curated ground truth. Overall accuracy was 89% (per-attribute: pT 87%, pN 91%, overall stage 76%, histology 99%), with coverage rates of 94-97%. The paper's real contribution is the error analysis: most pT misclassifications (T1-as-T2, 8.9% of cases) traced to the model applying an outdated/incorrect AJCC staging-edition cutoff to a correctly-extracted tumor-size value — a domain-rule error, not a data-extraction error — while a genuine hallucination problem showed up on blank/near-blank reports (only 5/15 correctly returned "unknown"). Reproducibility across a six-week gap was 91.3%. This is an LLM-assisted-curation paper (Track C priority category 5); the pipeline-stage fit is adjudication support (pulling structured context from a free-text note tied to a flagged case), not candidate generation, and its 76%-weakest-category number is the reason any such use needs per-field accuracy reporting, not a single aggregate.

Plain-English glossary

  • TNM staging — The standard cancer-staging system: T (primary tumor size/local spread), N (regional lymph node involvement), M (distant metastasis).（中文：标准的癌症分期体系：T（原发肿瘤大小/局部扩散）、N（区域淋巴结受累）、M（远处转移）。）
  • Prompt engineering — Iteratively refining the instructions given to an LLM until outputs stabilize into a consistent, parseable format, without updating model weights.（中文：反复打磨给LLM的指令，直到输出稳定成一致、可解析的格式，不涉及更新模型权重。）
  • Expert-curated ground truth — Structured data already extracted/logged by a trained human abstractor, used as the scoring reference.（中文：由受过训练的人工摘录员已经提取并记录的结构化数据，用作打分的参照标准。）
  • Coverage rate — The fraction of documents for which the model returns a usable value rather than "unknown"/empty.（中文：模型实际返回可用数值而非"未知"/空值的文档比例。）
  • Hallucination — An LLM producing a confident, fluent, but fabricated or unsupported output.（中文：LLM生成一个听起来自信、流畅，但却是虚构或没有依据的输出。）
  • AJCC staging edition — Versioned clinical staging-rule sets from the American Joint Committee on Cancer; cutoffs for a given T/N/M category can shift between editions.（中文：美国癌症联合委员会发布的、有版本号的临床分期规则集；不同版本之间T/N/M各分类的临界值可能发生变化。）

Methods / tools to lift

  • Field-by-field exact-match scoring against expert-curated ground truth — the accuracy/F1/coverage-rate reporting template.
  • Explicit "unknown" instruction + coverage-rate metric — separates "model answered wrong" from "model declined to answer."
  • Reproducibility check (identical run, ~6 weeks apart) — a directly reusable pattern for testing any LLM-based extraction tool's temporal drift.
  • Case-level error analysis distinguishing data-extraction errors from domain-rule errors — a diagnostic lens for any structured-extraction failure.

Where it lands + buildable artifact

Serves Liz / CFFPR data quality (method only). Pipeline stage: (b) adjudication — pulling structured context (e.g., mentions of a cast, edema, amputation, unit ambiguity) out of a free-text clinical note tied to an already-flagged case, not generating the flag itself. Buildable: llm-note-context-extractor (M) — a small local pipeline (same in-context-learning pattern as LLM-AIx, ep2) that extracts a defined set of context fields from a free-text note with an explicit "unknown" option and coverage-rate report, tested on a hand-labeled sample first.

What to verify first

  • Whether the accuracy pattern holds on a genuinely different note type/vocabulary than lung-cancer pathology reports.
  • Whether newer models than gpt-3.5-turbo-16k meaningfully close the overall-stage and hallucination gaps.
  • What hand-labeled validation sample size would be needed before trusting any deployment, given the 76%-vs-99% spread across categories.

Pipeline stage

(b) Adjudication support — pulls structured context from a free-text note for an already-flagged case; not a candidate-generation method.

Error types covered / not covered

Covered: domain-rule misapplication (e.g., wrong staging-edition cutoff applied to a correctly-extracted value); hallucination/fabrication on blank or sparse inputs. Not covered/not applicable to anthropometric data directly: unit conversion, digit transposition, decimal shift, or carry-forward errors specific to height/weight values — this paper's error taxonomy is oncology-staging-specific and would need its own validation on anthropometric note text.

ALEX Today's paper is "A critical assessment of using ChatGPT for extracting structured data from clinical notes," by Huang, Yang, Rong, and colleagues, published in NPJ Digital Medicine in 2024. 今天的论文是Huang、Yang、Rong等作者发表在《NPJ Digital Medicine》上的《对使用ChatGPT从临床笔记中提取结构化数据的批判性评估》，2024年发表。 It's the first of two Track C picks today — registry data quality — and it sits in the LLM-assisted curation bucket: can a general-purpose language model reliably turn free-text pathology notes into the structured fields a registry or a downstream statistical model actually needs, without task-specific training. 这是今天两个C赛道选题中的第一个——登记数据库数据质量——它属于LLM辅助整理这一类：一个通用的语言模型，能否在不需要针对具体任务训练的情况下，可靠地把自由文本病理笔记转换成登记数据库或下游统计模型真正需要的结构化字段。 The test case is lung cancer pathology reports, pulling out TNM staging and histological diagnosis, plus a smaller pediatric osteosarcoma validation set — not anthropometric data directly, but the error-taxonomy and evaluation design transfer directly to any free-text-to-structured-field extraction problem in a registry. 测试用例是肺癌病理报告，提取TNM分期和组织学诊断，外加一个更小的儿童骨肉瘤验证集——虽然不是直接的人体测量数据，但它的错误分类体系和评估设计，可以直接迁移到登记数据库中任何"自由文本转结构化字段"的提取问题上。

JORDAN Before results — what's the actual workflow here, prompt engineering and all, and what do 'coverage rate' and 'expert-curated ground truth' mean in this context? 在讲结果之前——这里的实际工作流程是怎样的，包括提示工程（prompt engineering）？"coverage rate"（覆盖率）和"专家整理的真值"（expert-curated ground truth）在这里又是什么意思？

ALEX Prompt engineering here means iteratively refining the instructions given to ChatGPT — what fields to extract, how to handle missing information, which staging edition to follow — until its outputs stabilize into a consistent, parseable format; it's not model training, it's instruction design. 这里的提示工程指的是反复打磨给ChatGPT的指令——要提取哪些字段、如何处理缺失信息、遵循哪个分期版本——直到它的输出稳定成一致、可解析的格式；这不是模型训练，而是指令设计。 Expert-curated ground truth is the structured data a human abstractor, someone trained to read the same pathology reports, already extracted and logged, and it's what ChatGPT's output gets scored against field by field. 专家整理的真值，是指一位受过训练、能读懂同样病理报告的人工摘录员，已经提取并记录下来的结构化数据，ChatGPT的输出会逐字段地与这份真值进行打分比对。 Coverage rate is a metric specific to this kind of LLM extraction task: the fraction of reports where the model actually returned a usable value for a field, as opposed to an 'unknown' or empty response — a model can have perfect accuracy on the reports it answers and still be practically useless if its coverage rate is low, because someone still has to manually handle every report it declined to answer. 覆盖率是这类LLM提取任务特有的一个指标：模型对某个字段实际返回了可用数值的报告比例，而不是返回"未知"或空值——一个模型即使在它给出答案的报告上准确率完美，如果覆盖率很低，实际用处仍然有限，因为它拒绝作答的每一份报告，仍然需要人工处理。

JORDAN What was actually unresolved before this study? 在这项研究之前，实际上有哪些悬而未决的问题？

ALEX Traditional medical NLP for structured-data extraction relies on rule-based systems or supervised deep learning, typically transformer models like BERT, and both approaches need a substantial human-annotated training corpus built fresh for every new extraction task — a lung-cancer staging extractor doesn't transfer to a breast-cancer or registry extraction task without redoing that annotation work. 传统用于结构化数据提取的医学NLP，依赖基于规则的系统或有监督深度学习，通常是像BERT这样的Transformer模型，这两种方法都需要为每一个新的提取任务重新构建一个规模可观的人工标注训练语料——一个肺癌分期提取器，不会自动迁移到乳腺癌或登记数据库的提取任务上，除非重新做一遍标注工作。 ChatGPT and similarly general-purpose LLMs offer a different bet: broad pretraining might supply enough general medical and commonsense reasoning that a well-designed prompt, not a retrained model, is enough to extract structured fields from a report the model has never specifically been trained on. ChatGPT以及类似的通用LLM提供了一种不同的赌注：广泛的预训练或许已经赋予了模型足够的通用医学知识和常识推理能力，只需要一个设计良好的提示，而不是重新训练一个模型，就足以从一份模型从未专门训练过的报告中提取结构化字段。 That's plausible but untested at any real scale before this paper, and it's exactly the question a registry team weighing whether to trust an LLM for chart abstraction needs answered with real error analysis, not just a headline accuracy number. 这个想法听起来合理，但在这篇论文之前，还没有在真实规模下被验证过，而这正是任何一个正在权衡"是否该信任LLM来做病历摘录"的登记数据库团队，需要用真实的错误分析（而不仅仅是一个头条准确率数字）来回答的问题。

ALEX So the study's actual purpose isn't just 'does ChatGPT get the right answer' — it's a critical assessment, meaning they specifically went looking for where and why it fails: hallucination on blank or noisy inputs, reproducibility across model versions over time, and misclassification patterns tied to specific staging rules rather than just an aggregate error rate. 所以这项研究的真正目的不只是"ChatGPT答对了没有"——而是一次批判性评估，也就是说他们专门去寻找模型在哪里失败、为什么失败：对空白或噪声输入的幻觉（hallucination）反应、模型版本随时间变化时的可复现性，以及与具体分期规则相关的误分类模式，而不只是一个聚合错误率。

JORDAN What's the actual setup — data and decision rule? 实际的设置是怎样的——数据和判定规则？

ALEX They pulled 1,026 lung cancer pathology reports from two public repositories, the Cancer Digital Slide Archive and TCGA via cBioPortal, with 774 forming the primary TCGA test set. Using ChatGPT-3.5, specifically gpt-3.5-turbo-16k, and a standard prompt walking through the TNM staging rules field by field, they extracted primary tumor stage, regional lymph node involvement, overall tumor stage, and histological diagnosis, then compared each extracted value against the expert-curated structured data field by field. 他们从两个公开数据库获取了1,026份肺癌病理报告——Cancer Digital Slide Archive和通过cBioPortal获取的TCGA数据——其中774份构成了主要的TCGA测试集。使用ChatGPT-3.5（具体是gpt-3.5-turbo-16k模型）和一个逐字段讲解TNM分期规则的标准提示，他们提取了原发肿瘤分期、区域淋巴结受累情况、总体肿瘤分期，以及组织学诊断，然后将每个提取值与专家整理的结构化数据逐字段比对。 When the model couldn't determine a value, it was instructed to return 'unknown' rather than guess, which is what feeds the coverage-rate metric. 当模型无法确定某个数值时，会被指示返回"未知"而不是猜测，这正是覆盖率指标的来源。

ALEX They also ran a second, smaller validation set of pediatric osteosarcoma reports to check whether the approach generalized beyond lung cancer, and a reproducibility check: running the identical model version, data, prompt, and temperature setting twice, about six weeks apart, to see how stable the outputs were over time. 他们还使用了第二个更小的儿童骨肉瘤报告验证集，来检验这种方法是否能推广到肺癌以外的场景，并做了一次可复现性检验：用完全相同的模型版本、数据、提示和温度设置，间隔约六周运行两次，观察输出结果随时间的稳定性。

JORDAN Where would you push back on that design? 你会在这个设计里对哪里提出质疑？

ALEX The decision rule for what counts as a correct extraction is entirely field-by-field exact match against the curated ground truth, which is the right instinct for a structured field, but it means a near-miss, like extracting the correct tumor size but applying the wrong staging-edition cutoff, gets scored identically to a wildly wrong answer, even though the paper's own error analysis later shows those two failure modes need very different fixes — one is a data-extraction problem, the other is a domain-rule problem baked into the prompt. 判断一次提取是否正确的规则，完全是逐字段与整理好的真值做精确匹配，这个直觉是对的，但这意味着一次"接近但错误"的结果——比如提取出了正确的肿瘤大小，却套用了错误的分期版本临界值——会和一个离谱的错误答案被同等计分，尽管论文自己后续的错误分析表明，这两种失败模式需要非常不同的修复方式——一个是数据提取问题，另一个是嵌入提示中的领域规则问题。

JORDAN So how did it actually perform, and how was ground truth obtained? 那它实际表现如何？真值又是怎么获得的？

ALEX On the 774-report TCGA test set, overall average accuracy across all four attributes was 89%, with per-attribute accuracy of 87% for primary tumor stage, 91% for lymph node involvement, 76% for overall tumor stage, and 99% for histological diagnosis — and coverage rates, the fraction of reports the model actually answered rather than returning unknown, ranged from 94% to 97%. 在774份报告构成的TCGA测试集上，四个属性的总体平均准确率为89%，各属性准确率分别为：原发肿瘤分期87%，淋巴结受累91%，总体肿瘤分期76%，组织学诊断99%——覆盖率，也就是模型实际给出答案而非返回"未知"的报告比例，在94%到97%之间。 On the separate pediatric osteosarcoma dataset, it did even better on the two attributes tested there, 98.6% accuracy for tumor grade and 100% for margin status. 在另一个独立的儿童骨肉瘤数据集上，模型在测试的两个属性上表现更好，肿瘤分级准确率98.6%，切缘状态准确率100%。

ALEX Ground truth throughout came from expert-curated structured data already published alongside the TCGA and CDSA datasets — not a freshly-adjudicated human review specific to this study, which matters for the study but is a limitation the paper is upfront about. 整个研究中的真值，都来自与TCGA和CDSA数据集一同发布的、已有的专家整理结构化数据——而不是为这项研究专门新做的人工审核，这一点对研究本身很重要，论文对这个局限性也是坦诚的。 The overall tumor stage number, 76%, is notably the weakest, and the error analysis explains why: 12.6% of primary-tumor-stage cases were misclassified, and the majority of those, 67 of 753 valid cases, were T1 wrongly called T2 — the model correctly extracted the raw tumor size measurement but applied an outdated or incorrect AJCC staging-edition cutoff to convert that size into a category, a domain-rule error rather than a data-extraction error. 总体肿瘤分期的76%明显是最弱的一项，错误分析解释了原因：12.6%的原发肿瘤分期病例被误分类，其中大多数——753个有效病例中的67个——是把T1错判成了T2——模型正确提取出了原始的肿瘤大小测量值，但在把这个大小换算成分期类别时，套用了过时或错误的AJCC分期版本临界值，这是一个领域规则错误，而不是数据提取错误。

ALEX There's also a real hallucination problem: on blank or nearly-blank reports, at temperature zero, the model didn't reliably return 'unknown' as instructed — among 15 missing report forms in the smaller dataset, it responded 'unknown' as expected in only 5 cases, converging to a consistent but fabricated response the other 10 times. 另外还存在一个真实的幻觉问题：对于空白或接近空白的报告，即使温度设为零，模型也没有像预期的那样可靠地返回"未知"——在较小数据集中的15份缺失报告表单里，模型只有5次按预期返回了"未知"，另外10次则收敛到了一个一致但被虚构出来的答案。 Reproducibility across the two runs six weeks apart was 91.3% equivalence on key attributes, better than nothing but a real drift number to plan around, not zero. 间隔六周的两次运行之间，关键属性的可复现性为91.3%的一致率，虽然聊胜于无，但这是一个需要纳入规划的真实漂移数字，而不是零。

JORDAN One more results detail before we move on — what did the error analysis find for the N-stage and M-stage categories specifically, beyond the T-stage story? 在往下讲之前，再问一个结果上的细节——除了T分期这个故事以外，错误分析对N分期和M分期具体发现了什么？

ALEX The paper's deepest error-analysis narrative is built around T-stage because it's the biggest single failure mode, but the general pattern holds across categories: most misclassifications trace back to the model applying an incorrect or outdated staging rule to a correctly-extracted raw value, rather than misreading the underlying clinical fact in the report itself. 论文最深入的错误分析叙述是围绕T分期展开的，因为它是最大的单一失败模式，但这个总体模式在各类别中都成立：大多数误分类的根源，是模型对一个正确提取出的原始数值套用了不正确或过时的分期规则，而不是错误地读取了报告本身记载的临床事实。 That's a meaningfully different failure mode than the pure hallucination problem seen on blank reports, and it means the fix isn't necessarily a better model, it can be a more precise prompt that pins down exactly which staging-edition rule to apply, which is a cheap, testable intervention compared with swapping in a larger or newer model. 这与在空白报告上看到的纯粹幻觉问题，是本质上不同的失败模式，这意味着修复方法不一定是换一个更好的模型，也可以是一个更精确的提示，明确锁定应该套用哪一版分期规则，相比换用一个更大或更新的模型，这是一种低成本、可测试的干预手段。

JORDAN Does this change the CFFPR outlier pipeline — which of the five applies? 这会改变CFFPR的异常值检测流程吗——五种可能性里哪一种适用？

ALEX This is (b), adjudication — not a candidate generator for flagging implausible height or weight values, but a possible tool for the separate step of resolving a flagged case once it's already been surfaced, specifically by pulling structured context out of a free-text clinical note tied to that encounter, when one exists. 这属于(b)裁定环节——不是用来生成候选异常标记的方法，不直接判断某个身高或体重数值是否不可信，而是在某个案例已经被标记出来之后，用于解决它的独立环节里可能派上用场的工具，具体来说，是从与该次就诊相关的自由文本临床笔记中（如果存在的话）提取出结构化的上下文信息。 If an implausible-value flag needs a human to check whether the note documents something like a cast, edema, an amputation, or a unit-conversion mention before deciding it's real versus a data-entry error, an LLM-extraction step could pre-populate that context rather than requiring the reviewer to read the full note from scratch. 如果一个不可信数值的标记，需要人工去检查笔记里是否记录了诸如石膏固定、水肿、截肢，或者单位换算之类的信息，才能判断这是真实情况还是数据录入错误，那么一个LLM提取步骤就可以预先填充这些上下文，而不需要审核者从头通读整份笔记。

ALEX The catch is everything from the results section about the weakest category, overall-stage accuracy at 76%, plus the hallucination problem on blank inputs — an adjudication-support tool that occasionally fabricates a confident-sounding but wrong answer on a sparse note is worse than no tool at all if the reviewer starts trusting it without spot-checking, so any use here would need the same coverage-rate and per-field accuracy reporting this paper does, not just a single overall number. 问题在于结果部分提到的所有细节——最弱类别（总体分期）的准确率只有76%，加上对空白输入的幻觉问题——一个偶尔会对稀疏笔记给出听起来自信却错误答案的裁定辅助工具，如果审核者开始不加抽查地信任它，反而比完全没有工具更糟糕，所以在这里的任何应用，都需要像这篇论文一样报告覆盖率和逐字段准确率，而不只是一个总体数字。 Buildable artifact: llm-note-context-extractor (M) — a small local pipeline, following the same in-context-learning-not-fine-tuning pattern as yesterday's LLM-AIx pick, that takes a free-text clinical note plus a defined list of context fields relevant to an anthropometric flag, cast, edema, recent surgery, unit ambiguity, and returns a structured extraction with an explicit unknown option and a coverage-rate report, tested first against a small hand-labeled sample before ever touching a real adjudication queue. 可构建的产物：llm-note-context-extractor（中等难度）——一个小型本地流水线，沿用昨天LLM-AIx那一集同样的"上下文学习而非微调"模式，输入是一段自由文本临床笔记，加上一份与人体测量异常标记相关的上下文字段清单——石膏固定、水肿、近期手术、单位歧义——输出一个带有明确"未知"选项和覆盖率报告的结构化提取结果，在真正接触任何真实的裁定队列之前，先在一个小型人工标注样本上做测试。

JORDAN What would we check before trusting this? 在信任这一点之前，我们需要核实什么？

ALEX First, whether the same accuracy pattern holds on a completely different note type and vocabulary than lung-cancer pathology reports — nothing here directly transfers to anthropometric or growth-related clinical notes without its own validation. 第一，同样的准确率模式，在与肺癌病理报告完全不同的笔记类型和词汇体系上是否依然成立——这里的任何结果，在没有经过自己的验证之前，都不能直接迁移到人体测量或生长相关的临床笔记上。 Second, whether newer models than gpt-3.5-turbo-16k meaningfully close the overall-stage and hallucination gaps, since this paper is already over a year old in a fast-moving field. 第二，比gpt-3.5-turbo-16k更新的模型，是否能显著缩小总体分期和幻觉问题上的差距，毕竟这篇论文在这个快速发展的领域里已经算是一年多以前的了。 Third, what a realistic hand-labeled validation sample size would need to be before trusting any deployment, given the 76%-versus-99% spread this paper shows across categories in the same task. None of this is a decision about how any current adjudication process actually works — just a question list. 第三，考虑到这篇论文在同一任务中不同类别之间76%到99%的巨大差异，在信任任何部署之前，一个现实可行的人工标注验证样本量需要多大。这些都不是关于任何现有裁定流程实际如何运作的判断——只是一份问题清单。
