Ep4 — Track C (2/2): A longitudinal analysis of data quality in a large pediatric data research network (PEDSnet)

Paper: Khare R, Utidjian L, Ruth BJ, Kahn MG, Burrows E, Marsolo K, Patibandla N, Razzaghi H, Colvin R, Ranade D, Kitzmiller M, Eckrich D, Bailey LC. "A longitudinal analysis of data quality in a large pediatric data research network." JAMIA. 2017. Abstract-only — full text was not retrievable through Europe PMC's open-access routes (fullTextXML 404; PMC-OA BioC mirror returned no result for PMC6259665).

PEDSnet is a pediatric clinical data research network (CDRN) aggregating EHR data from multiple children's hospitals into a shared common data model. This paper — co-authored by Michael Kahn, the Kahn of the Kahn data quality assessment framework — tracks 2182 data quality issues identified over 18 months and nine submission cycles via a semiautomated workflow: programmatic checks flag candidates, then two human investigators adjudicate each one by talking with the originating site's own ETL analysts. In the most recent cycle (850 annotated issues), missing data (>300) dominated over outliers (>100); medications (>160) and lab measurements (>140) were the most complex domains; 83% of issues traced to source data characteristics versus only 9% to ETL pipeline errors. The core transferable idea isn't a detection algorithm — it's the human-in-the-loop adjudication structure that resolves a flag into entry error, real clinical event, or pipeline artifact. Pairs naturally with yesterday's dataquieR paper: dataquieR-style rules generate candidates, PEDSnet-style adjudication resolves them, and Kahn's conformance/completeness/plausibility vocabulary names the problem types both touch.

Plain-English glossary

  • CDRN (clinical data research network) — A federated structure where multiple institutions each extract their own EHR data into a shared common data model so researchers can query across sites without centralizing raw records.（中文:临床数据研究网络,一种联合式结构,多家机构各自将自己的电子健康记录数据提取到共享的通用数据模型中,使研究者能够跨机构查询,而不必将原始记录集中存放。）
  • Conformance — In Kahn's framework, whether data values adhere to expected formats, data types, and relationships.（中文:符合性,在Kahn的框架中,指数据值是否遵循预期的格式、数据类型和关系。）
  • ETL (extract, transform, load) — The pipeline that pulls data out of a hospital's own EHR and reshapes it into a shared network data model.（中文:ETL〔提取、转换、加载〕,将数据从医院自己的电子健康记录中取出、并重塑成网络共享数据模型的流程。）
  • PCORnet — The national Patient-Centered Outcomes Research Network; PEDSnet is one of its pediatric member networks.（中文:PCORnet,全国以患者为中心的结局研究网络;PEDSnet是其儿科成员网络之一。）
  • Plausibility — In Kahn's framework, whether a value is believable given context, independent of whether it passes basic format checks.（中文:合理性,在Kahn的框架中,指一个值在给定情境下是否可信,与它是否通过基本格式检查无关。）

Buildable artifact: a lightweight adjudication-logging tool — a structured intake form/tracker for records a statistical model already flagged, capturing the three-way disposition (entry error, real event, pipeline artifact), evidence consulted, and final call, cycle over cycle.
