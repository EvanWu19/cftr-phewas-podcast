Ep4 (Track C — registry QC, 2 of 2): A flag is not a verdict

Gray and Robinson (2014, Epidemiology) test a common but largely unexamined QC reflex — excluding "shrinkers" (adolescents whose recorded height apparently decreased between visits) from analysis — against a self-constructed gold standard, using Add Health data from 816 female respondents whose adult height stability lets wave 3 and wave 4 measurements serve as ground truth. Excluding shrinkers (368 of 816, ~45%, by this definition) reduced precision by an order of magnitude compared to retaining them, and for the key regression outcome (maternal education's association with adolescent obesity), it also increased bias: the gold-standard odds ratio of 2.21 dropped to a non-significant 1.16 after exclusion, versus 1.91 when shrinkers were simply retained — a result that would have led researchers to wrongly conclude no association exists. The authors attribute this to selective exclusion from only one tail of a broader, only-partially-observable error distribution. The paper's real contribution is an evaluation methodology — constructing an internal gold standard from a cohort's own longitudinal stability rather than needing external ground truth — with a direct, cautionary bearing on any blanket "exclude flagged records" default. Buildable artifact: an Exclude-vs-Retain-vs-Substitute Bias/Precision Simulator.

Plain-English glossary

  • CDC 2000 growth chart (BMI percentile) — the US pediatric reference chart used to define obesity as BMI at or above the age- and sex-specific 95th percentile, the same reference-population-percentile logic as a WHO z-score, on a different underlying chart.（中文：美国儿科参照生长图表，用于将肥胖定义为BMI达到或高于按年龄和性别划分的第95百分位，其逻辑与WHO z分数的"相对参照人群百分位"逻辑相同，只是基于不同的底层图表。）
  • Gold-standard height (constructed) — a ground-truth height value established, for this study, by requiring a respondent's measured height to be consistent (within 0.5 inch) across two later survey waves, exploiting the fact that most girls reach adult height by 17.（中文：本研究构建的真值身高，通过要求受访者的测量身高在两个较晚的调查波次之间保持一致（误差在0.5英寸以内）来确立，依据的是大多数女孩在17岁时已达到成年身高这一事实。）
  • National Longitudinal Study of Adolescent Health (Add Health) — a large, multi-wave US cohort study that followed adolescents from the mid-1990s into adulthood, with height and weight both self-reported and separately measured at several waves.（中文：一项大型、多波次的美国队列研究，追踪青少年从上世纪90年代中期到成年期的发展情况，身高体重既有自我报告也有多波次的单独测量。）
  • Shrinker — a respondent whose height recorded at an earlier visit is greater than their later, more reliably established height; since true height loss doesn't occur during adolescent growth, this is a flag of measurement error rather than a real biological event.（中文：某受访者较早一次就诊记录的身高，大于其后来更可靠确立的身高；由于真实的身高下降不会发生在青春期生长阶段，这是测量误差的标记，而非真实的生物学事件。）

Full citation

Methods / tools to lift

  • Longitudinal-stability-constructed gold standard — using within-person measurement consistency across two later waves to establish ground truth internally, without an external validation dataset.
  • Three-condition comparison (gold standard / exclude / retain) — a reusable template for testing any flagged-value handling policy's bias and precision consequences side by side.
  • Bootstrapped uncertainty estimation (2,000 replications) — quantifying the precision of each condition's estimates for direct comparison.

Where it lands + buildable artifact

Pipeline stage: (d) evaluation, primary — the longitudinal-stability-constructed gold standard is a reusable way to measure a handling policy's bias/precision consequences without needing an external ground-truth dataset. (c) review budget / handling policy, secondary — a direct caution against a blanket "exclude anything flagged" default for the vast majority of flagged records that never receive individual human adjudication. Buildable artifact: an Exclude-vs-Retain-vs-Substitute Bias/Precision Simulator — run all three handling strategies against a chosen downstream analysis and report bias-versus-truth and precision side by side before committing to a default policy.

Error types covered / not covered: Covers one specific manifestation of measurement error — apparent height "shrinkage," i.e., a recorded decrease where none is biologically plausible. Does not cover the opposite-direction error (implausible excess growth) empirically, though the discussion explicitly names it as present in the same data; does not cover unit conversion, digit transposition, decimal shift, or carry-forward as distinct mechanisms, nor does it attempt to distinguish measurement error from a genuine clinical event, since "shrinkage" in growing adolescents is treated as definitionally implausible either way.

What to verify first

  • Whether the same bias/precision tradeoff holds for a different variable (e.g., weight), a different error direction, or a different population and age range — this result is specific to adolescent height shrinkage in older females.
  • Whether the "height stability by 17" assumption underlying the gold standard holds uniformly across individuals, or whether residual within-tolerance variation at waves 3/4 is silently folded into "truth."
  • Whether a similar bias/precision tradeoff would hold for a registry with its own specific mix of populations, visit patterns, and error types — this would need its own simulation exercise, not an assumption carried over from this study.
  • That "retaining flagged values improved both bias and precision here" is read as a caution against reflexive exclusion, not as a general rule that excluding flagged values is never correct.
