How did this episode land for you?

Blurb

A 2026 Nature Communications methods paper systematically compares two major sources of variant-interpretation evidence — multiplexed assays of variant effect (MAVEs) and computational variant effect predictors (VEPs) — across 99 MAVE score sets spanning 40 human proteins and 10 top-performing VEPs. The headline finding: VEPs correlate strongly with each other (mean Spearman ρ=0.84) but only weakly with MAVE measurements (ρ=0.43), and the disagreement is not random — it tracks evolutionary conservation (the strongest driver, correlations approaching −0.7), solvent accessibility, and intrinsic disorder in consistent, explainable directions. Five clinical case studies (BRCA1, SNCA, MSH2, MTHFR, CARD11) show concrete mechanisms behind specific discordant calls, including a splice-site effect neither standard VEPs nor non-SGE MAVEs caught, and a ClinVar classification that turns out to be circular with the very MAVE study being evaluated against it. It lands on Karen's variant-interpretation priority: the buildable artifact is a CFTR VEP-MAVE discordance triager that flags disagreements with a likely-cause tag for human review.

Plain-English Glossary

  • ACMG/AMP evidence tiers — The standard framework for weighing different types of evidence (computational, functional, population, clinical) toward a five-level pathogenicity classification.（中文:用于综合不同类型证据——计算、功能、人群、临床等——以得出五级致病性分类的标准评估框架。）
  • AlphaFold — A deep-learning system that predicts 3D protein structure from amino acid sequence, used here to derive solvent-accessibility annotations.（中文:一种基于深度学习、从氨基酸序列预测蛋白质三维结构的系统,本文用它来推算溶剂可及性注释。）
  • ClinVar — A public database of clinically-submitted variant classifications (pathogenic, benign, VUS, etc.) with supporting evidence and review-status stars.（中文:一个公开的变异临床分类数据库,记录致病、良性、意义不明等分类及其支持证据和审核星级。）
  • Data circularity — When a predictor's training data overlaps with the data used to evaluate it, inflating its apparent performance.（中文:指预测模型的训练数据与评估数据存在重叠,从而人为抬高其表观性能的问题。）
  • Intrinsically disordered region (IDR) — A stretch of a protein with no fixed 3D structure; poorly captured by conservation-based methods and a known blind spot for VEPs.（中文:蛋白质中没有固定三维结构的区段,基于保守性的方法难以很好覆盖,是VEP已知的一个盲区。）
  • Multiplexed assay of variant effect (MAVE) — A pooled, high-throughput wet-lab experiment that measures a functional readout (growth, stability, binding, etc.) for thousands of variants of one gene simultaneously.（中文:一种混合、高通量的湿实验,一次性为某基因的数千个变异测量某项功能读数,如生长、稳定性或结合活性。）
  • Protein language model (PLM) — A deep-learning model trained on protein sequences (analogous to a text language model) used by several of the population-free VEPs in this study, e.g., ESM-1v.（中文:一种基于蛋白质序列训练的深度学习模型,类似于文本语言模型,本文中部分"无人群数据型"VEP,如ESM-1v,采用了这种方法。）
  • Relative solvent accessibility (RSA) — A measure of how exposed a residue is to solvent versus buried in the protein interior; a key driver of MAVE-VEP discordance.（中文:衡量某个残基暴露于溶剂的程度,还是被埋藏在蛋白质内部的指标,是MAVE与VEP产生分歧的关键因素之一。）
  • Saturation genome editing (SGE) — A MAVE technique that engineers variants directly into their native genomic locus in a human cell line, preserving native splicing and regulatory context that plasmid-overexpression MAVEs lose.（中文:一种MAVE技术,直接在人类细胞系的原生基因组位点上引入变异,从而保留质粒过表达类MAVE会丢失的天然剪接和调控背景。）
  • Variant effect predictor (VEP, in this paper's sense) — A computational model that scores a variant's likely functional/clinical impact from features like conservation, structure, and physicochemical properties, without wet-lab data. Not to be confused with Ensembl's VEP annotation tool.（中文:一种计算模型,利用保守性、结构和理化性质等特征对变异的功能/临床影响打分,无需湿实验数据,不要与Ensembl的VEP注释工具混淆,两者恰好同名。）
  • Variant of uncertain significance (VUS) — A variant for which there is not yet enough evidence to classify as pathogenic or benign.（中文:目前尚无足够证据判定为致病或良性的变异。）
  • Z-score normalization — Converting each MAVE or VEP score set to a common standardized scale so scores from different sources can be directly subtracted and compared.（中文:将每个MAVE或VEP评分集转换为统一的标准化量纲,使不同来源的评分可以直接相减比较。）

Methods / Tools to Lift

  • Z-score normalization + directional alignment to a reference predictor (SIFT) — a simple, reusable recipe for putting any MAVE and VEP score set onto one comparable scale before cross-analysis.
  • Residue-level annotation cross-referencing (RSA, AIUPred disorder, MSA-based conservation, InterPro domains) — the toolkit used to explain where and why discordance concentrates, directly reusable for any gene with both MAVE and VEP coverage.
  • Clinical-trained vs. population-free VEP stratification — a practical way to avoid data-circularity when benchmarking predictors against ClinVar/gnomAD-derived labels.

Where It Lands + Buildable Artifact

Serves Karen / CFTR variant interpretation. Buildable artifact: a CFTR VEP-MAVE Discordance Triager — pull AlphaMissense/REVEL/CADD scores plus any MaveDB entry for CFTR, z-score normalize both sides, overlay per-residue conservation/RSA/disorder annotations, and output a flagged table tagging each discordant variant with a likely-cause label (splice-proximity, surface-exposed, disordered-region, gain-of-function-artifact) for human triage. Input: CFTR variant list (HGVS) + available MAVE/VEP score exports. Difficulty: M.

What to Verify First

  • Whether a MAVE dataset with adequate coverage actually exists for CFTR — much of the proteome, plausibly including CFTR, has no MAVE yet under the Atlas of Variant Effects Alliance's still-incomplete coverage.
  • Whether any ClinVar label used as a reference point was itself supported by the same MAVE being evaluated against it (the MSH2 S612P circularity pattern).
  • Whether inter-VEP agreement is being mistaken for accuracy — the authors' own prior work found little relationship between VEP-VEP consensus and agreement with experimental data.
  • Whether a gain-of-function mechanism could explain an apparent MAVE-VEP "disagreement" before treating it as a real discordance (the CARD11 C49Y pattern).

ALEX A variant effect predictor, or VEP in this paper's sense — not to be confused with Ensembl's VEP annotation tool, which is a different, unrelated use of the same acronym — is a computational model that scores a variant's likely impact using features like evolutionary conservation across species, protein structure, and physicochemical properties, without running any wet-lab experiment at all. 而这篇论文里说的变异效应预测器(variant effect predictor,也缩写为VEP——注意不要和Ensembl的VEP注释工具混淆,那是同一缩写的另一个不相关用法)则是一种计算模型,它利用跨物种进化保守性、蛋白质结构和理化性质等特征对变异的可能影响打分,完全不需要进行任何湿实验。

ALEX To make MAVE and VEP scores comparable at all, since they live on completely different scales, the authors converted every score set into z-scores, oriented so that higher always means more damaging, and then they can simply subtract one z-score set from another to get a discordance score for every variant. 为了让MAVE和VEP的评分可以直接比较,因为它们本来处在完全不同的量纲上,作者把每个评分集都转换成了z分数,并统一方向,使得分值越高代表越有害,这样就可以直接用一个z分数集减去另一个,得到每个变异的不一致性(discordance)评分。
