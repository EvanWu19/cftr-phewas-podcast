B1 cftr-varqc — Reproducible Pipeline ▶

An nf-core-style Nextflow workflow that packages the A1 + A2 analysis logic into portable, containerised, CI-tested infrastructure. It takes a VCF of CFTR variants, normalises them to HGVS (MANE NM_000492.4), joins precomputed effect-prediction scores, cross-checks against CFTR2 + ClinVar, and emits a MultiQC-style HTML report plus the discordance worklists.

✓ 6/6 processes succeeded 0 failed 5 local modules CI stub-run green on every push

Pipeline DAG

INPUT VCF │ ├─ HGVS_NORMALIZE bcftools norm + SnpEff HGVS (MANE NM_000492.4) │ ├─ SCORE_JOIN_MISSENSE join AlphaMissense/EVE/ESM1b/REVEL/PrimateAI │ └─ CLINVAR_CHECK → missense discordance worklist (A1) │ ├─ SPLICE_SCORE join SpliceAI/Pangolin + CADD-Splice PHRED │ └─ CLINVAR_CHECK → splice discordance worklist (A2) │ └─ MULTIQC_REPORT aggregate summaries → HTML + TSV

Modules & compute layer

  • HGVS_NORMALIZE → normalize_hgvs.py — HGVS_* / VAR_CLASS INFO fields
  • SCORE_JOIN_MISSENSE → join_missense_scores.py — 5 missense predictors
  • SPLICE_SCORE → join_splice_scores.py — SpliceAI / Pangolin / CADD
  • CLINVAR_CHECK → clinvar_cross_check.py — CFTR2 + ClinVar discordance flags
  • MULTIQC_REPORT → generate_report.py — aggregate → HTML/TSV

Each process runs in its own biocontainer (SnpEff, python, MultiQC) so the whole pipeline is reproducible across machines. A bundled 10-variant test VCF + each module's stub: block exercise the full DAG with no bioinformatics tools installed — exactly what CI runs on every push.

Run it

# Stub run — no data or tools needed (what CI does) nextflow run main.nf -profile test -stub-run # Real run on your VCF (GRCh38) with Docker nextflow run main.nf --vcf input.vcf.gz --outdir results/ -profile docker
