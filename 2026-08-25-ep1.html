Ep1 — MissenseNet: ShuffleNet + AlphaFold2 structural features for missense pathogenicity

Liu, Chen, Huang, and Guan (Biomolecules, 2024) build MissenseNet, a lightweight deep-learning classifier for missense variant pathogenicity that combines the usual sequence-based and ensemble predictor scores (categories A–C) with a new fourth category — structural features pulled from AlphaFold2 predictions. The architecture repurposes ShuffleNet V2 (a mobile-optimized convolutional network) with an encoder-decoder wrapper and a Squeeze-and-Excitation attention module, trained on gnomAD (benign) and ClinVar ≥1-star (pathogenic) variants split by protein to avoid leakage. Structural features alone underperform, but adding them to any existing category improves it, and the full model edges out REVEL and VEST4 on a held-out test set (AUC 0.9662 vs. 0.9554/0.9505). No CFTR-specific analysis — the buildable idea here is a CFTR-specific AlphaFold2 structural-feature lookup table to extend the existing CFTR2 predictor-calibration report, not adoption of MissenseNet itself.

Plain-English glossary

  • Missense variant — A single DNA change in a coding region that swaps one amino acid for another in the protein.（中文：编码区内的单个DNA改变，导致蛋白质中一个氨基酸被替换成另一个。）
  • VUS (variant of uncertain significance) — A genetic variant whose effect on disease risk hasn't been confidently classified as benign or pathogenic.（中文：一种遗传变异，其对疾病风险的影响尚未被明确判定为良性或致病性。）
  • AlphaFold2 — DeepMind's protein structure prediction model; given a sequence, it outputs a 3D structural model with per-residue confidence scores.（中文：DeepMind开发的蛋白质结构预测模型；给定序列后输出三维结构模型及每个残基的置信度分数。）
  • pLDDT — AlphaFold2's per-residue confidence metric for how reliable a predicted structural position is.（中文：AlphaFold2对每个残基预测结构位置可靠性的置信度指标。）
  • Depthwise separable convolution — A convolution operation split into a cheap per-channel step and a cheap channel-mixing step, used to keep neural networks small and fast.（中文：将卷积操作拆分为逐通道计算和通道混合两个低成本步骤，用于让神经网络保持轻量和高效。）
  • Squeeze-and-Excitation (SE) module — An attention mechanism that lets a neural network learn to weight some input feature channels more heavily than others.（中文：一种注意力机制，让神经网络学会对某些输入特征通道赋予更高权重。）
  • AUC (area under the ROC curve) — A standard classifier-performance metric; not re-explained on air, Runyu knows this cold.（中文：分类器性能的常用评估指标；因听众已熟悉，节目中未重新讲解。）
  • REVEL / VEST4 / MetaLR — Ensemble missense pathogenicity predictors that combine several sequence-based scores into one meta-score.（中文：将多个基于序列的评分组合成一个元评分的集成式错义致病性预测工具。）

Methods / tools to lift

  • AlphaFold Protein Structure Database — source of per-residue structural predictions (solvent accessibility, secondary structure, pLDDT) for essentially any human protein, including CFTR.
  • ShuffleNet V2 + SE-module architecture pattern — a lightweight feature-fusion architecture, generalizable beyond images to any small structured tabular feature set.
  • Protein-level (not variant-level) train/test split — a leakage-avoidance pattern worth replicating in any variant-classifier work.

Where it lands + buildable artifact

Serves Karen Raraigh / CFTR variant interpretation (method only). Buildable: CFTR structural-feature extractor (S) — pull AlphaFold2-derived structural features (solvent accessibility, secondary structure, pLDDT) for every CFTR missense position from the AlphaFold Protein Structure Database, and join against existing CFTR2 classifications from the earlier predictor-calibration-report idea, as an added column.

What to verify first

  • Whether gnomAD-as-benign training data meaningfully mislabels any CFTR carrier variants.
  • Whether the genome-wide AUC gain over REVEL/VEST4 translates to a CFTR-specific gain — needs its own held-out check, not assumed.
  • Whether the AlphaFold Protein Structure Database's CFTR entry is a reliable full-length model given CFTR's large multi-domain membrane-protein structure.
  • Whether structural-feature values actually separate CFTR2's classified pathogenic/benign variants before building anything more elaborate on top of the lookup table.

ALEX Today's paper is "Enhancing Missense Variant Pathogenicity Prediction with MissenseNet," by Liu, Chen, Huang, and Guan, published in Biomolecules in 2024. 今天的论文是刘、陈、黄、关四位作者发表在《Biomolecules》期刊上的《用MissenseNet增强错义变异致病性预测》，2024年发表。 It's a Track A pick — variant interpretation, the lane that feeds directly into a possible collaboration with Karen Raraigh. 这是A赛道的选题——变异解读，这个方向直接服务于与Karen Raraigh可能的合作。 The pitch is simple: another missense pathogenicity predictor, but one that folds AlphaFold2 structural features into a lightweight deep-learning architecture built for image-style feature fusion. 它的核心主张很简单：又一个错义致病性预测器，但这次把AlphaFold2的结构特征，融合进了一个为图像式特征融合设计的轻量级深度学习架构中。

JORDAN Before we get into the model, I want to make sure I have the domain vocabulary straight. 在深入模型细节之前，我想先把这个领域的术语理清楚。 What exactly is a missense variant, and why is AlphaFold2 relevant to predicting whether one is pathogenic? 什么是错义变异（missense variant），为什么AlphaFold2和预测其致病性有关？

ALEX A missense variant is a single-nucleotide change in a coding region that swaps one amino acid for another in the resulting protein — as opposed to a synonymous change, which alters the DNA but not the protein, or a nonsense change, which truncates it. 错义变异是编码区里的一个单核苷酸改变，导致最终蛋白质中一个氨基酸被替换成另一个——这与同义突变不同，同义突变改变DNA但不改变蛋白质；也与无义突变不同，无义突变会截断蛋白质。 Of the roughly four million missense mutations catalogued in humans, only about two percent have a confident benign-or-pathogenic call — the rest sit in that frustrating uncertain middle, which is exactly the VUS problem Karen's group deals with for CFTR. 在人类已编目的约四百万个错义突变中，只有大约百分之二有明确的良性或致病性判定——其余的都停留在那个令人头疼的不确定地带，这正是Karen团队在CFTR上处理的VUS（意义未明变异，variant of uncertain significance）问题。 AlphaFold2 is DeepMind's protein structure predictor — given an amino acid sequence, it outputs a 3D structural model with per-residue confidence scores. AlphaFold2是DeepMind开发的蛋白质结构预测工具——给定一段氨基酸序列，它会输出一个三维结构模型，并附带每个残基的置信度分数。 The logic for using it in pathogenicity prediction is that a missense change buried in a protein's structural core, disrupting folding or a binding pocket, is more likely to be damaging than the same kind of change sitting on a flexible, solvent-exposed loop. 把它用于致病性预测的逻辑是：埋藏在蛋白质结构核心、破坏折叠或结合口袋的错义改变，比发生在柔性、暴露于溶剂的环上的同类改变，更可能是有害的。

JORDAN Before AlphaFold2 came along, how were people even trying to bring structure into these predictions? 在AlphaFold2出现之前，人们是怎么尝试把结构信息纳入这些预测的？

ALEX Mostly through experimentally solved crystal structures, which only exist for a fraction of human proteins, or through homology models built from a related protein's known structure — both approaches leave huge coverage gaps. 主要是通过实验解出的晶体结构，但这只覆盖了一小部分人类蛋白质，或者通过基于相关蛋白质已知结构构建的同源模型——这两种方法都留下了巨大的覆盖空白。 AlphaFold2 changed that by making a confident structural prediction available for essentially every human protein, CFTR included, through the AlphaFold Protein Structure Database. 而AlphaFold2改变了这一点，通过AlphaFold蛋白质结构数据库，几乎为每一个人类蛋白质都提供了有一定置信度的结构预测，CFTR也不例外。 That's what opened the door to using structural features as a routine, scalable input to a pathogenicity model rather than a boutique add-on available for only a handful of well-studied genes. 这正是让结构特征能够成为致病性模型的一种常规、可扩展输入的原因，而不再是只对少数被深入研究过的基因才有的小众附加项。

JORDAN So the paper's premise is that most existing predictors haven't fully exploited that structural signal. 所以这篇论文的前提是，大多数现有预测工具还没有充分利用这种结构信号。 What was actually unknown or contested going in? 在这之前，实际存在哪些未知或有争议的地方？

ALEX Predictors like SIFT, PolyPhen-2, and CADD lean heavily on sequence conservation and simple biochemical substitution scores — how unusual is this amino acid change across evolutionary history, does it flip a charge, that sort of thing. 像SIFT、PolyPhen-2和CADD这类预测工具，主要依赖序列保守性和简单的生化替换评分——这个氨基酸变化在进化历史上有多罕见，它是否改变了电荷，诸如此类。 Newer ensemble tools like REVEL, VEST4, and MetaLR combine several of those sequence-based scores into one meta-score, and they perform quite well — REVEL and VEST4 both clear 0.95 AUC in benchmarks. 更新的集成工具，比如REVEL、VEST4和MetaLR，把几种基于序列的评分组合成一个元评分，表现相当不错——REVEL和VEST4在基准测试中都能达到0.95以上的AUC（ROC曲线下面积）。 What was less settled is whether adding AlphaFold2-derived structural features — things like predicted secondary structure, solvent accessibility, or local confidence — actually buys you anything once you already have those strong sequence-based ensembles, or whether it's redundant information dressed up as something new. 但不太确定的是，在已经有了这些强大的序列集成评分之后，加入AlphaFold2衍生的结构特征——比如预测的二级结构、溶剂可及性或局部置信度——是否真的能带来增益，还是只是把冗余信息包装成新东西。 This paper tries to answer that with a controlled ablation design. 这篇论文试图用一个受控的消融实验设计来回答这个问题。

JORDAN Walk me through what they actually built. 跟我讲讲他们实际构建了什么。

ALEX They defined four feature categories: Category A is sequence-based predictors, Category B is hybrid structure-function scores, Category C is integrated ensemble tools — the REVEL/VEST4/MetaLR family — and Category D is the new piece, structural features pulled from AlphaFold2 predictions. 他们定义了四类特征：A类是基于序列的预测因子，B类是混合结构-功能评分，C类是集成工具——也就是REVEL/VEST4/MetaLR这一族，D类是新加入的部分，从AlphaFold2预测结果中提取的结构特征。 The model itself, MissenseNet, is built on ShuffleNet V2, a lightweight convolutional architecture originally designed for mobile image classification, chosen here for computational efficiency rather than image content. 模型本身叫MissenseNet，建立在ShuffleNet V2之上——这是一种最初为移动端图像分类设计的轻量级卷积架构，这里选用它是为了计算效率，而不是因为图像内容本身。 They wrap it with an encoder-decoder structure using depthwise separable convolutions to compress the feature set, and add a Squeeze-and-Excitation, or SE, module — an attention mechanism that lets the network learn to weight some feature channels more heavily than others rather than treating every input feature as equally important. 他们用带有深度可分离卷积的编码器-解码器结构把它包起来，用来压缩特征集，并加入一个Squeeze-and-Excitation（简称SE）模块——一种注意力机制，让网络学会对某些特征通道加权，而不是把每个输入特征都同等对待。

JORDAN Why ShuffleNet specifically, out of all the architectures they could have picked? 在所有可选架构中，为什么偏偏选择ShuffleNet？

ALEX ShuffleNet V2 was designed for phones and other low-compute devices — its whole point is squeezing good accuracy out of a small parameter budget using depthwise separable convolutions, which factor a standard convolution into a cheap per-channel step and a cheap channel-mixing step. ShuffleNet V2最初是为手机等低算力设备设计的——它的核心目标就是用深度可分离卷积，在很小的参数预算下挤出不错的准确率，深度可分离卷积把一次标准卷积拆成一个便宜的逐通道步骤和一个便宜的通道混合步骤。 Repurposing that for tabular variant features rather than images is a reasonable bet: the feature vectors here are small and structured, not megapixel images, so a lightweight architecture avoids overfitting on a training set that, while large by genetics standards, is tiny by computer-vision standards. 把它挪用来处理表格式的变异特征而不是图像，是个合理的赌注：这里的特征向量很小、结构化程度高，不是百万像素的图像，所以轻量级架构可以避免在一个训练集上过拟合——这个训练集按遗传学标准来说不小，但按计算机视觉标准来说很小。 The Squeeze-and-Excitation module on top is what actually does most of the interpretive work, learning per-channel weights so the network can effectively down-weight a noisy or redundant feature without a human manually curating the feature set. 上面附加的Squeeze-and-Excitation模块才是真正承担大部分解读工作的部分，它学习逐通道的权重，让网络能够有效地降低某个嘈杂或冗余特征的权重，而不需要人工手动筛选特征集。

JORDAN And the training data? 训练数据是怎么来的？

ALEX Variants came from gnomAD version 3.1, treated as the benign pool, and ClinVar as of January 2021, filtered to a review status of at least one star, treated as pathogenic. 变异数据来自gnomAD 3.1版本，被当作良性变异池；以及截至2021年1月的ClinVar数据库，筛选出评审状态至少一星的变异，被当作致病变异。 To avoid a variant-level leakage problem, they split by protein rather than by individual variant — eighty percent of proteins went to train and validate, the remaining twenty percent, with their ClinVar variants held out entirely, became the independent test set. 为了避免变异层面的数据泄漏问题，他们按蛋白质而非按单个变异来划分数据集——百分之八十的蛋白质用于训练和验证，剩下百分之二十的蛋白质，连同其ClinVar变异一起被完全保留，作为独立测试集。

JORDAN That protein-level split sounds like the right instinct. 按蛋白质划分听起来是个正确的直觉。 Where would you push back? 你会在哪里提出质疑？

ALEX Two places. 两个地方。 First, gnomAD-as-benign is a common shortcut, but it's an imperfect proxy — gnomAD is a population database of people who weren't necessarily screened for every recessive disease, so it still contains carriers of pathogenic variants in genes like CFTR, sitting there labeled "benign" by virtue of being observed in a population sample. 第一，把gnomAD当作良性数据集是个常见的捷径，但这是个不完美的替代——gnomAD是一个人群数据库，其中的人并没有针对每种隐性疾病都被筛查过，所以它里面仍然混有像CFTR这样基因中的致病变异携带者，仅仅因为在人群样本中被观察到，就被贴上"良性"的标签。 That's a real concern for exactly the kind of recessive, carrier-tolerant gene CFTR is. 这对CFTR这种隐性遗传、携带者可耐受的基因来说，是个实实在在的问题。 Second, a ClinVar review-status filter of one star still lets through variants with some conflicting interpretations, so the "pathogenic" label isn't as clean as a two- or three-star filter would give you. 第二，一星的ClinVar评审状态筛选门槛仍然会放行一些存在解读分歧的变异，所以"致病"这个标签并不像用二星或三星筛选那样干净。 Neither of these sinks the paper, but they matter if you're thinking about applying this kind of model to a specific gene rather than genome-wide. 这两点都不会推翻这篇论文，但如果你考虑把这类模型用在某个特定基因而不是全基因组范围时，它们就很重要了。

JORDAN Let's get to results. 我们来看结果吧。 Did the structural features actually help? 结构特征真的有帮助吗？

ALEX On their own, Category D — the AlphaFold2 structural features — underperformed as a standalone predictor, same for Category A and B alone. 单独使用时，D类——也就是AlphaFold2结构特征——作为独立预测因子表现不佳，A类和B类单独使用也是如此。 Category C, the existing ensemble scores, was the strongest solo performer at 90.48 percent accuracy and 0.9625 AUC. C类，也就是现有的集成评分，作为单独使用时表现最强，准确率达到90.48%，AUC为0.9625。 But when they combined D with A, B, or C, every combination improved — the A-plus-D combination alone lifted accuracy from 84.36 to 85.43 percent, roughly a 1.27 percent relative gain. 但当他们把D与A、B或C组合时，每种组合都有提升——仅A加D的组合就把准确率从84.36%提升到85.43%，相对提升约1.27个百分点。 The full MissenseNet model, combining everything through the ShuffleNet-plus-SE architecture, reached an AUC of 0.9662 and an average precision of 0.9491 on the held-out test set, edging out REVEL at 0.9554 AUC and VEST4 at 0.9505, and outperforming CADD, MVP, DANN, and GenoCanyon by a wider margin. 完整的MissenseNet模型，通过ShuffleNet加SE架构整合所有特征，在保留的测试集上达到了0.9662的AUC和0.9491的平均精度，略微超过了REVEL的0.9554和VEST4的0.9505，并以更大的优势超过了CADD、MVP、DANN和GenoCanyon。

JORDAN What about the cross-validation setup — how confident should we be in those ablation numbers? 那交叉验证的设置呢——我们对这些消融实验的数字应该有多大信心？

ALEX The ablation results were averaged over tenfold cross-validation, which is a reasonable standard and helps smooth out the noise you'd get from a single train-test split — though it's worth remembering that's cross-validation within the training data, separate from the final held-out test set used for the headline AUC numbers. 消融实验结果是在十折交叉验证上取平均得到的，这是一个合理的标准做法，有助于平滑掉单次训练-测试划分可能带来的噪声——不过值得记住的是，这是训练数据内部的交叉验证，与用于最终AUC结果的独立保留测试集是分开的。 That two-tier design — cross-validation for feature and architecture choices, then a single untouched test set for the final comparison against REVEL and the others — is the right way to avoid quietly tuning the model to the test set, and it's a detail worth checking for in any predictor before trusting its headline number. 这种两层设计——用交叉验证来做特征和架构选择，再用一个完全未触碰过的测试集做最终与REVEL等工具的比较——是避免悄悄把模型调到贴合测试集的正确做法，这也是在信任任何预测器的头条数字之前，值得核实的一个细节。

JORDAN So a modest but real gain from adding structure, not a blowout. 所以加入结构特征带来的是适度但真实的提升，而不是压倒性的胜利。 Did it deliver on what it promised? 它实现了自己的承诺吗？

ALEX Yes, within the scope it set for itself — a genome-wide missense classifier that edges out the strongest existing ensembles by a small but consistent margin, with the AlphaFold2 features contributing a measurable, if modest, piece of that gain. 是的，在它给自己设定的范围内实现了——一个全基因组范围的错义分类器，以微小但一致的优势超过了现有最强的集成工具，而AlphaFold2特征贡献了其中可衡量、虽然不算大的一部分提升。 What it didn't do is test itself on any single gene in depth, CFTR included — this is a genome-wide benchmark, not a CF-specific validation. 它没有做的是，在任何单一基因上进行深入测试，CFTR也不例外——这是一个全基因组基准测试，而不是CF专属的验证。

JORDAN So where does this land for the work Runyu's actually trying to do? 那这篇论文对Runyu实际想做的工作有什么意义？
