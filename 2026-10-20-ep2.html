Ep2 (Track B — AI/tooling for registry & bioinformatics): nf-core/pacsomatic

Paper: Zhang W, Yi H, Niu B, Wu G, Chang TC. "nf-core/pacsomatic: a scalable somatic analytic pipeline using PacBio HiFi data." Bioinformatics, 2026.

Blurb

nf-core/pacsomatic is a Nextflow DSL2 pipeline for paired tumor-normal somatic analysis of PacBio HiFi long-read data: alignment, somatic SNV/indel/SV/CNV calling, CpG methylation profiling and differential-methylation-region (DMR) detection in the same pass, plus downstream functional annotation, mutational-signature analysis, tumor purity/ploidy estimation, and homologous-recombination-deficiency (HRD) assessment. It's released under the MIT license on nf-co.re and GitHub. The abstract describes scope and feature completeness, not a benchmark against ground truth, and full text wasn't retrievable (fullTextXML and BioC PMC-OA both failed for this 2026 paper), so the specific callers wrapped at each stage and any accuracy numbers remain unverified. What transfers for Runyu's work isn't the cancer-specific calling logic but the nf-core engineering pattern itself — modular, containerized, version-pinned, testable — which is directly reusable for packaging any existing in-house script (a CFTR annotation step, a registry-cleaning step) into something reproducible on anyone's infrastructure. Buildable artifact: an nf-core-style CFTR Annotation Module.

Plain-English glossary

  • DMR (differential methylation region) — a stretch of the genome where CpG methylation differs meaningfully between two samples (here, tumor vs. normal).（中文:基因组中的一段区域,在两个样本之间——此处为肿瘤与正常组织——CpG甲基化水平存在有意义的差异。）
  • HRD (homologous recombination deficiency) — a tumor's impaired ability to repair DNA double-strand breaks via homologous recombination; HRD-positive tumors tend to respond well to PARP inhibitors.（中文:肿瘤通过同源重组修复DNA双链断裂的能力受损;HRD阳性的肿瘤通常对PARP抑制剂反应良好。）
  • Nextflow DSL2 — the second-generation, module-based scripting style of the Nextflow pipeline language, which organizes a workflow into reusable, independently testable processes.（中文:Nextflow流程语言的第二代、基于模块的脚本风格,把工作流组织成可复用、可独立测试的流程单元。）
  • nf-core — a community project that curates Nextflow pipelines against shared engineering standards: mandatory containerization, continuous-integration testing, and standardized input/output conventions.（中文:一个按共同工程标准维护Nextflow流程的社区项目,要求强制容器化、持续集成测试和标准化输入输出规范。）
  • PacBio HiFi (high fidelity) — PacBio's long-read sequencing technology; the same DNA molecule is sequenced repeatedly in a circle and the passes combined into one long, highly accurate consensus read.（中文:PacBio公司的长读长测序技术,同一DNA分子被环形重复测序多次,合并为一条长且高度准确的一致性读长。）
  • Tumor purity — the fraction of cells in a sequenced sample that are actually tumor cells rather than infiltrating normal tissue.（中文:被测序样本中真正属于肿瘤细胞、而非混入的正常组织细胞的比例。）
  • Ploidy — the number of genome copies a cell carries; many tumors deviate from the normal diploid state.（中文:一个细胞携带的基因组拷贝数;许多肿瘤偏离正常的二倍体状态。）

Methods / tools to lift

  • nf-core module conventions — declarative process definitions, version-pinned containers, and an automated per-module test harness.
  • DSL2's modular structure — each pipeline stage (alignment, SNV/SV/CNV calling, methylation, downstream annotation) as an independently swappable, testable unit.
  • Single-pass methylation calling from HiFi raw signal — avoids a separate bisulfite-sequencing experiment.

Where it lands + buildable artifact

Serves AI-tooling / career — the transferable piece is nf-core's modular, containerized, testable pipeline engineering pattern, not the cancer-specific calling logic.

Buildable artifact — nf-core-Style CFTR Annotation Module (M). One-line MVP: re-package an existing in-house CFTR variant-annotation script as an nf-core-conformant Nextflow DSL2 module (declarative process + version-pinned container + module tests), taking a VCF plus the existing script as input and producing a reusable, testable module as output.

What to verify first

  • Which specific variant callers and statistical methods pacsomatic wraps at each stage — not named in the abstract.
  • Whether it's been validated against an orthogonal truth set (a well-characterized tumor-normal pair with known SVs) rather than only demonstrated on the authors' own cohort.
  • Actual runtime and compute-cost figures behind the "scalable" claim.
  • Current state of nf-core's own module-testing conventions before reusing the packaging pattern, since the ecosystem's tooling moves quickly.
