Ep1 (Track A) — Probabilistic gradient boosting for clinical variant interpretation

Karthik V, Prejesh S, Kudale SD, OmKumar CU (2026). Deep DNA and protein level feature integration for robust clinical variant interpretation using probabilistic gradient boosting. Frontiers in Digital Health.

A gradient-boosted classifier that predicts variant pathogenicity from concatenated DNA-level (alignment scores, GC content, Shannon entropy, hairpin stability) and protein-level (molecular weight, isoelectric point, hydrophobicity, BLOSUM substitution score) features, with a heteroscedastic variance head that returns a calibrated confidence interval alongside every pathogenicity probability rather than a single point estimate. Benchmarked on ClinVar 2020, GRCh37, and GRCh38, it reports ROC AUC of 0.9293–0.9646 and edges out several named baselines (EVE, FINSURF, VariPred, AlphaMissense) on self-reported, indirect comparisons — a caveat the authors flag themselves. The transferable idea for Runyu isn't the architecture; it's the pattern of pairing every score with a calibrated confidence measure and routing the wide-interval cases to human review. The buildable artifact is a disagreement-based confidence wrapper around predictor scores Karen's team likely already has (AlphaMissense, REVEL, CADD, SpliceAI) for CFTR VUS triage — no new model training required.

Plain-English glossary

  • VUS (variant of uncertain significance) — A genetic variant that current evidence can't confidently classify as pathogenic or benign.（中文:现有证据不足以判定为致病或良性的变异。）
  • ACMG/AMP framework — The field-standard set of evidence categories (e.g. PS3 for strong pathogenic functional evidence, BS3 for strong benign functional evidence) that curators combine into a final pathogenicity call.（中文:临床遗传学界用于变异分级的证据标准体系,综合多类证据得出最终致病性判断。）
  • ClinVar review status (star rating) — A 0–4 star system marking how much curation a ClinVar submission received, from a single unreviewed submitter (0 stars) to expert-panel consensus (4 stars).（中文:标注ClinVar提交记录审核程度的0至4星评级体系。）
  • GRCh37 / GRCh38 — Two successive builds of the human reference genome (2009 and 2013) with non-interchangeable coordinates; tools should be validated on both.（中文:人类参考基因组的两个先后版本,坐标体系不通用,工具需分别验证。）
  • Missense variant — A coding change that swaps one amino acid for another.（中文:错义变异,编码区内导致氨基酸替换的变化。）
  • Nonsense variant — A coding change that introduces a premature stop codon, truncating the protein.（中文:无义变异,产生提前终止密码子,导致蛋白质截短。）
  • Frameshift variant — An insertion or deletion that shifts the reading frame downstream of the change.（中文:移码变异,插入或缺失导致阅读框错位。）
  • Intronic variant — A change outside the coding exons that can still disrupt splicing or regulation.（中文:内含子变异,位于外显子之外但仍可能破坏剪接或调控。）
  • BLOSUM substitution score — A standard scoring matrix measuring how conservative or radical a given amino acid substitution is.（中文:BLOSUM替换矩阵,用于衡量某次氨基酸替换的保守或剧烈程度。）
  • Heteroscedastic model — A model whose predicted uncertainty varies case by case, rather than using one fixed error bar for every prediction.（中文:异方差模型,预测的不确定性会随样本而变化,而非统一固定值。）

Full citation

Karthik V, Prejesh S, Kudale SD, OmKumar CU (2026). Deep DNA and protein level feature integration for robust clinical variant interpretation using probabilistic gradient boosting. Frontiers in Digital Health. PMID: 42718683 · PMC: PMC13553750 · DOI: 10.3389/fdgth.2026.1845955

Methods / tools to lift

  • Heteroscedastic gradient boosting — a mean-and-variance boosted ensemble that returns calibrated per-prediction confidence intervals instead of a point estimate.
  • Optuna (Bayesian TPE hyperparameter search) — automated 100-trial hyperparameter tuning used to fit the ensemble.
  • Brier score + Expected Calibration Error (ECE) — the two calibration diagnostics used to check whether predicted probabilities track true outcomes.
  • Bootstrap resampling (1,000 iterations) — used to derive 95% confidence intervals around reported ROC AUC / PR AUC.
  • Feature-group ablation — systematically dropping one feature category at a time to quantify its marginal contribution.

Where it lands + buildable artifact

Priority served: Karen Raraigh / CFTR variant interpretation. The transferable pattern — score plus calibrated uncertainty, route wide-interval cases to human review — maps directly onto CFTR VUS triage.

Buildable MVP: A disagreement-based confidence wrapper: input a table of existing multi-predictor scores (AlphaMissense, REVEL, CADD, SpliceAI) per CFTR VUS, compute a simple spread/disagreement metric flagging cases where predictors straddle the pathogenic/benign boundary, and output a ranked manual-review list, worst-disagreement first. Difficulty: S–M (data wrangling and a defensible disagreement metric; no new model training).

What to verify first

  • Whether the reported calibration (Brier score, ECE) holds up specifically for missense variants, since that's the dominant variant type in a CFTR VUS queue, rather than relying on the pooled-across-types number.
  • Whether the "beats AlphaMissense/EVE/FINSURF" framing survives a true head-to-head re-run on one shared variant set — the paper's own comparisons are indirect, self-reported baselines.
  • Whether the model's gene-agnostic ClinVar training generalizes to CFTR specifically, since the paper includes no CF- or CFTR-specific validation and CFTR's multi-domain ABC-transporter structure was never part of the tuning process.
