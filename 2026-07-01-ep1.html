Track A — Gene-specific ACMG/AMP: the ClinGen ENIGMA BRCA1/2 VCEP specifications

Blurb. Parsons et al. (2024, AJHG) is the specification document for how a ClinGen Variant Curation Expert Panel (VCEP) takes the generic 2015 ACMG/AMP variant-classification framework and rewrites it for two specific genes, BRCA1 and BRCA2. The panel reviewed every evidence code for relevance, judged 13 non-applicable or overlapping and re-purposed 8, and — the transferable core — used statistical methods to calibrate evidence strength (supporting → very strong) to defined odds of pathogenicity rather than hand-waved labels. On a 40-variant pilot the gene-tuned rules resolved 11 of 13 uncertain/conflicting variants and retained or improved confidence on the rest. The specific genes barely matter here; the process is the object. It lands on the Karen collaboration — a real ClinGen CFTR VCEP and CFTR2 already publish CFTR-tuned rules — and the buildable artifact is a CFTR ACMG/AMP criteria worklist that applies each CFTR-specific code at its calibrated strength to a variant list and, for each remaining VUS, names the single missing piece of evidence that would resolve it. Abstract-only for us today (paywalled; OA full-text routes empty) — flagged on-air.

Plain-English glossary.

  • ACMG/AMP framework — the 2015 joint guideline that classifies a DNA variant into pathogenic / likely pathogenic / uncertain / likely benign / benign using a set of evidence codes.（中文：ACMG/AMP，2015 年的变异分类指南，用一组证据代码把变异分成致病到良性五档。）
  • ClinVar — public NIH database where labs deposit variant-to-condition assertions; conflicting entries are a core problem VCEPs address.（中文：ClinVar，美国 NIH 的公共数据库，存放各实验室"变异对应疾病"的判定；相互冲突的条目是 VCEP 要解决的核心问题。）
  • Evidence code — one line item of evidence (e.g. PS3 functional-assay damage, PM2 population-rarity, PP1 family co-segregation), each carrying a defined strength.（中文：证据代码，一条具体证据项，如 PS3 功能实验损害、PM2 人群罕见、PP1 家系共分离，各带一个规定的强度。）
  • Evidence strength / Bayesian points — supporting/moderate/strong/very-strong tiers, each mapped to a numeric odds of pathogenicity (Tavtigian points) so evidence can be summed instead of eyeballed.（中文：证据强度／贝叶斯点数，把支持性、中等、强、极强各映射到一个致病几率数值，让证据可以相加而非凭感觉。）
  • Co-segregation — a variant tracking with disease through affected relatives in a family, used as evidence.（中文：共分离，变异在一个家族中随患病亲属一起遗传，作为一类证据。）
  • Functional assay — a lab experiment that directly measures whether a variant impairs the protein.（中文：功能实验，在实验室里直接测量变异是否损害蛋白质功能。）
  • HGVS — the standardized notation for writing a variant unambiguously.（中文：HGVS，变异命名的标准化书写规范。）
  • Missense variant — a single-base change that swaps one amino acid for another.（中文：错义变异，改变一个氨基酸的单碱基变异。）
  • Tumor-suppressor gene — a gene whose loss of function raises cancer risk (BRCA1/BRCA2 here).（中文：抑癌基因，功能缺失会升高癌症风险的基因，此处指 BRCA1/BRCA2。）
  • VCEP (Variant Curation Expert Panel) — a ClinGen-sanctioned per-gene expert group that adapts the generic codes to its gene and submits to ClinVar under FDA-recognized processes.（中文：VCEP，变异审编专家组，经 ClinGen 认证、针对某基因把通用代码本地化并按 FDA 认可流程提交 ClinVar 的专家小组。）
  • VUS (variant of uncertain significance) — a variant that can't be called pathogenic or benign, so it can't be clinically acted on; shrinking the VUS pile is the goal.（中文：VUS，意义未明变异，既不能判致病也不能判良性、临床无法据以行动；削减 VUS 堆积是目标。）

Methods / tools to lift.

  • Gene-specific ACMG/AMP specification workflow: review every generic evidence code → keep / drop / merge / re-purpose per gene biology → calibrate each surviving code's strength.
  • Tavtigian Bayesian points calibration — map each evidence tier to a numeric odds of pathogenicity so evidence sums to a class.
  • Pilot-validation loop: run the draft spec on a labeled variant mix (uncertain + already-classified) and measure VUS resolution + confidence retention.

Where it lands + buildable artifact. Serves Karen / variant interpretation. Paste-ready MVP: CFTR ACMG/AMP criteria worklist — input CFTR variants in normalized HGVS plus available evidence annotations (population frequency, functional-assay result, computational scores, segregation); apply each published CFTR-VCEP evidence code at its calibrated strength, sum points to a provisional class, and for every remaining VUS emit the single missing evidence type that would tip it and the strength it would need — outputting a ranked curation to-do list. Input: CFTR variant list + evidence table. Difficulty: M. Sits one layer above the CFTR PP3/BP4 calibration notebook (that decides per-evidence-type thresholds; this pulls all levers across a whole list).

What to verify first.

  • Abstract-only today: obtain full specification tables, code-by-code strength assignments, and calibration methods before building.
  • Use CFTR's own calibration (published CFTR VCEP / CFTR2), not BRCA numbers — strengths are gene-specific by design.
  • Circularity: if ClinVar labels both calibrate the codes and seed the test set, resolution rate is inflated; use an independent labeled set.
  • Missense-only coverage: route splice-region CFTR variants through a separate SpliceAI-style track.
  • Pilot resolution (11/13) came from hand-picked variants; expect a lower rate on a fresh backlog.
