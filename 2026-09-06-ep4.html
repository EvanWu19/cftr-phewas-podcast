Who Gets a Code for Obesity? Reliability, Use, and Implications of Combining International Classification of Diseases-Based Obesity Codes, 2014-2021

Kompaniyets L, Pierce S, Belay B, Goodman AB. Childhood Obesity, 2025.

Blurb

Using EHR data on 7.4 million children ages 2-19 from 2014-2021, this CDC-authored study asked whether ICD-based obesity code under-capture — already known from prior work — is random or systematic. Obesity code utilization rose from 3.9% to 9.8% over the study period while BMI-measured obesity prevalence rose from 17.4% to 20.5%; code sensitivity improved from 19.8% to 40.8% but remained poor. Among children with obesity in 2021, those with severe obesity or a chronic disease were significantly more likely to actually receive a code, meaning under-capture is concentrated in milder, less clinically complex cases. This is a hard caution against treating a diagnosis code as a neutral corroborating field when adjudicating a flagged height/weight/BMI value, or as ground truth when scoring a flagging tool: a missing code is the expected outcome for many true-positive cases, and its absence is itself biased. The buildable artifact is a code-reliability-weighted adjudication step that discounts a missing code's evidentiary weight according to known severity-dependent sensitivity, rather than treating code presence/absence as a binary confirm/deny signal.

Plain-English glossary

  • Diagnosis code vs status code — a diagnosis code records that a clinician identified and is actively managing a condition (e.g., an ICD obesity diagnosis code); a status code documents a measured fact (e.g., a BMI-percentile-linked code) without necessarily implying active management.（中文:诊断代码记录临床医生已识别并正在管理某疾病;状态代码记录一项已测量的事实,不一定意味着正在积极管理。）
  • Pediatric obesity / severe obesity thresholds — pediatric obesity is BMI ≥95th percentile for age and sex; severe obesity is typically ≥120% of the 95th percentile or higher — both moving, age/sex-specific thresholds rather than fixed adult BMI cutoffs.（中文:儿科肥胖指BMI达到按年龄性别划分的第95百分位以上;重度肥胖通常指第95百分位的120%以上——均为随年龄性别变化的阈值,而非固定的成人BMI界值。）
  • Code sensitivity — the proportion of children who truly have obesity (by BMI) who also have a corresponding diagnosis/status code in their record.（中文:真正患有肥胖(按BMI标准)的儿童中,病历中也有相应诊断/状态代码的比例。）
  • Systematic (differential) misclassification — measurement error that is not random but correlated with patient characteristics, biasing downstream comparisons in a specific direction rather than just adding noise.（中文:并非随机、而是与患者特征相关的测量误差,会使下游比较产生特定方向的偏倚,而不仅仅是增加噪声。）

Methods / tools to lift

  • Modeling probability of receiving a diagnostic code as a function of patient severity/comorbidity characteristics, restricted to a true-positive subgroup.
  • Distinguishing diagnosis codes from status codes rather than pooling all "obesity-related" codes together.

Pipeline stage: (b) adjudication, primary — caution against treating a corroborating diagnosis code as a neutral confirm/deny signal; (d) evaluation, secondary — code presence is a poor, severity-biased ground truth. What to verify first

  • Whether this under-capture-concentrated-in-milder-cases pattern holds in an intensively followed, disease-specific registry population rather than the general pediatric EHR population studied here.
  • This study only characterizes under-capture among true positives — it does not characterize the opposite error (a code appearing without true obesity); a separate check is needed for that direction.
  • Whether general-pediatric-care coding conventions and incentives carry over to a specialty-clinic context.

Error types covered / not covered

Covered: systematic (severity-dependent) under-capture of a corroborating diagnostic code, and the confound this introduces into any code-based ground truth or cross-check. Not covered: false-positive coding (a code appearing without true obesity), unit conversion, digit transposition, decimal-shift, or carry-forward data-entry errors — this paper's signal is entirely about coding completeness and its bias, not raw measurement accuracy.
