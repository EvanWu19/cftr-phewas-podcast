The Kahn/Weiskopf data-quality vocabulary gets two new dimensions

Lewis et al. (JAMIA, 2023) extend Weiskopf's foundational 2013 review of EHR data-quality assessment, systematically reviewing 103 papers (2013–2023) against the original five dimensions — completeness, correctness, concordance, plausibility, currency — and seven assessment methods. They add two new dimensions, conformance (compliance with a predefined representational structure, assessed via a new method called structural agreement) and bias (missingness not at random), and find that data element agreement, element presence, and data source agreement have all overtaken gold-standard comparison as the field's most common assessment methods (used in 82, 69, and 50 of 103 papers respectively, versus 40 for gold standard). This is a taxonomy paper, not a detection method — it doesn't change the CFFPR outlier pipeline's mechanics directly, but supplies vocabulary worth adopting: an impossible height/weight value is a plausibility problem, a cross-visit inconsistency is a concordance problem, and nonrandom missingness is a bias problem, three distinct categories rather than one undifferentiated "bad data" bucket. The field-wide move away from gold-standard comparison is also useful precedent that rigorous quality assessment doesn't require one.

Plain-English glossary

  • Kahn framework / Weiskopf dimensions — the field-standard taxonomy (from a 2013 review) of EHR data quality, originally five dimensions and seven assessment methods, now widely cited shorthand for structured data-quality discussion.（中文：源自2013年一篇综述的电子健康记录数据质量领域标准分类体系，最初包含五个维度和七种评估方法，现已成为结构化讨论数据质量问题的通用简称。）
  • Completeness — whether data is present at all in the record.（中文：数据在记录中是否存在。）
  • Correctness — whether a recorded value is actually true.（中文：某个记录的数值是否真实准确。）
  • Concordance — whether elements agree with each other, or with an external source.（中文：各元素之间、或与外部来源之间是否一致。）
  • Plausibility — whether a value makes sense in a larger clinical context, regardless of whether it's provably correct.（中文：某个数值在更广的临床背景下是否合理，无论能否证明其字面正确。）
  • Currency — whether data is accurate and up to date for the time point it claims to represent.（中文：数据对于其所声称的时间点而言是否准确、及时。）
  • Conformance — compliance with a predefined representational structure (correct data type, unit, coded format); newly added dimension.（中文：是否符合预先定义的表示结构，如正确的数据类型、单位、编码格式；本文新增的维度。）
  • Bias (as a DQ dimension) — missingness not at random, e.g. sicker patients having more complete records, which biases any complete-case analysis.（中文：非随机缺失，例如病情更重的患者记录更完整，这会使任何仅使用完整病例的分析产生偏倚；本文新增的维度。）
  • Structural agreement — a new assessment method: checking agreement with predefined formatting/structural constraints, used almost exclusively to assess conformance.（中文：一种新的评估方法，检查是否符合预先定义的格式或结构约束，几乎专门用于评估一致规范性。）
  • Gold standard (comparison) — assessing data quality by comparing against an external dataset considered to be true; expensive to build, and increasingly less common than other methods in this review.（中文：通过与一个被视为真实的外部数据集进行比较来评估数据质量的方法；构建成本高，本综述发现其使用频率日益低于其他方法。）

Error types covered / not covered

This is a taxonomy paper, not an error-detection method, so it doesn't itself flag specific error types. It does provide categories that specific errors map onto: an impossible value is a plausibility issue; a value inconsistent with the same patient's other records is a concordance issue; a wrong unit or malformed field is a conformance issue; and systematically missing measurements for certain patient subgroups is a bias issue. It says nothing about digit transposition, decimal-shift, or carry-forward errors specifically.
