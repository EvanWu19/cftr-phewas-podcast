Plain-English glossary

Atemporal plausibility — Whether a data value or its distribution is believable at a single point in time, given internal or external expectations, as opposed to how it behaves over time.（中文：在单一时间点上,数据值或其分布是否可信,区别于其随时间的变化情况。）

Completeness — The Kahn DQ category describing whether data values are present at all, without regard to what those values actually are.（中文：Kahn数据质量框架中的"完整性"类别,指数据值是否存在,不涉及数值本身是否可信。）

Computational conformance — Whether a value derived by calculation was computed correctly according to its own specification, independent of whether the result is believable.（中文："计算符合性",指按规范正确计算得出的派生值,不涉及结果是否合理可信。）

Conformance — The Kahn DQ category describing whether data values meet formatting, relational, or computational specifications; it does not assess believability, only structural validity.（中文：Kahn框架中的"符合性"类别,指数据是否满足格式、关联或计算规范,不评估数据是否可信。）

Data dictionary — The document specifying the intended format, allowed values, and constraints for every field in a data set; the contract a data submitter builds against.（中文："数据字典",规定数据集中每个字段的格式、允许取值及约束条件的文档,是数据提交方据以建设的规范契约。）

Gold standard — An external reference a community has agreed to trust enough to validate other data against; Kahn stresses that designating something a gold standard is itself a judgment about confidence, not an objective fact.（中文："金标准",某个领域内被信任、可用于验证其他数据的外部参照;将某来源定为金标准本身是一种信任度判断,而非客观事实。）

Plausibility — The Kahn DQ category describing whether data values are believable, given internal knowledge, another related value, or an external reference; it is the category that finally looks at the value itself.（中文：Kahn框架中的"合理性"类别,指结合内部知识、相关数值或外部参照,判断数据值本身是否可信。）

Relational conformance — Whether data respects structural relationships in the database, such as foreign keys resolving correctly or a unique identifier not being duplicated.（中文："关联符合性",指数据是否满足数据库中的结构性关系,例如外键正确关联、唯一标识不重复。）

Secondary use (of data) — Using data for a purpose other than the one for which it was originally collected, such as using EHR data captured for clinical care and billing for research or registry purposes.（中文："数据二次使用",将数据用于最初收集目的以外的用途,例如将用于临床诊疗和计费的电子病历数据用于科研或登记系统。）

Temporal plausibility — Whether a time-varying value behaves as expected across time, such as an admission date preceding a discharge date or a booster following an initial immunization.（中文："时序合理性",指随时间变化的数值是否符合预期的时间顺序,例如入院日期早于出院日期,或加强针晚于首次接种。）

Uniqueness plausibility — Whether an object that should appear only once (a patient, a record) appears duplicated within or across data sources.（中文："唯一性合理性",指本应唯一出现的对象（如患者、记录）是否在数据内部或跨数据源中被重复。）

Validation (DQ context) — Assessing a data value against an external referent — a gold standard, an independent database, external domain knowledge — rather than against the data's own internal expectations.（中文："验证性评估（外部对照）",指依据外部参照（金标准、独立数据库或外部专业知识）而非数据自身内部预期来评估数据值。）

Value conformance — Whether a data field matches its allowed format or value set, such as a sex field restricted to specific codes.（中文："取值符合性",指数据字段是否符合允许的格式或取值范围,例如性别字段仅限特定编码。）

Verification (DQ context) — Assessing a data value against internal expectations — metadata, a stated range, local knowledge — with no external referent involved.（中文："核查性评估（内部对照）",指依据元数据、既定范围或本地知识等内部预期来评估数据值,不涉及外部参照。）
