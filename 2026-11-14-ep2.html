Ep2 — Track B: LLM Framework for Structured Biomarker Extraction and TNBC Identification From Pathology Reports

Paper: Jain N, Annambhotla T, Siddharthan A, Kanala H, Budhiraja A, Goutam Sinha M, Charan D, Ahmad Dar M, Patel T, C L B. "Large Language Model Framework for Structured Biomarker Extraction and Triple-Negative Breast Cancer Identification From Pathology Reports: Development and Evaluation Study." JMIR Formative Research. 2026. Full text retrieved via NCBI efetch (PMC route) after Europe PMC's fullTextXML and BioC routes both failed; not abstract-only. Code and sample dataset public on GitHub.

A development-and-evaluation study building an LLM pipeline that OCRs and chunks 532 TCGA breast cancer pathology reports, then extracts structured biomarker fields (ER, PR, HER2, tumor size, and others) via schema-constrained JSON prompts, before classifying triple-negative breast cancer (TNBC) status from the extracted fields. Four small, fast models (GPT-4o mini, GPT-4.1 nano, GPT-5 nano, Gemini 2.5 Flash-Lite) are crossed against three prompting strategies (zero-shot, few-shot, chain-of-thought), evaluated against manual ground truth with bootstrapped 95% confidence intervals. Chain-of-thought prompting consistently and substantially outperformed zero-shot and few-shot prompting across models and fields; Gemini 2.5 Flash-Lite led on balanced accuracy/F1, though GPT-5 nano edged it on raw accuracy. Tumor size was the hardest field to extract across all models, due to inconsistent reporting formats. Downstream TNBC classification sensitivity topped out at 83% (GPT-5 nano) — a number the authors themselves flag as inadequate for autonomous clinical decision-making, framing the system explicitly as a decision-support tool requiring pathologist review. The paper does not benchmark against a rule-based/regex baseline, which it acknowledges as a limitation. The transferable pattern — schema-constrained JSON extraction plus chain-of-thought prompting plus bootstrapped per-field confidence intervals — serves the AI-tooling/career priority; the buildable artifact is a small, reusable extraction harness generalizable to any free-text clinical or registry field.

Plain-English glossary

  • Chain-of-thought (CoT) prompting — A prompting technique that asks the model to reason step by step before producing its final structured answer, as opposed to answering directly.（中文：一种提示技巧,要求模型在给出最终结构化答案之前先逐步进行推理,而不是直接给出答案。）
  • ER / PR (estrogen / progesterone receptor) — Two hormone receptors whose presence on breast cancer cells determines whether endocrine (hormone-blocking) therapy will be effective.（中文：两种激素受体,它们在乳腺癌细胞上的存在与否决定了内分泌(激素阻断)治疗是否有效。）
  • HER2 (human epidermal growth factor receptor 2) — A growth-signaling receptor; its overexpression on breast cancer cells determines whether HER2-targeted drugs will be effective.（中文：一种生长信号受体;乳腺癌细胞上该受体的过度表达决定了HER2靶向药物是否有效。）
  • Immunohistochemistry (IHC) — A staining technique that visualizes whether a specific protein (such as ER, PR, or HER2) is present in a tissue sample, and is the lab method that actually generates receptor-status results.（中文：一种染色技术,用于观察组织样本中是否存在某种特定蛋白质(如ER、PR或HER2),是实际产生受体状态结果的实验室方法。）
  • Ki-67 — A proliferation marker measuring how fast tumor cells are dividing, used alongside receptor status to characterize tumor aggressiveness.（中文：一种增殖标志物,衡量肿瘤细胞分裂的速度,通常与受体状态一起用于刻画肿瘤的侵袭性。）
  • Pathology report — A narrative clinical document written after tissue examination, containing gross description, microscopic findings, immunohistochemistry results, and final diagnosis, with no standardized structure across institutions.（中文：组织检查后撰写的叙述性临床文档,包含大体描述、显微镜下所见、免疫组化结果和最终诊断,不同机构之间没有统一的结构标准。）
  • Schema-constrained prompting — Prompting an LLM to return output in a strict, predefined JSON structure with named fields, rather than free-text prose.（中文：提示大语言模型以严格、预定义的JSON结构(含命名字段)返回输出,而不是自由文本叙述。）
  • TCGA / GDC (The Cancer Genome Atlas / Genomic Data Commons) — A public cancer genomics data resource and its API-accessible data portal, used here as the source of pathology report PDFs.（中文：一个公共癌症基因组学数据资源及其可通过API访问的数据门户,本文中用作病理报告PDF文件的来源。）
  • TNBC (triple-negative breast cancer) — A breast cancer molecular subtype defined by the absence of ER, PR, and HER2, which removes endocrine and HER2-targeted treatment options and is associated with worse outcomes.（中文：一种以ER、PR和HER2三者均为阴性定义的乳腺癌分子亚型,这意味着内分泌治疗和HER2靶向治疗都不适用,预后通常较差。）

Methods / tools to lift

  • Hierarchical sliding-window chunking — segmenting long documents on clinically meaningful boundaries (immunohistochemistry, diagnosis, microscopic findings) rather than arbitrary text splits.
  • OCR preprocessing pipeline — PDF-to-image at 300 DPI via pdf2image, text extraction via pytesseract, parallelized per-document across CPU workers.
  • Schema-constrained JSON extraction — prompting for strict, named-field JSON output suitable for direct loading into a structured database.
  • Chain-of-thought prompting — step-by-step reasoning before the final structured answer, shown here to substantially outperform zero-shot/few-shot across every field tested.
  • Bootstrapped per-field 95% confidence intervals — quantifying reliability per extracted field rather than reporting one blanket pipeline accuracy number.
  • Public GitHub repository with sample dataset, framework, and code.

Where it lands + buildable artifact

Serves the AI-tooling / career priority. MVP: A small, reusable LLM extraction harness — schema-constrained JSON prompts + chain-of-thought reasoning, run against a handful of small/fast models, with bootstrapped 95% confidence intervals computed per field against a small gold-labeled validation sample — generalizable to any free-text clinical or registry field needing structured extraction with a per-field trust score. Input: a free-text field + target JSON schema + small labeled validation set. Difficulty: S–M.

What to verify first

  • Performance against a real rule-based/regex baseline on our own data — this paper explicitly didn't make that comparison.
  • How much performance degrades on a different institution's reporting style, given the single-institution, 532-report TCGA dataset here.
  • Whether these models can be prompted toward calibrated probabilities rather than categorical output, if a confidence threshold is needed for routing to human review.
  • The actual human-review workload this pattern would produce downstream, given the authors' own 83% sensitivity caveat on the TNBC classification task.
