Ep2 (Track B) — 2026-08-28

A locally-hosted LLM pulled a sensitive label out of messy free text — without the data ever leaving the hospital

Wiest and colleagues (Br J Psychiatry, 2024) benchmarked three Llama-2 variants — a generic English model and two German-fine-tuned models ("Sauerkraut" and "Emgerman") — extracting a binary suicidality label from 100 psychiatric admission notes at a single German hospital, deployed entirely on local hardware via llama.cpp so no protected health information left institutional control. The best result, from the German fine-tuned "Emgerman" model with a three-example prompt, reached 87.5% accuracy, 83.0% sensitivity, and 91.8% specificity. The more transferable finding is about prompt sensitivity: the generic model was prompt-robust (balanced accuracy stayed 73–80% regardless of prompt design), while the fine-tuned model swung by roughly 21 points depending on how many in-context examples it got — and chain-of-thought prompting made every model worse, in one case collapsing sensitivity from 83% to 17%. The buildable artifact is a local-LLM extraction harness — an open-weights model deployed via llama.cpp, a few-shot prompt template, and a small hand-labeled evaluation sample — as a template for extracting structured labels from sensitive free text without a cloud API, if a relevant free-text field exists in a registry context.

Plain-English glossary

  • Locally-hosted / on-prem inference — running a model's weights and computation entirely on hardware the institution controls, so no data is sent to an external server.（中文：将模型权重和计算过程完全运行在机构自有掌控的硬件上，数据不会被发送至外部服务器。）
  • llama.cpp — an open-source C++ framework for running large language models efficiently on ordinary consumer-grade hardware rather than data-center GPUs.（中文：一个开源C++框架，用于在普通消费级硬件（而非数据中心GPU）上高效运行大语言模型。）
  • Fine-tuned model — a general-purpose foundation model further trained on domain- or language-specific data (here, German-language psychiatric text) to specialize its behavior.（中文：在通用基础模型之上，针对特定领域或语言的数据进一步训练，以使其行为专业化的模型，此处指德语精神科文本。）
  • In-context learning / few-shot prompting — teaching a model a task by including worked examples directly in the prompt, rather than updating the model's weights through training.（中文：通过在提示中直接给出示例来教会模型完成任务，而不是通过训练更新模型权重。）
  • Chain-of-thought prompting — a two-step prompting technique where a model first generates reasoning, then that reasoning is fed back in to produce a final answer; did not help and often hurt performance in this paper.（中文：一种两步提示技巧，模型先生成推理过程，再将该推理反馈回去以得出最终答案；在本文中该方法未能带来提升，往往反而降低了性能。）
  • Balanced accuracy — the average of sensitivity and specificity, used here to compare models fairly when the two classes (suicidal / not suicidal) aren't equally sized.（中文：敏感性与特异性的平均值，本文用它在两类样本（有/无自杀倾向）数量不均衡时公平比较模型表现。）
  • Ground truth (consensus) — the reference labels against which model output is checked; here, agreement between a resident and a consultant psychiatrist reading the same 100 notes.（中文：用于核验模型输出的参照标签；本文中为一名住院医师与一名主治精神科医师阅读同一批100份记录后达成的共识。）

Methods / tools to lift

  • Staged prompt-engineering protocol (P0 zero-shot → P1–P3 progressive few-shot → P4 chain-of-thought) as a systematic way to benchmark prompt design rather than guessing.
  • Bootstrapped (10,000-iteration) confidence intervals on every accuracy/sensitivity/specificity metric.
