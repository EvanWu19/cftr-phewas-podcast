Blurb

This episode covers "Initializing a hospital-wide data quality program: the AP-HP experience" (Daniel et al., 2019, Computer Methods and Programs in Biomedicine), which is abstract-only — the paper is genuinely closed access, confirmed via the Europe PMC core record, so everything here is drawn from the structured abstract alone. AP-HP, a 37-hospital Paris group, built a Clinical Data Repository for large-scale secondary research use of its EHR data and, motivated by the Learning Healthcare System idea, ran two data-quality (DQ) campaigns in 2017 across patient identification (PI, 8.8M patients) and healthcare services (HS, 13,099 consultation agendas + 2,122 care units). The paper's main contribution is operational, not statistical: it demonstrates the Kahn-framework-style completeness/conformance/plausibility taxonomy and a 5-phase scope-measure-analyze-improve-control campaign structure being used at scale, plus a three-way root-cause attribution (data originator / ETL / entry-tool limitation) that turns "11 issues found" into "16 actions with owners." It is not an anthropometrics paper and reports no sensitivity/PPV figures. For Liz's CFFPR height/weight data-quality task, this paper lands at the vocabulary/framework level (pipeline stage (e), with a secondary touch on (c) the human review budget), motivating a lightweight "DQ-dimension + root-cause issue tracker" — a tagging schema, not a new detection method.

Plain-English glossary

  • Completeness — one of the Kahn-framework DQ dimensions: whether data that should be present actually is.（中文：数据质量维度之一,指应存在的数据是否确实存在）
  • Conformance — whether data matches the expected format, type, or allowed values.（中文:指数据是否符合预期的格式、类型或允许的取值范围,也称规范符合性）
  • ETL (Extract-Transform-Load) — the pipeline that moves data from source EHR systems into a downstream research/analysis repository; a distinct root-cause bucket from human entry error.（中文:提取-转换-加载,将数据从源电子健康记录系统搬运到下游研究仓库的流程,是与人工录入错误不同的一类根本原因）
  • HS (Healthcare Services) — this paper's domain covering consultation scheduling and care-unit structure.（中文:医疗服务,本文中涉及门诊预约安排和护理单元结构的领域）
  • Kahn framework — a widely cited taxonomy for categorizing EHR/registry data-quality problems into dimensions such as completeness, conformance, and plausibility.（中文:一个被广泛引用的分类体系,用于将电子健康记录/登记库的数据质量问题归入完整性、一致性、合理性等维度)
  • Learning Healthcare System — a health system designed to continuously generate evidence from its own routinely collected data and feed it back into care.（中文:学习型医疗系统,指能持续从自身日常数据中产生证据并反馈回临床实践的医疗系统)
  • OMOP Common Data Model — a standardized schema that multiple health systems map their EHR data into, so DQ tools and studies can run unmodified across institutions.（中文:OMOP通用数据模型,一种标准化数据结构,使数据质量工具和研究可在不同机构间不加修改地运行)
  • PI (Patient Identification) — this paper's domain covering whether a patient's identity data is correct and not duplicated/fragmented.（中文:患者身份识别,本文中涉及患者身份数据是否正确、是否重复或分散的领域)
  • Plausibility — whether a value makes clinical or logical sense even if technically well-formed; the dimension a weird height/weight value would usually fall into.（中文:合理性,指数值在临床或逻辑上是否说得通,即使格式本身正确;奇怪的身高体重数值通常归入此类)
