Ep3 — Track C (1/2) — Erroneous adult height/weight in All of Us (Guide 2024)

Almost all published growth-cleaning methods are pediatric; this paper builds the missing adult-specific version. It fits a weighted GAMLSS reference model (mean, spread, skewness, and kurtosis, stratified by sex) on longitudinal All of Us EHR data, derives a kurtosis-aware modified standard deviation score (MSDS), and layers an EWMA-based trajectory check plus consecutive-measurement change cutoffs (8cm/height, 15kg within 180 days/weight) on top. On ~4.1M height and ~5.2M weight measurements, ~1.4%/1.5% got flagged, mostly by the consecutive-change rule. A 250-participant manual chart review found height sensitivity 90.4%/precision 73.4% and weight sensitivity 65.9%/precision 62.9% — with inter-rater kappa of only 0.65–0.78 between the two human reviewers, meaning the "gold standard" itself carries real disagreement. Against the original pediatric algorithm's raw-value adult extension, this method's height sensitivity went from 7.7% to 90.4% — strong evidence the adult reference chart, not just the trajectory logic, is what drives the improvement. Lands on candidate generation and evaluation methodology for the Liz-assigned CFFPR outlier work.

Plain-English glossary

EWMA (exponentially weighted moving average) — A method for estimating a person's expected value from their other measurements, weighting nearer-in-time points more heavily; the mechanism used to catch erroneous inliers.（中文:利用个体其他测量值来估计其预期数值的方法,时间上更接近的点权重更高;用于捕捉错误内点的核心机制。）

Erroneous inlier — A measurement that looks plausible for the general population but doesn't fit a specific person's own trajectory.（中文:对整体人群而言看似合理、但不符合某个人自身轨迹的测量值。）

GAMLSS / wGAMLSS — Generalized additive models for location, scale, and shape: a flexible reference-model framework that fits mean, spread, skewness, and kurtosis together; "weighted" (w) so people with many repeated measurements don't dominate the fit.（中文:位置-尺度-形状广义可加模型,一种可同时拟合均值、离散度、偏度与峰度的灵活参考模型框架;加权版本(w)可避免测量次数多的个体主导拟合结果。）

Kurtosis — A statistical property describing how heavy or thin the tails of a distribution are, relevant to how accurately extreme values get identified.（中文:描述分布尾部"厚"或"薄"程度的统计量,与能否准确识别极端值有关。）

LMS model — The lambda-mu-sigma model underlying CDC pediatric growth charts; fits three age-specific parameters (skewness, median, spread) but doesn't model kurtosis and assumes one measurement per person per age.（中文:CDC儿科生长曲线图所依据的lambda-mu-sigma模型;为每个年龄段拟合偏度、中位数、离散度三个参数,但不建模峰度,且假定每人每个年龄只有一次测量。）

Modified standard deviation score (MSDS) — A kurtosis-aware extension of the ordinary z-score, designed to stay accurate for extreme (tail) values.（中文:纳入峰度影响的标准差评分扩展版本,旨在对极端(尾部)数值也保持准确。）

Full citation

Methods / tools to lift

  • wGAMLSS reference-chart fitting for a population with unbalanced repeated measurements (not one-measurement-per-person).
  • MSDS as a kurtosis-aware alternative to plain z-scores for flagging extreme values.
  • EWMA-based erroneous-inlier detection with three variants (all-points, exclude-preceding, exclude-following).
  • Sensitivity-curve threshold selection (sweep candidate cutoffs, optimize precision at a target NPV).
  • Comparing a new algorithm against both an existing production cleaning process and the "naive" prior-generation method, on the same data.

Where it lands + buildable artifact

Pipeline stage: (a) candidate generation — an adult-specific reference-and-trajectory alternative to compare against a spline mixed-effects candidate generator, plus (d) evaluation — the kappa 0.65/0.78 finding is a direct, quantified caution about manual-review ground truth. Buildable: adult-wgamlss-reference-prototype (M) — fit a wGAMLSS-style reference model on synthetic/public longitudinal height-weight data, compute MSDS + EWMA flags, and reproduce the paper's sensitivity-vs-precision curve methodology as a benchmarking harness.

What to verify first

  • Generalization beyond one dataset — thresholds were largely inherited from the pediatric algorithm rather than independently derived from adult data.
  • Performance depends heavily on measurement frequency/spacing per the paper's own limitations section.
  • How a real, non-error trajectory inflection (e.g., a modulator-era weight jump) would be handled by the EWMA inlier logic — not tested in this paper.

Pipeline stage

(a) candidate generation (primary); (d) evaluation (secondary, via the inter-rater kappa finding).

Error types covered / not covered

Covered: absolute extreme values, erroneous inliers (trajectory-inconsistent but population-plausible), large consecutive-measurement jumps, carried-forward/repeated same-day values (flagged as warnings, not auto-excluded, for adults). Not covered / not tested: unit conversion errors, digit transposition, height/weight field swaps, real clinical-event-driven trajectory shifts (e.g., pregnancy, medication-driven weight change) versus data-entry error.

JORDAN Let's get the paediatric-versus-adult vocabulary sorted first. 我们先把儿科和成人之间的术语差异理清楚。 Pediatric growth charts, like the CDC ones, are built using something called the LMS model — can you unpack that? 像CDC那样的儿科生长曲线图是用一种叫LMS模型的方法构建的——你能解释一下吗? ALEX: LMS stands for lambda, mu, sigma — three parameters fit at each age that together describe a skewed distribution: mu is roughly the median, sigma is the spread, and lambda is a skewness/transformation parameter that lets the distribution be asymmetric instead of forcing a plain bell curve. LMS指的是lambda(偏度参数)、mu(位置参数)、sigma(离散度参数)——三个在每个年龄段分别拟合的参数,共同描述一个可以有偏度的分布:mu大致相当于中位数,sigma是离散程度,lambda则是一个偏度/变换参数,让分布可以是不对称的,而不必强行套用一个对称的钟形曲线。 The problem for adults is that LMS was built for one measurement per child at each age, whereas EHR data gives you an unbalanced number of repeated measurements per adult, and LMS also doesn't model kurtosis — how heavy or thin the tails of the distribution are — which turns out to matter for catching extreme values accurately. 但对成人来说,问题在于LMS是为"每个儿童在每个年龄只有一次测量"设计的,而电子病历里每个成人的重复测量次数是不均衡的,而且LMS也不建模峰度(kurtosis)——也就是分布尾部有多"厚"或多"薄"——而这一点对准确捕捉极端值其实很重要。

JORDAN So what did they use instead? 那他们用了什么替代方案? ALEX: A model called GAMLSS — generalized additive models for location, scale, and shape — which is a more flexible cousin of LMS that can fit not just the mean and spread but also skewness and kurtosis simultaneously, and they weighted it, calling the result wGAMLSS, so that people with many repeated measurements don't dominate the fit over people with only a few. GAMLSS(位置-尺度-形状广义可加模型)是一种比LMS更灵活的模型,可以同时拟合均值、离散度、偏度,还有峰度,而他们又给它加了权重,称之为wGAMLSS,这样测量次数多的人就不会在拟合中压过测量次数少的人。 From that model they derive a modified standard deviation score, or MSDS — an extension of the ordinary z-score that also accounts for kurtosis, so it stays accurate out in the tails where a plain z-score gets unreliable. 从这个模型出发,他们推导出了一个修正标准差评分(MSDS)——是普通z分数的扩展版本,同时纳入了峰度的影响,因此在分布尾部(普通z分数会变得不可靠的地方)依然保持准确。 And EWMA — exponentially weighted moving average — is the mechanism that lets the algorithm compare one measurement against the trend of a person's other measurements, weighting nearby-in-time values more heavily, which is how you catch an erroneous inlier: a value that's totally plausible for the population but doesn't fit that specific person's own trajectory. 而EWMA(指数加权移动平均)则是让算法把某次测量与该个体其他测量的趋势进行比较的机制,时间上更接近的数值权重更高,这正是捕捉"错误内点"的方法——也就是那种在人群里完全说得通、但不符合这个人自己轨迹的数值。

JORDAN Why did this need a whole new paper — what was the actual gap? 为什么这需要专门写一篇新论文——真正的空白在哪里? ALEX: Daymont's original growthcleanr algorithm was built for pediatric CDC growth charts and was later extended to run on adults, but that adult extension worked directly on raw measurement values because no adult reference chart existed — and the whole point of a reference chart, demonstrated in the pediatric literature, is that it makes the trajectory model far more sensitive to what's actually implausible for that person at that age and sex, not just implausible in some generic sense. Daymont最初的growthcleanr算法是为儿科CDC生长曲线图设计的,后来被扩展用于成人,但那个成人扩展版本是直接作用于原始测量值的,因为当时并不存在成人参考曲线图——而参考曲线图的意义,正如儿科文献所证明的那样,在于它能让轨迹模型对"这个人在这个年龄、这个性别下到底哪些是真正不合理的"变得敏锐得多,而不只是笼统意义上的不合理。 So the gap was straightforward: build the missing adult reference chart properly, using longitudinal EHR data instead of a clean cross-sectional cohort, and see whether a trajectory model built on top of it actually catches more real errors than the raw-value approach. 所以这个空白很直接:好好地把缺失的成人参考曲线图建出来,用纵向电子病历数据而不是干净的横截面队列,然后看看建立在其之上的轨迹模型,是否真的比直接用原始数值的方法能捕捉到更多真实错误。

第一,一个绝对极端值检查:如果MSDS的绝对值超过25,就直接标记为极端值——这是一个刻意设定得很保守的阈值,目的是让仅凭这条规则被剔除的数值,几乎肯定是真正的错误,而不是真实存在的离群值。 Second, the EWMA-based inlier check: they compute a person's expected MSDS from their other
