Ep3 (Track C, QC #1) — Data accuracy in the ECFSPR: on-site validation project (Naehrlich et al., 2025)

Blurb. Automated registry checks (range/logic/consistency rules) can't catch a value that's internally plausible and consistent but simply wrong — e.g. a reasonable height pulled from the wrong clinic visit. On-site source-record verification is the only way to catch that error class, and this project did it at real scale: teams visited 133 of 397 centres across 34 countries and checked 4,024 people with CF's registry data against their original medical records. Simple demographic fields (DOB, sex, transplant status) were >99% accurate; genetic variant data was accurate 96.6% of the time when an original lab report existed, but a report was only available for 85.2% of people. Height, weight, and FEV1 — exactly the variables the Liz assignment cares about — were the least accurate of 16 variables checked (87–89%), and the paper traces this specifically to encounter-selection errors (picking the wrong visit/date under a complex "best value of the year" rule), not simple data-entry typos. Multiple independent national registries (Switzerland, France, US, UK) show the same pattern. Serves as an external, source-verified accuracy benchmark for the Liz assignment — no claims about CFFPR's own internals.

Plain-English glossary

  • On-site data validation — a validation method where the true value is confirmed by comparing registry-submitted data directly against the original source medical record at the reporting centre, as opposed to automated internal-consistency checks.（中文：一种验证方法，通过直接将登记库提交的数据与报告中心的原始病历进行比对来确认真实值，区别于自动化的内部一致性检查。）
  • MHR (medical health record) — the original clinical record at the reporting centre, used here as the ground-truth source against which registry data is checked.（中文：报告中心保存的原始临床病历，本文用作核对登记库数据的真值来源。）
  • Representativeness — a data-quality dimension: whether the people captured in a registry reflect the true target population.（中文：数据质量维度之一：登记库中收录的人群是否反映了真实的目标人群。）
  • Completeness — a data-quality dimension: whether, for the people captured, all relevant fields are actually filled in.（中文：数据质量维度之一：对已收录的人群，相关字段是否都被实际填写。）
  • Accuracy — a data-quality dimension: whether the recorded value matches the true value in the source record (the focus of this paper).（中文：数据质量维度之一：记录的数值是否与源记录中的真实值相符（本文的核心关注点）。）
  • Validity — a data-quality dimension: whether a recorded value actually adheres to the registry's own definition for that variable (a technically-true number under the wrong definition still counts as an error).（中文：数据质量维度之一：记录的数值是否真正符合登记库对该变量的定义（技术上真实但套用错误定义的数值仍算错误）。）
  • Encounter-selection error — an error where the recorded value itself is plausible, but comes from the wrong clinical visit/date under a complex selection rule (e.g. "last measurement of the year" or "visit with the best FEV1%pred").（中文：一类错误：记录的数值本身合理，但根据复杂的选择规则（如"年度最后一次测量"或"最佳FEV1%pred就诊"）挑选时选错了就诊日期/记录。）

Methods / tools to lift

  • Root-cause attribution (encounter-selection vs. measurement error) — distinguishing why a field is inaccurate, not just that it is, as a design input for candidate generators.

  • On-site visits covered 133/397 centres, likely skewed toward willing/better-resourced sites (flagged by the authors themselves) — not a random sample of the true population-wide accuracy.

Error types covered / not covered

Covered: encounter/visit-selection errors under a complex "best value of the year" definition; missing source documentation for genetic variants; report-vs-registry genotype mismatches. Not covered: unit conversion errors, digit transposition, decimal-shift errors, carry-forward (stale value repeated across visits), or real-clinical-event vs. data-error discrimination — this paper measures whether values match source records, not why a value is physiologically implausible.
