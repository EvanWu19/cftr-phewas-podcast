Ep2 — Track B — AI Tooling & Pipeline Architecture

Blurb

Lam et al. (2020, Bioinformatics) introduce RICOPILI, the Psychiatric Genomics Consortium's open-source Perl/R pipeline that automates the full multi-cohort genome-wide association study (GWAS) workflow: technical/genomic QC with automated red/yellow/green flags, principal-components-based ancestry/relatedness filtering, phasing and imputation against 1000 Genomes or the Haplotype Reference Consortium panel, and downstream association, meta-analysis, LD score regression, and polygenic risk scoring — all portable across SLURM, QSUB, BSUB, and Google Cloud Platform, and shipped with a deliberately-flawed simulated training dataset. RICOPILI is credited as the main pipeline behind the PGC's most-cited GWAS output (108 schizophrenia loci) and has been used by 112 analysts supporting 800+ investigators internationally. This lands in the AI-tooling/career lane: not as a tool to adopt directly, but as a mature reference architecture for exactly the kind of reproducible, cluster-portable, multi-step analysis pipeline a senior RWE-and-genomics data scientist gets evaluated on building — seeding a buildable, modernized reimplementation of its module-per-stage QC-flag design.

Plain-English glossary

  • GWAS (genome-wide association study) — a study design that scans hundreds of thousands to millions of genetic markers in a large cohort and tests each for statistical association with a trait or disease.（中文：一种研究设计，在大型队列中扫描数十万到数百万个遗传标记，逐一检验其与某性状或疾病的统计学关联。）
  • Imputation — statistically filling in genotypes not directly measured by an array, using a densely-sequenced reference panel and linkage disequilibrium patterns.（中文：利用高密度测序参考面板和连锁不平衡模式，统计学地补全芯片未直接测量到的基因型。）
  • Linkage disequilibrium (LD) — the tendency of nearby genetic variants to be inherited together as a block, which imputation exploits to infer untyped genotypes.（中文：相邻遗传变异倾向于作为一个整体被共同遗传的现象，基因型填补正是利用这一特性来推断未直接测量的基因型。）
  • Phasing — determining which alleles sit together on the same physical chromosome copy (haplotype), a prerequisite for imputation.（中文：判断哪些等位基因位于同一条染色体拷贝（单倍型）上，是基因型填补的前提步骤。）
  • Polygenic risk score (PRS) — a single per-person score summarizing overall genetic risk for a trait by summing the weighted effects of many variants from a GWAS.（中文：将GWAS中众多变异的加权效应加总为单一个体评分，用以概括某性状的总体遗传风险。）
  • Reference panel (1000 Genomes / HRC) — a collection of densely sequenced genomes used as the statistical backbone for imputation.（中文：用作基因型填补统计基础的高密度测序基因组集合，如千人基因组计划或单倍型参考联盟（HRC）。）

Full citation

Lam M, Awasthi S, Watson HJ, et al. RICOPILI: Rapid Imputation for COnsortias PIpeLIne. Bioinformatics. 2020. PMID: 31393554 | PMC7868045 | DOI: 10.1093/bioinformatics/btz633

Methods/tools to lift

  • EIGENSTRAT — standard tool for computing genetic principal components to flag ancestry outliers and population stratification.
  • Eagle / SHAPEIT — haplotype phasing tools used ahead of imputation.
  • IMPUTE / Minimac — genotype imputation engines run against 1000 Genomes / HRC reference panels.
  • METAL — fast meta-analysis tool for combining GWAS summary statistics across cohorts.
  • HAPGEN — simulator used to generate a synthetic, deliberately-flawed training/onboarding dataset.
  • Automated red/yellow/green QC flags — heuristic per-parameter traffic-light triage for cohort-level quality control.
  • Cluster-job parallelization — portability across SLURM, QSUB, BSUB, and Google Cloud Platform for scaling to large multi-cohort jobs.

Where it lands + buildable artifact

Serves the AI-tooling/career priority. Buildable artifact: pipeline-qc-flags-lite — input any tabular multi-cohort/multi-batch dataset (not necessarily genomic) plus a config file of per-field QC thresholds; the tool runs red/yellow/green flagging RICOPILI-style, implemented in a modern workflow engine (Snakemake/Nextflow) for declarative, auditable QC logic, and ships with a small synthetic dataset seeded with known problems for verification. Difficulty: M (straightforward flagging logic, but a clean workflow-engine implementation plus a genuinely useful synthetic test dataset is real design work).

What to verify first

  • How current RICOPILI's default reference panels and phasing tools still are, given that panels like TOPMed have grown substantially since HRC and this paper is from 2020.
  • Whether the pipeline has been validated or adapted outside psychiatric genetics before assuming its defaults transfer to a different disease area.
  • What has changed in workflow-engine best practice (Nextflow/Snakemake) since 2020 before directly porting the Perl-centric architectural choices.
  • This paper says nothing about what pipeline architecture, if any, is currently used for CFFPR data processing — separate, unverified question.
