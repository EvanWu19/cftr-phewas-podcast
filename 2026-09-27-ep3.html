Ep3 (Track C, 1 of 2) -- Improving reliability and accuracy of structured data extraction using a consensus large-language model approach: a use case description in multiple sclerosis

Poser PL, et al. 2026. Frontiers in Artificial Intelligence. PMID 41766943 / PMC12946029 / DOI 10.3389/frai.2026.1658575.

A German neuroimmunology group benchmarks a consensus of three flagship LLMs (Claude Sonnet-3.7, Gemini-2-pro, o3-mini) against a human reference for extracting 19 structured variables of varying complexity from 30 anonymized MS outpatient reports. A JSON structured-output function eliminates formatting errors outright (versus up to 147 column errors under naive prompting), and after nine rounds of prompt refinement, individual models plateau around 11.1% content-error rate -- a ceiling the three-model consensus breaks through, reaching a 1.48% true-error rate, statistically indistinguishable from trained neurology specialists (~2%, p=0.6447), for under a dollar and a few minutes versus roughly five hours of staff time. The paper's own choice to exclude non-consensus cases from the error count, rather than counting them as unresolved, is worth watching -- those are plausibly the hardest cases. The buildable artifact treats this as an adjudication and review-budget tool: an independent, cheap second opinion straight from a flagged record's underlying free text, not a new way to generate flags.

Plain-English glossary

  • Chart abstraction -- the traditional, labor-intensive process of a trained human reading unstructured clinical notes and converting relevant facts into structured, analyzable fields.（中文：传统的、劳动密集型的病历摘录过程，由经过培训的人员阅读非结构化临床记录，并将相关事实转化为结构化、可分析的字段。）
  • Consensus (multi-model) -- accepting an LLM-extracted value only when at least two of several independently-run models agree, used here to push past a single model's error-rate ceiling.（中文：只有当多个独立运行的模型中至少两个结果一致时，才采用LLM提取出的数值，本文用它来突破单一模型的错误率天花板。）
  • EDSS (Expanded Disability Status Scale) -- the standard 0-10 clinical disability scale in multiple sclerosis, derived from a structured neurological exam but often described only in prose in a clinic note.（中文：多发性硬化症的标准0-10分临床残疾量表，来自结构化的神经系统检查，但在临床记录中常常只以文字描述的形式出现。）
  • Oligoclonal bands (OCBs) / AQP4 and MOG antibody status -- laboratory and serological markers used in MS diagnosis, extracted here as test variables of varying complexity.（中文：用于多发性硬化症诊断的实验室和血清学标志物，本文将其作为不同复杂度的测试变量进行提取。）
  • Structured output function -- a built-in LLM API feature (as opposed to a plain-text prompt) that constrains a response to a defined JSON schema, essentially eliminating column-naming and column-count errors.（中文：LLM API的一项内置功能（区别于纯文本提示），将响应限制在一个预定义的JSON schema内，基本消除了列命名和列数错误。）
  • True-error rate -- this paper's stricter error metric, counting only deviations from the human reference that could not be justified by a defensible alternative reading of the source note.（中文：本文使用的一种更严格的错误率指标，只统计那些无法用对原始记录的合理替代解读来解释的偏差。）

Methods / tools to lift

  • JSON structured-output API functions -- constrain LLM responses to a schema, eliminating formatting/column errors outright.
  • Field-level typing + enumerated categorical values -- layered fixes that cut data-type errors by up to 88% on top of a structured-output function.
  • Multi-model majority-vote consensus -- a cheap way to approximate a second opinion and push past a single model's accuracy ceiling.
  • True-error-rate adjudication -- distinguishing genuine content errors from defensible edge-case interpretations before counting a deviation as an error.

Where it lands + buildable artifact

Serves Liz / CFFPR data quality (method only). Buildable: consensus-extraction adjudication assistant (S-M) -- given a flagged record's underlying free-text source (public/synthetic notes only) and the specific field in question, run 2-3 LLMs, report agreement/disagreement, and validate the split against a small test set with known ground truth.

What to verify first

  • Whether any underlying free-text source even exists behind a flagged anthropometric value -- an internal registry-provenance question this podcast doesn't assume an answer to.
  • Whether excluding non-consensus cases (rather than counting them as inconclusive) understates the real-world error rate, since those are plausibly the hardest cases.
  • That the human reference itself was a constructed consensus (unanimous agreement among two specialists and two residents), not an externally validated gold standard.
  • Generalizability from 30 monocentric, German-language MS reports to a CF registry's own clinical-note vocabulary and structure, which is unverified rather than assumed.

Pipeline stage

(b) adjudication, primary -- an independent consensus re-extraction from underlying source text as a second opinion on a flagged value. (c) human review budget, secondary -- model agreement is cheap and near-human-reliable, so agreement cases can route to faster resolution while disagreement cases get full human review.

Error types covered / not covered

Covered (indirectly, via adjudication rather than detection): ambiguous or context-dependent values where the correct read requires interpreting surrounding prose (e.g. walking distance inferred from exam findings). Not covered: unit mismatch, decimal-place shift, transposed digits, or carry-forward errors at the structured-field level -- this paper never touches a numeric anthropometric field, and its consensus mechanism only helps once an underlying free-text source exists to re-extract from.
