How did this episode land for you?

Track C — registry data quality. Charlotte Woolley and colleagues (Edinburgh) benchmark five growth-data cleaning methods — general cutoff, standard z-score, temporal z-score, non-linear regression, and non-linear mixed-effects (NLME) models — against four uncleaned canine longitudinal datasets and one human cohort (CLOSER) with gold-standard simulated errors (12 error types, injected at rates from 0.1% to 50%). NLME modeling, which fits each individual's own random-effect deviation from the population growth curve, was the strongest baseline (26 points higher sensitivity on average) and improved further with a five-step correct-don't-delete decision algorithm (duplicate check, transposition check, largest-plausible-change check, hard biological bounds) that pushed sensitivity up another 7.68 points. The method's R code is public as growth_cleanR. For CFFPR-style registry work, this is primarily a candidate-generation upgrade — individual-trajectory prediction intervals catch data-entry errors a fixed population cutoff would miss, and avoid over-flagging patients who are legitimately far from the population average — with the five-step decision logic offering concrete rules for the adjudication layer too.

Plain-English glossary

Far outlier — in this paper's convention, a measurement more than 4 standard deviations from its predicted value, stricter than the common 3-SD rule.（中文:本文惯例中,指偏离预测值超过4个标准差的测量值,比常见的3倍标准差规则更严格。）

Non-linear mixed-effects (NLME) model — a growth-curve model (here, modified Gompertz/asymptotic curves) that lets each individual have their own random-effect deviation from the population trajectory.（中文:一种生长曲线模型(此处为修正的Gompertz/渐近曲线),允许每个个体拥有相对于群体轨迹的随机效应偏差。）

Gold-standard error simulation — an evaluation method that injects known synthetic errors into clean data so sensitivity/specificity can be measured against true ground truth rather than estimated.（中文:一种评估方法,向干净数据中注入已知的合成错误,从而可以对照真实值直接测量敏感度和特异度,而非估算。）

Correct-don't-delete decision algorithm — a five-step rule set (duplicate removal, transposition check, plausible-change check, hard bounds) that corrects suspected errors where possible instead of deleting the record.（中文:一套五步规则(去重、换位检查、合理变化检查、硬性边界),在可能的情况下纠正可疑错误而不是直接删除记录。）

MVP: a prototype NLME prediction-interval model for one anthropometric measure with individual random effects, paired with a lightweight duplicate/transposition/plausible-change/hard-bounds decision layer, validated using the paper's gold-standard synthetic error injection method. Difficulty: M.

What to verify first

  • The NLME method converged in only 76.36% of simulation runs — a fallback path for non-convergent cases needs its own design and validation, not treatment as a rare edge case.
  • Growth curves here are fit to canine and UK-cohort human data; CF-specific (and possibly modulator-era-specific) growth trajectory shapes would need their own curve fitting.
  • Implausibility bounds (e.g., 250 kg weight ceiling) were set from the authors' domain knowledge of their datasets — any CFFPR adaptation needs its own clinically-grounded bounds.
  • Nothing here implies anything about CFFPR's actual current flag rate or existing cleaning rules.

Error types covered: unit conversion, digit transposition, multiply/divide by 10/100/1000, additive shift (+100/+1000), random substitution, exact and near-duplicate entries. Not covered: carry-forward errors, and real-clinical-event vs. data-entry-error confusion beyond the plausible-change/hard-bounds heuristics.
