Blurb

Rigby & Stasinopoulos (2014, Statistical Methods in Medical Research) is a foundations paper, not an applied cohort study — the original GAMLSS authors solving their own framework's practical bottleneck: how to automatically select the smoothing parameters that shape the L, M, S (and optionally kurtosis) curves underlying growth charts and other centile-based reference systems. The method reformulates a P-spline smoothing term as a random effect with a variance parameter mathematically tied to the smoothing parameter, then estimates it via "internal"/"local" maximum likelihood on the predictor scale of each distribution parameter — a fast, automatic, likelihood-based alternative to hand-tuning or grid search across up to four parameters at once. Closed access, no PMCID — abstract-only. This paper doesn't change the CFFPR outlier pipeline directly; it's vocabulary/framework (e) — the statistical engine underneath essentially every centile-based growth-chart method this track has already covered, including the LMSz gene-specific growth chart paper. Understanding it changes how much trust to place in any tool that flags "outside the 0.4th/99.6th percentile," since that boundary is only as stable as the smoothing choice behind the underlying curve.

Plain-English glossary

  • GAMLSS (generalized additive models for location, scale and shape) — a modern statistical framework that models up to four parameters of a distribution (location, scale, skewness, kurtosis) as smooth functions of a covariate like age.（中文：位置-尺度-形状广义可加模型，一种现代统计框架，可将分布的最多四个参数——位置、尺度、偏度、峰度——建模为如年龄等协变量的平滑函数。）
  • LMS method — the classical three-parameter (L, M, S) version of this model underlying most growth charts: L (Box-Cox skewness power), M (median), S (coefficient of variation).（中文：该模型的经典三参数版本，是大多数生长曲线图的基础：L为Box-Cox偏度幂次，M为中位数，S为描述离散程度的变异系数。）
  • P-spline (penalized spline) — a flexible smooth curve built from many small basis functions, with a penalty term discouraging excessive wiggliness.（中文：一种带惩罚项的样条曲线，由许多小的基函数构成，惩罚项用于抑制曲线出现过多抖动。）
  • Smoothing parameter — controls how heavily the wiggliness penalty is weighted; too high flattens real signal, too low overfits noise.（中文：控制抖动惩罚权重大小的参数；数值过高会抹平真实信号，过低则会过拟合噪声。）
