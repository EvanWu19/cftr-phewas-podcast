Show Notes — Track A — Functional Assays Are Essential for Interpretation of Missense Variants (Raraigh et al., 2018)

Blurb. Raraigh, Cutting, and colleagues at Johns Hopkins took 48 CFTR missense variants associated with variable expressivity of cystic fibrosis and measured what each one actually does to the chloride channel, using mutants stably integrated into a native isogenic human airway cell line that lacks endogenous CFTR. Of 29 variants tied to the full (severe) phenotype, 21 produced <10% of wild-type CFTR function and 5 were moderate (10–25%), but 3 unexpectedly retained >25% (two above 75%); of 19 partial-expressivity variants, 14 had >25% function while 4 had essentially none (>75%). Net result: 6 of 48 (13%) supposedly disease-causing variants did not alter CFTR function at all, and four computational predictors — CADD, REVEL, SIFT, and PolyPhen-2 — could not separate severe from moderate from minimal loss of function. Plugged into the ACMG/AMP framework, the functional data substantially refined pathogenicity calls. Where it lands: the Karen / variant-interpretation priority. Buildable artifact: a CFTR missense calibration table + notebook that plots predictor scores against measured %WT-CFTR function to map where the tools mis-rank. Fetched abstract-only (Europe PMC core); flagged on-air.

Plain-English glossary

  • ACMG/AMP framework — the standard rulebook clinical labs use to classify a variant as pathogenic, benign, or uncertain, combining multiple lines of evidence.（中文：美国医学遗传学学会与分子病理学会联合制定的变异致病性分类标准，综合多种证据给变异定级。）
  • CFTR chloride channel function — how much chloride a given CFTR protein moves across the cell membrane, expressed as a percentage of the normal (wild-type) version.（中文：某个 CFTR 蛋白搬运氯离子的能力，以正常版本的百分比表示。）
  • Functional assay — a wet-lab measurement of what a protein actually does, as opposed to a computational prediction of what it might do.（中文：在实验室直接测量蛋白质实际功能的实验，而非计算预测。）
  • Isogenic (native isogenic context) — cell lines that are genetically identical except for the single variant introduced, so any measured difference is attributable to that variant.（中文：除了引入的那一个变异外，遗传背景完全相同的细胞系，使差异可归因于该变异。）
  • Missense variant — a single DNA change that swaps one amino acid for another; the protein is still made but with one building block changed.（中文：一个碱基改变导致一个氨基酸被替换，蛋白仍合成但有一处改变。）
  • Variable expressivity — when people carrying the same variant differ in disease severity (vs. penetrance, which is whether disease occurs at all).（中文：携带同一变异的人病情严重程度不同；与外显率——是否发病——相对。）
  • Wild-type (WT) — the normal, non-mutated reference version of the gene or protein.（中文：基因或蛋白正常的、未突变的参照版本。）

Methods / tools to lift

  • Native isogenic stable-expression assay — measures variant chloride function at near-physiological levels (avoids overexpression masking partial defects).
  • %WT-CFTR thresholds — <10% = severe / life-limiting; ~10–25% = moderate; >25% (esp. >75%) = likely non-disease-causing — a quantitative scale for pathogenicity.
  • ACMG/AMP integration — functional results applied as PS3/BS3-style evidence to refine clinical classification.
  • Predictor benchmarking — CADD, REVEL, SIFT, PolyPhen-2 scores compared against measured function as ground truth.

Where it lands + buildable artifact

Serves Karen / variant interpretation. Paste-ready MVP: Build a CFTR missense calibration notebook that joins each variant to its published functional %WT-CFTR value, its CADD/REVEL/AlphaMissense scores, and its CFTR2 clinical label, then plots predictor score vs. measured function and flags mis-ranked variants. Input: public variant tables (this paper + follow-ups), CFTR2, gnomAD, precomputed predictor scores. Difficulty: S–M (join + scatter + residual analysis, no new model).

What to verify first

  • Whether the cell-line %WT-CFTR readings agree with orthogonal measures (organoid swelling, nasal potential difference) before treating percentages as ground truth.
  • Whether predictor failures generalize beyond this variable-expressivity-enriched set to clearly-severe and clearly-benign variants.
  • Whether newer predictors (AlphaMissense, ESM-based) close the gap — the 2018 comparison predates them; re-run before concluding the gap persists.
