Data Extraction and Curation from Radiology Reports for Pancreatic Cyst Surveillance Using Large Language Models

Choubey et al. Journal of the American College of Surgeons, 2025.

Blurb

A single-center retrospective study of 991 patients under pancreatic-cyst surveillance, spanning 3,198 longitudinal scans, tested whether zero-shot GPT-4 prompting — no training data, no fine-tuning — could extract nine structured radiographic variables from free-text radiology reports: the exact "worrisome feature" and "high-risk stigmata" fields that IPMN surveillance guidelines use to risk-stratify pancreatic cysts. Against a manually annotated institutional database as ground truth, categorical variables hit 97-99% accuracy and continuous variables 92-97%, with the interesting twist that Cohen's kappa favored cyst size (0.92) over MPD size (0.82) despite MPD's higher raw accuracy — a reminder that accuracy and kappa can diverge under skewed value distributions. The weakest field was multi-class lesion counting, at 81%. This is a directly transferable blueprint for any registry that needs longitudinal structured variables pulled from unstructured clinical text, and the episode sketches a lightweight zero-shot extractor with a built-in accuracy-plus-kappa evaluation harness as the buildable artifact. Note: full text was unavailable through any route tried today; the episode is built entirely from an unusually detailed structured abstract.

Plain-English glossary

  • IPMN (intraductal papillary mucinous neoplasm) — a cystic pancreatic lesion that can remain benign for years but in a minority of cases progresses toward malignancy, hence structured surveillance.（中文:导管内乳头状黏液性肿瘤,一种胰腺囊性病变,可能多年保持良性,但少数病例会进展为恶性肿瘤,因此需要结构化监测。）
  • Worrisome features / high-risk stigmata — the Fukuoka-style consensus terms for radiographic findings (e.g., MPD dilation, cyst growth, solid components) used to risk-stratify pancreatic cysts and decide on surveillance intensity or surgery.（中文:福冈共识标准中用于对胰腺囊肿进行风险分层、决定监测强度或是否手术的放射学表现分类术语。）
  • Zero-shot prompting — using a general-purpose LLM with instructions alone, no task-specific labeled training examples, to perform an extraction or classification task.（中文:仅用指令提示通用大语言模型完成提取或分类任务,不提供任何任务专用的标注训练样本。）
  • Cohen's kappa — a chance-corrected agreement statistic; can diverge from raw accuracy when a variable's true values are skewed toward one category.（中文:一种校正了偶然一致性的统计量;当变量真实取值分布不均衡时,可能与原始准确率产生分歧。）
  • Registry-abstraction bottleneck — the general problem of a registry's source data living in unstructured free text, requiring manual reading and re-entry to populate structured fields.（中文:登记系统源数据存在于非结构化自由文本中,需要人工阅读并重新录入才能填充结构化字段的普遍问题。）

Methods / tools to lift

  • Zero-shot GPT-4 prompting for structured-variable extraction from free-text radiology reports, no fine-tuning.
  • Per-field evaluation against a manually curated ground-truth database, reporting both accuracy and Cohen's kappa.
  • Mapping extraction targets directly onto an established clinical risk-stratification rule (Fukuoka-style IPMN criteria) rather than an arbitrary field list.

Where it lands + buildable artifact

Serves AI-tooling / career track. Buildable: a lightweight zero-shot registry-field extractor — input a batch of free-text notes plus a target-variable schema (categorical/continuous/multi-class); output structured JSON with per-field confidence, plus an evaluation harness computing accuracy and kappa against a small hand-labeled validation set. Difficulty: S-M.

What to verify first

  • Whether the target free-text source has enough unstructured content, and whether the fields of interest have a validated downstream use, to make extraction worthwhile.
  • External validity to a different institution's dictation style, template, or abbreviation conventions — this is single-center, single model version.
  • Error rate already baked into the manually annotated ground-truth database itself.
  • PHI / data-governance requirements for routing clinical text through an external LLM API, before any pilot.
  • Whether results are GPT-4-specific or generalize across capable general-purpose models — not tested in this paper.
