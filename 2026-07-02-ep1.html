Blurb

The ClinGen Sequence Variant Interpretation Splicing Subgroup (Walker et al., Am J Hum Genet 2023) fixes a real inconsistency: the ACMG/AMP rulebook has six evidence codes that touch splicing (PVS1, PS3, PP3, BS3, BP4, BP7), but no shared guidance on how to apply them, so gene-specific expert panels each invented their own specifications. Using empirically derived splicing evidence, the subgroup sets weightings and code choices for general use, outlines how to fold splicing into a gene-specific PVS1 decision tree, and gives a methodology to calibrate splice-prediction tools. Headline recommendations: repurpose PVS1_Strength to carry RNA-assay evidence of loss-of-function transcripts; use BP7 for RNA results showing no splicing impact in intronic/synonymous variants; reserve PS3/BS3 for well-established assays measuring effects not captured by an RNA-splicing assay; and invoke PS1 on the basis of similar predicted splicing effect to a known-pathogenic variant. Where it lands: the Karen / variant-interpretation priority — specifically a CFTR splice-evidence router that runs variants through SpliceAI and maps each to these codes, the splice counterpart to the missense PP3/BP4 calibration notebook. Read abstract-only (not open access; full threshold tables not in hand).

Plain-English glossary

  • Cryptic splice site — a sequence that isn't normally used for splicing but gets activated by a variant, causing the splicing machinery to cut in the wrong place.（中文：隐蔽剪接位点——本来不用于剪接、却被变异激活的序列，导致剪接机器在错误的位置剪切。）
  • Exon / intron — exons are the coding pieces of a gene that are kept; introns are the pieces between them that are cut out during splicing.（中文：外显子/内含子——外显子是基因中被保留的编码片段，内含子是它们之间、在剪接时被剪掉的片段。）
  • Exon skipping — when a variant destroys a splice site so an entire exon is left out of the mature transcript.（中文：外显子跳跃——变异破坏了剪接位点，导致整个外显子从成熟转录本中被漏掉。）
  • HGVS — the standardized written notation for describing a variant precisely.（中文：HGVS——精确描述变异的标准化书写规范。）
  • PVS1 / PS3 / PP3 / BS3 / BP4 / BP7 — the six ACMG/AMP evidence codes relevant to splicing: PVS1 (very strong, likely loss-of-function), PS3/BS3 (functional-assay, pathogenic/benign), PP3/BP4 (computational prediction, pathogenic/benign), BP7 (benign; silent/intronic with no predicted splice effect).（中文：ACMG/AMP中与剪接相关的六条证据代码：PVS1为"非常强、疑似功能丧失"，PS3/BS3为功能实验的致病/良性代码，PP3/BP4为计算预测的致病/良性代码，BP7为"无预测剪接影响的沉默/内含子变异"良性代码。）
  • PVS1_Strength — a strength-adjustable version of PVS1, here repurposed to carry RNA-assay evidence at a dialed weight.（中文：PVS1_Strength——PVS1的强度可调版本，这里被重新用来以调节后的权重承载RNA实验证据。）
  • RNA-splicing assay — an experiment (usually RT-PCR on patient RNA) that reads out which transcripts a variant actually produces.（中文：RNA剪接实验——通常是对患者RNA做RT-PCR，读出某变异实际产生了哪些转录本的实验。）
  • Splice donor / acceptor site — the short signal sequences at the start and end of an intron that the splicing machinery uses to find intron boundaries.（中文：剪接供体/受体位点——内含子起点和终点的短信号序列，剪接机器靠它们找到内含子边界。）
  • Splicing — the cut-and-paste step where introns are removed and exons joined to make the mature RNA.（中文：剪接——去除内含子、拼接外显子以形成成熟RNA的"剪切—粘贴"步骤。）
  • Synonymous variant — a DNA change that doesn't alter the amino acid, but can still disrupt splicing.（中文：同义变异——不改变氨基酸的DNA变异，但仍可能破坏剪接。）
  • VCEP (Variant Curation Expert Panel) — a gene-specific ClinGen committee that writes classification rules for its gene.（中文：VCEP——ClinGen针对特定基因的专家组，为该基因编写分类规则。）

Methods / tools to lift

  • ACMG/AMP splice code mapping — the direction-of-evidence assignment: RNA loss-of-function → PVS1_Strength; RNA no-impact (intronic/synonymous) → BP7; non-RNA validated functional effect → PS3/BS3; predicted-splice-similarity to a known pathogenic variant → PS1.
  • Gene-specific PVS1 decision tree — the flowchart process for deciding whether a predicted LoF variant earns "very strong" or a downgraded strength, extended to splice-affecting variants.
  • Splice-tool calibration methodology — derive score→evidence-strength mapping from a set of variants with known RNA outcomes, rather than a vendor default cutoff.
  • SpliceAI — deep-learning splice-effect predictor (the "predicted" input to the framework).

Where it lands + buildable artifact

  • Priority: Karen / variant interpretation (splice lane).
  • Artifact — CFTR splice-evidence router (S–M): input a list of CFTR variants in normalized HGVS; run each through SpliceAI; map results to this paper's codes (predicted disruption → PVS1/PP3; predicted no-impact intronic/synonymous → BP7; existing RNA assay → PVS1_Strength/BP7 experimental path); output a per-variant splice-evidence table that merges with the missense PP3/BP4 lane.

What to verify first

  • Abstract-only — obtain the full paper's specification tables and exact strength assignments before coding the code-mapping table.
  • Calibrate SpliceAI for CFTR specifically, not a genome-wide default cutoff (score ≠ evidence until dosed to strength).
  • Confirm any "RNA assay" flag corresponds to a well-established assay, per the paper's PS3/BS3 reservation — not a one-off RT-PCR.
  • Ensure deep-intronic variants are in-scope (a coding-only pipeline would drop exactly the variants where splice prediction matters).
  • Public method on public CFTR variants only — no registry internals.

ALEX Sure. 好。A human gene is not one continuous stretch of coding sequence — it's broken into coding pieces called exons separated by non-coding pieces called introns. 人类的基因不是一段连续的编码序列——它被分成叫做外显子（exon）的编码片段，中间被叫做内含子（intron）的非编码片段隔开。When the gene is transcribed into RNA, the cell has to cut out the introns and stitch the exons together, and that cut-and-paste step is called splicing. 当基因被转录成RNA后，细胞必须把内含子剪掉、把外显子拼接起来，这个"剪切—粘贴"的步骤就叫剪接。The machinery finds the boundaries using short signal sequences: a splice donor site at the start of each intron and a splice acceptor site at its end. 剪接机器靠一些短的信号序列来找到边界：每个内含子起点的剪接供体位点（splice donor site）和终点的剪接受体位点（splice acceptor site）。A variant can break splicing in a few ways. 一个变异可以通过几种方式破坏剪接。It can destroy a real splice site so an exon gets skipped entirely, it can create a brand-new "cryptic" splice site so the machinery cuts in the wrong place, or it can weaken a site so you get a mix of correct and incorrect transcripts. 它可以破坏一个真正的剪接位点，导致某个外显子被整段跳过（exon skipping，外显子跳跃）；也可以造出一个全新的"隐蔽"剪接位点（cryptic splice site，隐蔽剪接位点），让机器在错误的地方剪切；还可以只是削弱某个位点，让你得到正确和错误转录本的混合物。And here's the part that matters clinically: a variant doesn't have to sit in the protein-coding letters to do this. 而临床上关键的一点是：一个变异不必落在蛋白质编码的字母上才能干这件事。A deep-intronic variant, or even a synonymous variant that looks harmless because it doesn't change the amino acid, can still wreck a splice site. 一个深内含子变异（deep-intronic variant，位于内含子深处的变异），甚至一个看起来无害、因为不改变氨基酸的同义变异（synonymous variant，同义变异），都可能毁掉一个剪接位点。That's why splicing gets its own evidence rules. 这就是为什么剪接需要有它自己的一套证据规则。 And one bit of vocabulary you'll hear constantly: an RNA-splicing assay just means an experiment — usually RT-PCR on patient RNA — that reads out which transcripts a variant actually produces. 还有一个你会不断听到的词汇：RNA剪接实验（RNA-splicing assay）指的就是一个实验——通常是对患者RNA做RT-PCR——用来读出某个变异实际产生了哪些转录本。That's the observed side of the paper's title;
