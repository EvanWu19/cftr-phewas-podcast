Novel Pediatric Height Outlier Detection Methodology for Electronic Health Records via Machine Learning With Monotonic Bayesian Additive Regression Trees

Sparapani RA, Teng BQ, Hilbrands J, Pipkorn R, Feuling MB, Goday PS. Journal of Pediatric Gastroenterology and Nutrition, 2022.

Abstract-only this run — no PMCID, closed access; full text not retrievable via any fetch route tried. This paper builds a single, deliberately simple pediatric height-outlier rule: a monotonic Bayesian Additive Regression Trees (BART) model — monotonic meaning predicted height is constrained to only increase with age — predicts expected height from age, sex, race, and weight measured at the same visit (a cross-sectional, concurrent-covariate design, not a within-child trajectory model). Trained on 1,376 children (2–8y, outlier status unknown at training time) and evaluated on an independently, manually reviewed 318-patient test cohort, the model reached R² of 82.2%/75.3% (train/test) and AUC 0.841 for outlier discrimination; at a stated "relatively aggressive" 0.075 probability cutoff, sensitivity was 0.713, specificity 0.793, PPV 0.615, NPV 0.856 — meaningfully below the high-90s numbers posted by more elaborate sequence-aware methods (e.g. AWAD's Bi-LSTM, AUC 0.989), a real cost of choosing a simpler, single-rule architecture. It lands as an ML alternative to trajectory- or reference-chart-based candidate generators, with a genuine independently-labeled test-cohort evaluation — a contrast with this morning's flagged-only review paper.

Plain-English glossary

  • cross-sectional / concurrent-covariate model — a model predicting an expected value from covariates measured at the same visit, rather than from that individual's own longitudinal history; distinct from within-child trajectory methods covered elsewhere in this catalog.（中文：一种根据同一次就诊时测量的协变量来预测期望值的模型，而非根据个体自身的纵向历史；不同于本目录中其他讨论过的个体内轨迹方法。）
  • monotonic constraint (in BART) — a modeling restriction forcing predicted height to only increase, never decrease, as age increases, encoding the physiological fact that height can't shrink between visits barring measurement error.（中文：BART 模型中的一种建模限制，强制预测身高只能随年龄增加而增加，不能减少，体现了"除非测量错误，身高在两次就诊间不会缩短"这一生理事实。）
