Ep3 — Track C — Identifying outliers and implausible values in growth trajectory data (Yang 2016)

A foundational Track C paper (cited by 3 of the track's 4 named citation-graph anchors) that adapts a method originally built for fetal-growth-restriction screening — conditional percentiles — into a general-purpose data-cleaning tool for postnatal growth trajectories. Instead of comparing a measurement to the population distribution at that age, it fits a random-effects model of weight-on-age (restricted cubic spline, 5 knots) across the cohort, then computes a conditional mean and variance for each visit given that same individual's prior weight, flagging measurements more than 4 SD from that conditional expectation. Applied to 86,427 weight measurements from 8,217 girls in the PROBIT trial (Belarus), it flagged 234 points (0.27%) from 216 girls — points a conventional ±4 SD population cutoff would not have caught, because each sat well within normal population range and only looked wrong relative to that individual's own trajectory. Visual review confirmed implausibility in essentially all flagged cases, though this is a demonstration with subjective confirmation, not a formal sensitivity/specificity evaluation against an independent gold standard. This is squarely a pipeline-stage (a) candidate-generation method: a specific, individual-conditioned alternative to population-cutoff flagging. Buildable: conditional-percentile-flagger (S) — implement the exact recipe on synthetic longitudinal data and diff its flagged set against a plain population-cutoff approach.

Plain-English glossary

Conditional growth percentile — A percentile or expected-value calculation for a growth measurement that is conditioned on (calculated relative to) that same individual's own prior measurements, rather than the population distribution at that age.（中文:一种生长测量值的百分位数或期望值计算方式,以该个体自身此前的测量值为条件计算,而非相对于该年龄段的人群分布。）

Population (unconditional) percentile — The standard CDC/WHO growth-chart approach: converting a measurement to a percentile or z-score relative to a reference population at that age, with no reference to the individual's own history.（中文:标准的CDC/WHO生长曲线图方法:将测量值转换为相对于该年龄段参考人群的百分位数或z分数,不参考个体自身的历史数据。）

Small for gestational age (SGA) — The obstetric classification this method's underlying logic originated from: a fetus whose estimated weight falls far below what's expected given its own earlier growth, regardless of population percentile.（中文:该方法底层逻辑的产科学起源:胎儿估计体重远低于根据其自身此前生长情况所预期的值,而不论其在人群百分位数中的位置,即被归类为小于胎龄儿。）

Growth trajectory — The full sequence of an individual's repeated height/weight measurements over time, as distinct from any single measurement viewed in isolation.（中文:个体随时间推移的一系列连续身高体重测量值,区别于孤立看待的单次测量。）

Restricted cubic spline — A flexible nonlinear curve-fitting technique (with knots at chosen points) used here to model the non-linear shape of early-childhood growth as a function of age.（中文:一种灵活的非线性曲线拟合技术(在选定点设置结点),本文用它来对幼儿早期非线性的生长形态随年龄的变化进行建模。）

Methods / tools to lift

  • Conditional-percentile flagging rule — random-effects model + restricted cubic spline + 4-SD conditional-mean/variance threshold; Stata code provided by the authors.
  • 3-SD sensitivity analysis — a simple, reusable pattern for showing how flag counts change with threshold choice.

Where it lands + buildable artifact

Pipeline stage: (a) candidate generation — an individual-conditioned alternative to population-cutoff flagging.

Buildable: conditional-percentile-flagger (S) — implement the method on synthetic longitudinal height/weight data and diff its flagged set against a plain population cross-sectional cutoff to quantify the trajectory-conditioning advantage empirically.

What to verify first

  • Model fit quality of the underlying growth spline — the method's flags are only as meaningful as the fit, per the authors' own limitation.
  • Whether a modulator-era-style rapid, real weight change would be indistinguishable from an implausible outlier under this rule, since it was built on pre-modulator-era growth patterns.
  • The reported 0.27% flag rate against an independently adjudicated error set, since the paper's own confirmation was visual/subjective review rather than blinded chart adjudication.

Error types covered / not covered

Covered: implausible trajectory-level jumps or drops inconsistent with an individual's own growth pattern (the paper's own examples resemble likely data-entry or unit errors). Not covered: a first/baseline measurement (structurally excluded, since there's no prior point to condition on), errors within an individually plausible trajectory, and — not tested in this paper — genuinely rapid real physiological weight change.
