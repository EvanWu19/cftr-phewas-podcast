Ep4 — Track C (2/2) — growthcleanr vs. cp vs. PeAnOF on PCORnet (Lin 2022)

A genuine three-way head-to-head at national multi-site registry scale: growthcleanr (trajectory-based EWMA, CDC reference, adult-capable, error-correcting), conditional percentile / cp (STATA, minimal, ±4SD from individual conditional trajectory), and PeAnOF (Python, WHO reference, robust-regression outlier logic). Run on the PCORnet MedWeight Study — 71M weight and 51M height measurements across 15 institutions — growthcleanr flagged 17.5%/11.8% of pediatric/adult measurements; cp flagged almost nothing (0.03%/0.1%) but left 62 pediatric measurements beyond 10 SD post-cleaning versus 2 for growthcleanr; PeAnOF's regression logic actually beat growthcleanr's trajectory logic in one instructive edge case — a sparse individual with mostly-implausible values, where EWMA flagged the one true point instead of the many false ones. Runtime varied 18-fold (3h vs 6h vs 54h on a compute cluster) — an operational constraint as real as accuracy at this scale. Only growthcleanr handles adult data at all. Lands on candidate generation for the Liz-assigned CFFPR work, with a specific buildable edge-case stress test.

Plain-English glossary

Conditional percentile (cp) — A minimal pediatric growth-outlier method that fits a conditional mean/variance for each measurement from an individual's own trajectory and flags deviations beyond 4 SD; no unit, duplicate, or swap checking.（中文:一种精简的儿科生长异常值检测方法,根据个体自身轨迹为每次测量拟合条件均值/方差,标记偏离超过4个标准差的数值;不检查单位、重复值或字段互换问题。）

PCORnet — A U.S. distributed research network of 60+ healthcare systems organized around a shared common data model, enabling the same query to run across all participating sites.（中文:由60多家美国医疗系统组成的分布式研究网络,围绕共享的通用数据模型组织,使同一查询能在所有参与站点运行。）

PeAnOF (PaEdiatric ANthropometric measurement Outlier Flagging pipeline) — A Python growth-outlier tool using the WHO growth reference and robust linear regression, rather than trajectory-averaging, to flag outliers.（中文:一种基于Python的儿科人体测量异常值标记工具,使用WHO生长参考标准和稳健线性回归(而非轨迹平均法)来标记异常值。）

Robust linear regression — A regression method less sensitive to extreme values than ordinary least squares, used here as the outlier-flagging basis for PeAnOF.（中文:相比普通最小二乘法对极端值更不敏感的回归方法,本文中作为PeAnOF标记异常值的基础。）

Weight cap (EHR-vendor artifact) — A known limitation in some EHR systems where the recordable weight value is capped (400 lb in this study), requiring a dedicated detection rule rather than treating it as a normal implausible value.（中文:部分电子病历系统中已知的限制,即可录入的体重数值存在上限(本研究中为400磅),需要专门的检测规则,而不能当作普通的不合理数值处理。）

WHO growth reference vs. CDC growth chart — Two different pediatric growth standards; PeAnOF uses WHO, growthcleanr uses CDC, meaning the two tools aren't judging "implausible" against the identical baseline.（中文:两种不同的儿科生长参考标准;PeAnOF使用WHO标准,growthcleanr使用CDC标准,意味着两个工具判断"不合理"所依据的基准并不完全相同。）
