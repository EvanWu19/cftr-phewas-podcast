Ep4 (Track C, 2 of 2) — Joint modeling of a longitudinal marker and an informative visiting process

Stamoulopoulos A, Thomadakis C, Touloumi G (2026). Joint Modeling of Longitudinal Data and Potentially Informative Visiting Process to Dynamically Predict Future Visit Times. Statistics in Medicine.

Paired deliberately with ep3's review of EMR measurement-error taxonomy: where that paper named "informative visiting" as an open problem in passing, this one builds a model for it directly. A linear mixed model for a continuous marker is linked, via correlated shared random effects, to a proportional-hazards gap-time model for the visiting process itself, letting the model distinguish visiting-at-random (VAR) from visiting-not-at-random (VNAR) and derive dynamic, updating predictions for when a patient's next visit will occur. Applied to an HIV cohort (AMACS), the estimated correlation between the visiting and marker random effects was 0.68 (95% CI 0.65–0.71) — a strong VNAR signal. For Runyu, the transferable insight is structural: any "expected value at time t" flagging model that treats visit timing as exogenous is quietly miscalibrated if visiting is actually informative — exactly the kind of substrate check worth running before trusting a candidate-generation model like ep3's conditional growth percentile method.

Plain-English glossary

  • Informative visiting process — When whether/when a patient is measured is itself correlated with the value being measured, biasing models that treat visit timing as incidental.（中文:信息性就诊过程,指患者是否/何时就诊本身与被测量的值相关,会使把就诊时间当作无关信息的模型产生偏倚。）
  • VAR / VNAR (visiting at random / not at random) — A taxonomy (Pullenayegum & Lim) distinguishing whether visit timing is independent of marker values, conditional on observed history, or not.（中文:就诊随机/非随机分类体系,区分在已知历史信息条件下,就诊时间是否与标志物取值独立。）
  • Gap time vs. calendar time — Modeling the time since the last visit (gap time) versus modeling on the fixed calendar timeline; gap-time models tend to be more robust when the true time scale is uncertain.（中文:间隔时间与日历时间,分别指以"距上次就诊的时长"或固定日历时间轴建模;时间尺度不确定时间隔时间模型通常更稳健。）
  • Shared random effects joint model — Links a longitudinal marker submodel and an event-timing submodel through correlated, normally distributed patient-specific random effects.（中文:共享随机效应联合模型,通过相关的、服从正态分布的患者特异性随机效应,把纵向标志物子模型与事件时间子模型连接起来。）
  • Terminal event — An event (e.g. death) that ends follow-up entirely; treating it as non-informative when it isn't can bias the model, especially at higher terminal-event proportions.（中文:终末事件,指彻底结束随访的事件(如死亡);若并非非信息性却被当作非信息性处理,会使模型产生偏倚,终末事件比例越高偏倚越明显。）

Full citation

Methods / tools to lift

  • Shared-random-effects joint model (LMM + gap-time proportional-hazards) — links a continuous marker trajectory to the timing of the visits that produced it.
  • VAR/VNAR diagnostic framing (Pullenayegum & Lim taxonomy) — a way to name and test whether visit timing is informative before trusting downstream models that assume it isn't.
  • Dynamic, updating prediction of time-to-next-visit — probability that the next gap exceeds a clinically meaningful threshold, conditional on prior gaps and marker history.
  • One-dimensional-integration likelihood trick — keeps the joint likelihood computationally tractable regardless of how many random effects the longitudinal submodel has.

Where it lands + buildable artifact

Pipeline stage: (a) candidate generation, primary — a direct methodological complement to ep3's conditional growth percentile method: checks whether the "expected value at time t" reference itself is contaminated by informative visit timing.

Buildable MVP: A lightweight VNAR diagnostic: on a public longitudinal anthropometric dataset, compute the correlation between the gap to the next encounter and the previous visit's residual from a simple growth-reference model, as a first-pass check of whether an informative-visiting signal is present before investing in a full shared-random-effects joint model. Difficulty: M.

Error types covered / not covered: Covered: bias in an expected-trajectory reference arising from informative visit timing (VNAR). Not covered: no specific anthropometric error types (unit conversion, digit transposition, decimal shift, carry-forward) — this is a substrate-model paper, not an error-classification paper.

What to verify first

  • Whether the shared-random-effects assumption holds under a visiting rhythm very different from AMACS's roughly six-to-eight-month adult HIV-monitoring cadence.
  • Whether a single scalar visiting random effect is expressive enough to capture registry-specific drivers of visit timing (insurance changes, moves, treatment starts), or would need covariate extensions.
  • What the terminal-event proportion looks like in any population this gets applied to next, given the simulation showed real bias once terminal events reached roughly 40% of the cohort.
