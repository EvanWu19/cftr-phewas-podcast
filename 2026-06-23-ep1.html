Show notes — REVEL (Track A, variant interpretation)

Blurb. REVEL (rare exome variant ensemble learner; Ioannidis et al., Am J Hum Genet 2016) is an ensemble missense-pathogenicity predictor that folds thirteen component scores — MutPred, FATHMM, VEST, PolyPhen, SIFT, PROVEAN, MutationAssessor, MutationTaster, LRT, GERP, SiPhy, phyloP, phastCons — into a single random-forest score from 0 to 1. Its key design move is training on recently discovered pathogenic + rare neutral variants while excluding any variant used to train its component tools, an attempt to estimate honest generalization rather than circular, leakage-inflated performance. On two independent test sets it beat every single tool and seven rival ensembles (MetaSVM, MetaLR, KGGSeq, Condel, CADD, DANN, Eigen), with its largest edge precisely on the rare (AF < 0.5%) variants that dominate CFTR. It ships precomputed scores for every possible human missense variant. Where it lands: the Karen / variant-interpretation lane. Buildable artifact: a CFTR missense triage table joining precomputed REVEL scores to CFTR2 functional class and ClinVar, surfacing score-vs-clinical discordances. Sourcing flag: abstract-only — PMC full text was empty on every route; all numbers are from the abstract or well-documented public REVEL facts.

Plain-English glossary

  • Allele frequency — how common a variant is in a population; "rare" here means below 0.5%.（中文：等位基因频率，某变异在人群中出现的常见程度；这里"罕见"指低于 0.5%。）
  • Conservation score (GERP / phyloP / phastCons / SiPhy) — measures of how unchanged a genomic position has stayed across evolution; high conservation flags likely functional importance.（中文：保守性分数，衡量某基因组位点在进化中保持不变的程度；高保守提示可能具功能重要性。）
  • Missense variant — a single-base coding change that substitutes one amino acid for another, leaving the protein full-length.（中文：错义变异，单碱基编码改变，把一个氨基酸换成另一个，蛋白质仍为全长。）
  • Pathogenicity — how likely a variant is to actually cause disease.（中文：致病性，某变异实际引起疾病的可能性。）
  • Purifying selection — evolutionary removal of harmful changes, which keeps important positions conserved.（中文：纯化选择，进化对有害改变的清除，使重要位点保持保守。）
  • VUS (variant of uncertain significance) — a variant that can't yet be classified as benign or pathogenic.（中文：意义未明变异，尚无法判定为良性或致病的变异。）
  • ClinVar / SwissVar — curated databases of variants annotated with disease assertions (ClinVar = NIH archive; SwissVar = UniProt-linked).（中文：人工整理的带疾病判定的变异数据库；ClinVar 为 NIH 归档，SwissVar 与 UniProt 关联。）

Full citation. Ioannidis NM, Rothstein JH, Pejaver V, et al. REVEL: An Ensemble Method for Predicting the Pathogenicity of Rare Missense Variants. Am J Hum Genet. 2016;99(4):877–885. PMID 27666373 · PMC PMC5065685 · DOI 10.1016/j.ajhg.2016.08.016. According to PubMed; full text was not retrievable (abstract-only).

Methods / tools to lift

  • Ensemble-over-predictors: use thirteen existing scores as features to a single classifier rather than choosing one tool.
  • Leakage-scrubbed training: exclude any training instance that the component tools were trained on, to estimate generalization rather than memorized performance.
  • Precomputed lookup table: distribute scores for all possible missense variants so downstream users join rather than run inference.
  • Component tools split into functional-impact predictors (SIFT, PolyPhen, VEST, FATHMM, PROVEAN, MutPred, MutationAssessor) and conservation scores (GERP, phyloP, phastCons, SiPhy).

Where it lands + buildable artifact. Karen / variant interpretation. MVP (paste-ready): pull precomputed REVEL scores for all CFTR missense variants → join on build-tagged genomic coordinate to CFTR2 functional class + ClinVar assertion → emit a ranked discordance table (REVEL-damaging-but-CFTR2-uncertain; clinically-pathogenic-but-REVEL-benign). Difficulty S. Best run alongside the existing EVE / AlphaMissense / ESM1b notebooks so the classical-ensemble consensus and the deep-learning predictors can be contrasted on the same CFTR variants.

What to verify first

  • Threshold provenance: this 2016 paper gives a continuous score, not a clinical cutoff; ACMG/ClinGen REVEL thresholds come from later calibration work and must be sourced separately, not attributed to this paper.
  • Training contamination: don't benchmark REVEL on CFTR variants that may have been in its training set; use a hold-out or document overlap.
  • Calibration vs ranking: a strong AUC confirms ordering, not that the score equals a probability; clinical use needs calibration.
  • Abstract-only caveat: confirm all method details against the full text before relying on internals beyond the abstract.

JORDAN And "pathogenicity" here just means how likely that swap is to actually cause disease? 这里的"致病性"(pathogenicity) 就是指那个替换实际引起疾病的可能性有多大，对吗？

JORDAN Conservation meaning evolution has been "protecting" that spot? 保守性的意思是进化一直在"保护"那个位点？

ALEX Right — strong purifying selection has weeded out changes there, so the position is a proxy for functional importance. 对——强烈的纯化选择 (purifying selection) 已经把那里的改变淘汰掉了，所以这个位点是功能重要性的一个替代指标。Now, the problem this paper names: each of these tools is decent but imperfect, and they disagree with each other constantly. 现在，这篇论文点出的问题是：这些工具每一个都还不错但都不完美，而且它们彼此之间不停地相互矛盾。A clinician gets SIFT saying "tolerated," PolyPhen saying "probably damaging," and CADD somewhere in the middle, and has no principled way to combine them. 临床医生会看到 SIFT 说"可耐受"，PolyPhen 说"可能有害"，CADD 在中间某处，却没有一个有原则的办法把它们综合起来。
