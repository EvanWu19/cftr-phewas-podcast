Ep2 — Assessing data quality of rheumatoid and psoriatic arthritis patients in the All of Us Research Program

Abstract-only episode. Spotnitz M, Giannini J, Clark E, Ostchega Y, Litwin TR, Berman L (2026), JAMIA Open. This paper applies a five-domain data-quality checklist — conformance, completeness, concordance, plausibility, temporality — to rheumatoid arthritis (RA) and psoriatic arthritis (PsA) phenotype cohorts inside the All of Us Research Program's OMOP CDM data. Most ICD source codes mapped cleanly to SNOMED; concept prevalence was low and most concept-pair correlations were weak; DMARD prescribing patterns matched prior literature; and the fraction of records with enough data to compute clean event timing ranged from 13-85% (RA) and 16-81% (PsA) depending on the concept pair, though a plausible rheumatoid-factor-then-DMARD-then-diagnosis sequence held up across both diseases. The takeaway for this podcast isn't the specific numbers but the reusable five-domain skeleton: a clean, citable way to organize a registry fitness-for-use report that this podcast's Track C episodes have been circling from the growth-data side using overlapping vocabulary (Kahn framework, Weiskopf & Weng dimensions).

Plain-English glossary

  • OMOP CDM (Observational Medical Outcomes Partnership Common Data Model) — A standardized schema that reshapes EHR or registry data into one consistent table structure with concepts mapped to a shared vocabulary (usually SNOMED CT), so the same analysis code runs across institutions.（中文：一种标准化数据结构，把电子病历或登记数据统一转换为一致的表结构，并把概念映射到共同词表（通常是SNOMED CT），使同一套分析代码能跨机构运行。）
  • All of Us Research Program — NIH's national longitudinal cohort aiming for 1M+ US participants, oversampling historically underrepresented communities, releasing EHR data in OMOP format.（中文：NIH的全国性纵向队列项目，目标招募超百万美国参与者，对代表性不足群体过采样，以OMOP格式发布电子病历数据。）
  • Five-domain data-quality taxonomy — Conformance (does a value fit its expected format/vocabulary), completeness (how much is missing), concordance (do related concepts agree), plausibility (is a value clinically believable), temporality (does event timing/sequencing make sense).（中文：一致性（数值是否符合预期格式/词表）、完整性（缺失多少）、协调性（相关概念是否一致）、合理性（数值是否临床可信）、时序性（事件时间顺序是否合理）。）
  • DMARD (disease-modifying antirheumatic drug) — Guideline-recommended drug class for RA/PsA treatment.（中文：类风湿性关节炎/银屑病关节炎治疗指南推荐的改善病情抗风湿药物类别。）
  • Concept-sequence analysis — Checking whether the order in which clinical concepts appear in a record matches expected clinical practice.（中文：检查病历中临床概念出现的顺序是否符合预期的临床实践。）

Full citation

Methods / tools to lift

  • Five-domain DQ checklist (conformance/completeness/concordance/plausibility/temporality) — a reusable audit skeleton for any OMOP-shaped or OMOP-mappable cohort.
  • Concept-sequence analysis — checking whether the relative order of related clinical concepts in a record matches expected practice, as an indirect temporality check.
  • Per-phenotype (not whole-resource) auditing — treating data quality as phenotype-specific rather than a single blanket verdict for an entire data resource.

Where it lands + buildable artifact

Serves the Liz Cromwell / CFFPR registry data-quality priority — method only, no CFFPR-specific claims. MVP: a five-domain DQ scorecard generator — a script that takes any tabular registry export, computes a conformance check, completeness rate, concordance pair, plausibility bound, and temporality rule per field, and renders all five as a one-page summary table. Difficulty: S.
