Track A — MuSA: a Nextflow pipeline for deep, reproducible annotation and clinical ranking of genomic variants

Note on sourcing: the paper is listed OA=No in our index with no PMCID, confirmed non-OA via Europe PMC (isOpenAccess=N). This episode is sourced from a detailed structured abstract (Background/Results/Conclusions) only — not the full methods text.

Blurb

Scognamiglio and colleagues (BMC Bioinformatics, 2026) tackle a problem familiar to anyone assembling a CFTR variant-curation workflow by hand: standalone tools like VEP and ANNOVAR require complex manual configuration, produce verbose transcript-level output unsuitable for clinical review, and depend on ad hoc glue scripts. MuSA (Multi-Source variant Annotation) is an nf-core-compliant Nextflow pipeline that automates the whole chain — VEP with 22 plugins (AlphaMissense, CADD, SpliceAI, Enformer), ANNOVAR, a pre-configured dbNSFP distribution, the experimental RENOVO pathogenicity predictor, and automated ACMG/AMP classification via GeneBe and InterVar — consolidating everything into a richly annotated MAF file and a clinically formatted, HPO-filtered interactive HTML report. Benchmarked on 22,705 GIAB NA12878/HG001 variants, extended-mode annotation completes in ~20 minutes on a 64-core server. The transfer to Karen's variant-harmonization work is close to direct: this isn't a new predictor, it's the reproducible orchestration layer a CFTR curation pipeline needs. Buildable artifact: cftr-musa-panel, a CFTR-scoped deployment of MuSA's basic mode with a custom HPO panel and CFTR2 wired in as an extra evidence column.

Plain-English glossary

  • Nextflow — a workflow language and execution engine for writing a reproducible pipeline once and running it identically on a laptop, HPC cluster, or cloud.（中文:一种工作流语言和执行引擎,用于把一个可复现的流程写一次,并在笔记本电脑、高性能计算集群或云端以相同方式运行。）
  • nf-core — a community project curating standardized, peer-reviewed Nextflow pipelines built on shared conventions.（中文:一个维护基于共享规范构建的、经同行评审的标准化Nextflow流程库的社区项目。）
  • VEP (Ensembl Variant Effect Predictor) — the standard tool for annotating which gene/transcript a variant falls in and what functional/population databases say about it.（中文:用于标注变异所在基因/转录本及相关功能与群体数据库信息的标准工具。）
  • CADD (Combined Annotation Dependent Depletion) — an integrative score combining dozens of annotation types into one estimate of variant deleteriousness.（中文:一种整合多种注释信息、评估变异有害性的综合评分工具。）
  • SpliceAI — a deep-learning model predicting whether a variant disrupts normal splicing, including from deep intronic positions.（中文:一种基于深度学习、预测变异是否破坏正常剪接的工具,包括深内含子位置的变异。）
  • ANNOVAR / dbNSFP — ANNOVAR is an independent annotation engine run alongside VEP as a cross-check; dbNSFP is a large precompiled database bundling dozens of predictor scores for nearly every possible missense change.（中文:ANNOVAR是与VEP并行运行、用作交叉验证的独立注释引擎;dbNSFP是汇总多种预测分数的大型预编译数据库。）
  • HPO (Human Phenotype Ontology) — a standardized, hierarchical vocabulary of clinical signs/symptoms used to match a patient's phenotype to causal genes.（中文:一种标准化的、带层级关系的临床体征/症状词汇表,用于将患者表型与致病基因匹配。）
  • ACMG/AMP classification — the joint standard for sorting a variant into pathogenic/likely pathogenic/VUS/likely benign/benign tiers based on a structured evidence checklist.（中文:一套结构化证据清单标准,用于将变异归入致病、可能致病、意义不明、可能良性、良性五个等级之一。）
  • GIAB (Genome in a Bottle) — a NIST-coordinated reference project providing high-confidence "truth set" variant calls for benchmarking.（中文:由美国国家标准与技术研究院协调的参考项目,提供高置信度的"真值集"变异标注,用于基准测试。）
  • MAF file (mutation annotation format) — a tabular format for storing variant annotation results (not to be confused with minor allele frequency, which shares the same abbreviation).（中文:一种存储变异注释结果的表格格式,注意与"次要等位基因频率"缩写相同但含义不同。）

Methods / tools to lift

  • nf-core-compliant Nextflow orchestration — parallel, containerized (Docker/Singularity) annotation branches with YAML-based version tracking and SHA-256 reference-database integrity checks.
  • Multi-source annotation fusion — VEP (22 plugins incl. AlphaMissense/CADD/SpliceAI/Enformer) + ANNOVAR + dbNSFP + RENOVO run together and consolidated into one MAF file (up to 920 columns/variant).
  • Automated ACMG/AMP tiering via external services (GeneBe, InterVar) plus HPO-matched gene-panel filtering into a clinically formatted interactive HTML report.

Where it lands + buildable artifact

Karen / CFTR variant interpretation & harmonization. Buildable: cftr-musa-panel (S–M) — deploy MuSA's basic (fast) mode against a batch of CFTR variants in VCF format, with a custom HPO panel scoped to CF-relevant phenotype terms and CFTR2 classifications wired in as an extra evidence column alongside GeneBe/InterVar output; outputs one clinically readable HTML report per batch.

What to verify first

  • MuSA currently supports germline small variants (SNVs/indels) on hg38 only — check how it handles CFTR's intron-8 poly-T/TG-repeat tract specifically.
  • RENOVO's VUS-prioritization module is explicitly flagged experimental by the authors — treat its output as triage, not verdict.
  • Check GeneBe/InterVar rate limits and terms of use before routing real CFTR variant batches through them (external dependency, not under our control).
