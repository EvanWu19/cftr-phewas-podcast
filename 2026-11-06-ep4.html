Ep4 (Track C 2/2 — registry QC): gamlssReport — exact-centile disclosure for regression-based growth norms

Blurb. Blagus et al. (2025, PLOS ONE) address a reporting gap in published regression-based norms (GAMLSS/LMS-style growth and fitness references): papers typically publish only selected centiles at selected predictor values or age-interval midpoints, and the underlying fitted model usually can't be shared because it contains protected individual-level data. They provide the R package gamlssReport, with functions to extract a fitted GAMLSS model into a human-readable table plus a shareable, data-free machine-readable object (gamlssReport), compute an exact centile or score for any input combination (centile.gamlssReport/score.gamlssReport), and auto-generate a no-code web app (ShinyApp.gamlssReport). A worked example using a published standing-long-jump norm model for European boys is stark: a 10-year-old boy's 140cm jump evaluates to exactly the 54.7th centile using the real model, but naive interpolation between the nearest published (age-10.5-midpoint) table values suggests only the 45th-50th centile — non-overlapping answers. The episode maps this to pipeline stage (a), candidate generation — whatever reference model underlies a flagging rule determines what counts as "far enough from expected" to flag, and a naive table-lookup habit anywhere can systematically misjudge borderline cases near interval boundaries. Buildable artifact: an Exact-Centile Flagging Substrate using a public (non-CFFPR) reference model.

Plain-English glossary

Centile — Synonymous with percentile: the fraction of a reference population falling below a given value at a given age; same concept whether using CDC or WHO reference conventions.（中文：与百分位数同义：在某个年龄点上，参照人群中数值低于某个给定值的比例；无论使用CDC还是WHO参照惯例，概念都相同。）

Continuous norming — Treating age and other predictors as genuinely continuous (rather than binned into discrete groups) when constructing reference norms, intended to allow exact score evaluation for any predictor value.（中文：在构建参照常模时，把年龄等预测变量当作真正连续的变量处理（而不是划分为离散组别），目的是让任意预测变量值都能被精确评分。）

GAMLSS — Generalized Additive Models for Location, Scale, and Shape: a modern, more flexible successor to LMS that models up to four distribution parameters (location, scale, skewness, kurtosis) as smooth functions of predictors like age.（中文：位置、尺度和形状的广义加性模型，是LMS方法的现代、更灵活的升级版，把最多四个分布参数（位置、尺度、偏度、峰度）建模为年龄等预测变量的平滑函数。）

LMS method — The classical method (lambda/mu/sigma: skewness, median, coefficient of variation) underlying CDC and WHO growth charts, generating an exact z-score or percentile at any age from three smoothly-varying parameters.（中文：CDC和WHO生长曲线图所依据的经典方法（λ/μ/σ：偏度、中位数、变异系数），通过三个平滑变化的参数，在任意年龄点生成精确的z分数或百分位数。）

P-spline — A penalized regression spline using many equally-spaced knots plus a penalty term controlling smoothness, commonly used to model the non-linear, age-varying parameters in a GAMLSS model.（中文：一种带惩罚项的回归样条，使用许多等距节点，并通过惩罚项控制平滑程度，常用于建模GAMLSS模型中随年龄非线性变化的参数。）

Methods / tools to lift

  • gamlssReport R package — extracts a fitted GAMLSS model into a human-readable table and a data-free, shareable machine-readable object.
  • centile.gamlssReport / score.gamlssReport — compute an exact centile for a given score (or vice versa) at any combination of predictor values, no table interpolation needed.
  • ShinyApp.gamlssReport — auto-generates a no-code web application for exact score/centile lookup from the same model object.
  • Privacy-preserving model-sharing disclosure format — a documented standard for what to publish (full parameter/spline details) versus what to withhold (individual-level data).

Where it lands + buildable artifact

Pipeline stage: (a) candidate generation, primary — the reference model consulted by a flagging rule determines what counts as "far enough from expected" to flag. (d) evaluation, secondary — the disclosure format enables cross-site/cross-study model comparison without a data-sharing agreement for underlying records.

Buildable artifact: Exact-Centile Flagging Substrate (S). MVP: wrap a public, non-CFFPR growth-reference GAMLSS model (e.g. a CDC or WHO reference) in the gamlssReport format, and compare its exact centile output against a naive midpoint-table lookup across a simulated age grid, to quantify how large the discrepancy can get.

What to verify first

  • Whether gamlssReport applies directly to whatever smoothing approach any real reference model actually uses — it currently supports only P-spline additive terms, not e.g. SITAR's own curve-registration method.
  • That this paper addresses reporting/sharing an already-fitted model only — it says nothing about the data-cleaning, model-selection, and diagnostic steps needed before trusting the model being reported.
  • How large the table-vs-exact discrepancy realistically is for any specific reference table or model actually in use, rather than assuming the standing-long-jump example's magnitude generalizes.

Error types covered / not covered

This is a model-reporting/disclosure method, not a flagging method — it covers none of the specific error types (unit conversion, transcription, carry-forward, decimal shift, real-clinical-event confusion) directly. Its relevance is indirect and upstream: a reference model consulted via lossy table interpolation rather than exact evaluation can systematically shift which records a downstream flagging rule calls outliers, regardless of error type.

JORDAN Let's get the paediatric-growth vocabulary straight. 先把儿科生长相关的术语理清楚。What's GAMLSS, in plain terms, and how does it relate to the LMS method people usually associate with growth charts? GAMLSS用通俗的话讲是什么，它和人们通常跟生长曲线图联系在一起的LMS方法有什么关系？

ALEX GAMLSS stands for Generalized Additive Models for Location, Scale, and Shape, and it's the modern, more flexible successor to the LMS method that CDC and WHO growth charts were originally built on. GAMLSS代表"位置、尺度和形状的广义加性模型"（Generalized Additive Models for Location, Scale, and Shape），它是CDC和WHO生长曲线图最初所依据的LMS方法的现代、更灵活的升级版本。LMS models a reference distribution at each age using three parameters — lambda for skewness (the Box-Cox power transformation), mu for the median, and sigma for the coefficient of variation — and from those three numbers at any given age, you can compute an exact z-score or percentile for a measured value. LMS方法用三个参数，在每一个年龄点上建模一个参照分布——λ代表偏度（Box-Cox幂变换参数），μ代表中位数，σ代表变异系数——有了某个年龄点上的这三个数字，你就可以为一个测量值计算出精确的z分数或百分位数。GAMLSS generalizes that idea to up to four distribution parameters instead of three — mu, sigma, nu, and tau, covering location, scale, skewness, and kurtosis — and lets each of those parameters vary smoothly with age or other predictors using penalized regression splines called P-splines, rather than the simpler curve-fitting LMS originally used. GAMLSS把这个思路推广到最多四个分布参数，而不是三个——μ、σ、ν和τ，分别对应位置、尺度、偏度和峰度——并允许这些参数中的每一个，都通过一种叫做P-splines的带惩罚回归样条，随年龄或其他预测变量平滑变化，而不是用LMS最初使用的更简单的曲线拟合方法。In practice, for pediatric growth work specifically, GAMLSS is usually fit in R using the gamlss library, and it's become one of the most common tools for building modern growth-reference curves. 在实际操作中，具体到儿科生长研究领域，GAMLSS通常使用R语言里的gamlss软件包来拟合，它已经成为构建现代生长参照曲线最常用的工具之一。
