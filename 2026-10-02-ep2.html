Episode blurb

No single common data model (CDM) or data standard has won the standardization war in health data, and this systematic review by Finster, Wenzel, and Taghizadeh (BMC Medical Informatics and Decision Making, 2025) shows why: it scores OMOP CDM, i2b2, PCORnet CDM, and FDA's Sentinel against five criteria (suitability, popularity, adaptability, interoperability, support), and separately scores FHIR, openEHR, CDA, and HL7 v2 the same way. OMOP comes out ahead among CDMs (21+) and FHIR among data standards (24+), but the paper's real finding is that OMOP's edge is driven less by any single criterion than by the sheer scale of the OHDSI network built around it — over 331 data sources, 2.1 billion patient records, 34 countries. The paper's own conclusion — "no single global representation can be selected" — is the headline worth remembering: cross-model translation tooling matters as much as picking a winner. Buildable artifact: a hands-on OHDSI sandbox rehearsal using Synthea synthetic data, ETL-Synthea, and the Data Quality Dashboard, serving the AI-tooling/career-positioning priority.

Plain-English glossary

CDM (Common Data Model) — a standardized schema that transforms data from different source systems into one consistent table structure and vocabulary, so the same analysis code can run against many databases.（中文：一种标准化的模式，把来自不同源系统的数据转换成统一的表结构和词汇体系，使同一套分析代码能在多个数据库上运行。）

ETL (Extract-Transform-Load) — the process of pulling data out of a source system, reshaping it, and loading it into a target schema or model.（中文：从源系统提取数据、对其进行转换，再加载到目标模式或模型中的过程。）

FHIR (Fast Healthcare Interoperability Resources) — a modern data-exchange standard defining how health systems send and receive structured clinical information.（中文：一种现代的数据交换标准，定义了医疗系统之间如何发送和接收结构化临床信息。）

i2b2 (Informatics for Integrating Biology and the Bedside) — a minimalist CDM storing most clinical facts in one star-schema table, favoring query speed and flexibility over semantic richness.（中文：一种简约的通用数据模型，把大多数临床事实存放在一张星型模式表中，优先考虑查询速度和灵活性，而非语义丰富度。）

LOINC (Logical Observation Identifiers Names and Codes) — the standard vocabulary for naming laboratory tests and clinical measurements.（中文：用于命名化验项目和临床测量指标的标准词汇表。）

OHDSI (Observational Health Data Sciences and Informatics) — the open international research network and software ecosystem built around the OMOP CDM.（中文：围绕OMOP通用数据模型建立的开放国际研究网络及软件生态系统。）

OMOP CDM (Observational Medical Outcomes Partnership Common Data Model) — a widely-adopted CDM that maps source data into a standardized set of analyzable constructs and vocabulary.（中文：一种广泛采用的通用数据模型，把源数据映射成一套标准化、可分析的结构和词汇体系。）

PCORnet CDM — the common data model behind the US Patient-Centered Outcomes Research Network, connecting hospitals and clinics across multiple research networks.（中文：美国"以患者为中心的结果研究网络"所使用的通用数据模型，连接多个研究网络下的医院和诊所。）

Sentinel / SCDM — the FDA's own distributed data model, built for post-market drug-safety surveillance, with tighter access control than other CDMs.（中文：FDA自己的分布式数据模型，专为上市后药品安全监测而构建，访问控制比其他通用数据模型更严格。）

SNOMED CT — the dominant standard terminology for clinical diagnoses and findings.（中文：用于临床诊断和临床发现的主流标准术语体系。）

Full citation

Methods / tools to lift

  • A five-criteria-category (suitability, popularity, adaptability, interoperability, support) structured qualitative scoring framework, reusable for evaluating any new CDM or standard that comes along later.
  • Three named ETL strategies (direct ETL, query translation, layered CDM integration) as a vocabulary for describing any cross-model data-movement plan.
  • OHDSI's own validation stack (Achilles, Data Quality Dashboard) and Sentinel's 1,200+-check data-quality toolkit as concrete examples of what a mature CDM's QC tooling looks like.

Where it lands + buildable artifact

Serves AI-tooling / career positioning. Buildable artifact (M): a Synthea-generated synthetic patient population, run through OHDSI's own ETL-Synthea mapping into OMOP CDM tables, then checked with the Data Quality Dashboard to produce a baseline pass/fail report — a zero-risk, zero-PHI sandbox for building hands-on familiarity with vocabulary mapping, DQD rule interpretation, and ATLAS cohort definition.

What to verify first

  • The literature search was Scopus-only and restricted to a specific keyword list within medicine; the authors acknowledge a different database or keyword set could change the popularity/adoption picture, especially for closely-scored candidates like PCORnet vs i2b2.
  • Scoring is qualitative and author-assigned per CDM/standard, with no reported inter-rater reliability check — treat point totals as directional, not as a precise instrument.
  • The paper's own stated conclusion is that no single CDM should be adopted in isolation; any OMOP-based prototype should be designed with cross-model interoperability (via one of the three ETL strategies) in mind from the start.

ALEX Yes, and this is practically useful — they lay out three broad ETL approaches. 有的，而且这部分很有实用价值——他们列出了三种大致的ETL（抽取-转换-加载，Extract-Transform-Load）方式。Direct ETL processes transform and map data straight from one CDM to another, say i2b2 to FHIR or OMOP, aiming to preserve completeness during the conversion; query translation instead lets you query across different CDMs without transforming the underlying data at all, keeping everything in its original format while still enabling cross-model analysis; and layered CDM integration builds new standards or knowledge graphs on top of existing CDMs, combining multiple models into one cohesive framework. 直接ETL流程把数据从一个CDM直接转换映射到另一个，比如从i2b2到FHIR或OMOP，目标是在转换过程中尽量保持数据完整性；查询转换则完全不转换底层数据，而是让你跨不同CDM进行查询，数据保持原始格式的同时依然能实现跨模型分析；分层CDM整合则是在现有CDM之上构建新的标准或知识图谱，把多个模型整合进一个统一的框架。There's also a dedicated effort called the Common Data Model Harmonization project, which maps PCORnet, i2b2, OMOP, and Sentinel all onto a shared reference model called BRIDG, specifically to make sharing and interpreting research data across all four easier at once. 还有一个专门的项目叫做通用数据模型协调项目（Common Data Model Harmonization），它把PCORnet、i2b2、OMOP和Sentinel统一映射到一个叫BRIDG的共享参考模型上，专门用来让这四者之间的数据共享和解读同时变得更容易。
