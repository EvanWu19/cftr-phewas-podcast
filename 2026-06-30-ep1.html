Blurb

ClinGen's earlier work (2022) showed you shouldn't use a variant predictor's raw score as evidence — you should calibrate it against a trusted set of ClinVar pathogenic/benign variants using a local-posterior-probability method, then map score thresholds to ACMG evidence strengths (Supporting → Moderate → Strong → Very Strong). This paper extends that calibration to three newer-generation tools — AlphaMissense, ESM1b, and VARITY. All three reach Strong evidence for pathogenicity and Moderate for benignity, though sometimes only for a small slice of variants, and offer at best modest gains over the four previously recommended predictors. The transferable method is the calibration recipe; the buildable artifact is a CFTR-specific PP3/BP4 calibration notebook that fits gene-specific thresholds using CFTR2 labels and asks whether they beat the genome-wide cutoffs. Serves the Karen Raraigh / variant-interpretation priority.

Plain-English glossary

  • ACMG/AMP framework — the standard rulebook for classifying a DNA variant as pathogenic or benign, built from labeled evidence criteria.（中文：ACMG/AMP 框架，是判定变异致病或良性的标准规则体系，由一条条带代号的证据组成。）
  • AlphaMissense — DeepMind tool that scores missense damage using AlphaFold structure plus a protein language model.（中文：AlphaMissense，DeepMind 的工具，结合 AlphaFold 结构与蛋白质语言模型给错义变异的有害程度打分。）
  • Benign / Pathogenic — clinical classifications meaning a variant does not / does cause disease.（中文：良性 / 致病，指变异不致病 / 致病的临床分类。）
  • CFTR2 — curated CF-specific variant database with clinical and functional annotations.（中文：CFTR2，专门针对囊性纤维化、经人工审编的变异数据库，含临床与功能注释。）
  • ClinVar — NIH public archive of variant–clinical-significance assertions, the usual labeled "ground truth."（中文：ClinVar，美国 NIH 的公共数据库，收录变异与临床意义的判定，是常用的标注金标准。）
  • ESM1b — protein language model trained only on natural protein sequences (no clinical labels), flagging variants that break learned sequence "grammar."（中文：ESM1b，仅用天然蛋白序列训练的蛋白质语言模型（无临床标签），标记破坏蛋白"语法"的变异。）
  • Functional assay — wet-lab experiment that directly measures whether a variant protein still works.（中文：功能实验，直接测量变异蛋白是否仍能正常工作的湿实验室实验。）
  • Local posterior probability — empirical probability that a variant is pathogenic given that its score falls in a particular range; the basis of the calibration.（中文：局部后验概率，指在某分数区间内变异为致病的经验概率，是校准的基础。）
  • Missense variant — a single DNA change that swaps one amino acid for another.（中文：错义变异，一个把某氨基酸换成另一个的 DNA 改变。）
  • PP3 / BP4 — ACMG criteria for "computational evidence supports damaging" (PP3) and "supports benign" (BP4).（中文：PP3 / BP4，ACMG 中"计算证据支持有害"（PP3）与"支持良性"（BP4）的证据条目。）
  • VARITY — supervised ensemble predictor designed to limit training-data circularity.（中文：VARITY，一种有监督的集成预测器，刻意设计以减少训练数据的循环论证。）

Methods / tools to lift

  • Local-posterior-probability calibration — converts a predictor's raw score into a dosed ACMG evidence strength against a labeled set, rather than trusting the raw score.
  • Per-tier coverage reporting — always report not just the strength a threshold reaches but how many variants it actually applies to.
  • AlphaMissense / ESM1b / VARITY — three predictors with distinct inductive biases (structure+pLM / pure pLM / supervised ensemble); useful as an ensemble whose disagreement is informative.

What to verify first

  • Label independence — how much of CFTR2's evidence already used computational predictors (circularity risk).
  • Per-tier sample size — enough confidently-benign CFTR missense variants to fit a stable BP4 threshold?
  • Allele-frequency confounding — ensure the benign set isn't just common variants.
  • Scope — calibration is missense-only; splice/other classes need separate (e.g. SpliceAI-based) handling.
