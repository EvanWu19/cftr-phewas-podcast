Ep4 (Track C — registry QC, 2 of 2): Half the recorded cancer stages were simply wrong

Park and colleagues (2025, JMIR Medical Informatics) build a 4-stage rule-based quality management process (QMP) for a 6,491-patient colorectal cancer registry at Gachon University, directly citing the Wells et al. missing-data paper from today's ep3. Before any correction, comparing existing recorded TNM/SEER codes against 164 manually re-coded reference cases found a 50% error rate for TNM and 31.1% for SEER among non-missing records; an auditable, phrase-level rule library built from Korean CRC staging guidelines and the SEER manual then matched that same reference set at 93.3%/93.9% concordance and cut missing-data rates (TNM 75.3%→35.7%, SEER 24.3%→18.5%) across all 6,491 cases — with TNM/T/N/M only emerging as important predictors in a downstream survival model after the fix (AUROC 0.856→0.872). Buildable artifact: an Expected-vs-Actual Feature Importance Scanner.

Plain-English glossary

  • AJCC TNM staging — the American Joint Committee on Cancer's standard cancer-staging system: T for primary tumor invasion depth, N for regional lymph node involvement, M for distant metastasis.（中文：美国癌症联合委员会制定的标准癌症分期系统：T代表原发肿瘤浸润深度，N代表区域淋巴结受累情况，M代表远处转移。）
  • Gradient Boosting Classifier — the feature-importance model used to compare theoretically-expected prognostic variables against what the real-world data actually ranked as important (standard ML, used here as a QC-targeting tool rather than a flagging model).（中文：本文用于比较"理论预期重要"的预后变量与真实世界数据实际排序重要性之间差异的特征重要性模型（标准机器学习方法，此处用作质量控制目标定位工具，而非标记模型）。）
  • Kahn framework / Weiskopf & Weng dimensions — two foundational EHR data-quality-assessment frameworks explicitly cited in this paper's discussion, naming dimensions like completeness and conformance for evaluating data quality.（中文：本文讨论部分明确引用的两个基础性电子健康档案数据质量评估框架，提出了完整性、一致性等用于评估数据质量的维度。）
  • SEER summary stage — a coarser cancer-staging system maintained by the US National Cancer Institute's SEER program, used internationally as a simpler alternative to full TNM.（中文：由美国国家癌症研究所SEER项目维护的一套更粗略的癌症分期系统，在国际上作为完整TNM分期的一种更简单的替代方案被广泛使用。）

Full citation

Methods / tools to lift

  • 4-stage QMP (Planning / Identification / Operation / Evaluation) — the overall rule-based correction workflow structure.
  • Literature-vs-data feature-importance mismatch — using a Gradient Boosting Classifier's variable rankings against theoretically-expected importance to decide which variables need QC attention, a variable-level (not record-level) targeting signal.
  • Automated stage classification library — an auditable library of keyword/phrase patterns (from clinical staging guidelines) mapped directly to TNM/SEER codes, independently re-deriving a structured value from pathology/imaging free text.

Where it lands + buildable artifact

Pipeline stage: (b) adjudication, primary — independent rule-based re-derivation of a structured value from source text gives a correctness check on an existing recorded code, transferable to checking a flagged height/weight record against other available fields for the same encounter. (a) candidate generation, secondary — the literature-vs-data feature-importance mismatch flags which variables across a dataset deserve QC attention, a level above record-level flagging. Buildable artifact: an Expected-vs-Actual Feature Importance Scanner — run a feature-importance model, compare against literature-derived expectations, flag under-performing variables as QC-priority targets.

Error types covered / not covered: Covers wrong-but-present categorical codes (via independent re-derivation) and missing categorical codes (same mechanism); does not address continuous-value errors like unit conversion, digit transposition, decimal-shift, or carry-forward, since the target variables here are categorical staging codes, not continuous anthropometric measurements.

What to verify first

  • Whether the 50%/31.1% baseline error rates and 93.3%/93.9% concordance figures, specific to this institution's reporting conventions and the Korean CRC guideline paired with AJCC 8th edition, transfer to a different registry's free-text conventions or to continuous fields like height/weight.
  • The automated library's true accuracy on previously-missing values specifically — the 164-case validation set explicitly excluded missing-value cases, so recovery accuracy on the harder subset remains unverified.
  • Whether a literature-vs-data feature-importance mismatch reliably signals a data-quality problem, as opposed to real clinical heterogeneity in a given population, before treating it as a QC trigger.
  • That a flagged discrepancy between two independently derived values isn't automatically treated as proof one of them is an error, given the authors' own caveat about multidisciplinary staging complexity.
