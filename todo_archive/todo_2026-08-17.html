Buildable artifacts surfaced across 330+ episodes, consolidated and scored · post-Liz-pivot framing

Last evaluated: 2026-08-17 · Cadence: re-score weekly (Mondays). A Progress column is reserved for future sessions — start a session and say "attack the to-do list" to update status and re-score.

What this is. Every episode ends with a "buildable artifact" — the concrete thing worth building off that paper. After the CFGP/WGS door closed and the project re-centered on Liz-sponsored data work + the Karen Raraigh genetics collaboration as the warm near-term move, these collapse into a small set of distinct, mostly public-data-only deliverables. 195 raw mentions across 334 episodes (plus signals from the listener Q&A feedback log) are consolidated into 21 distinct to-dos below (full source list in the appendix). Auto-updated weekly by a scheduled task that archives the prior version to todo_archive/ before rewriting.

Importance (1–5) — weight to career. 5 = directly breaks the bottleneck (Karen collaboration / AI-on-registry-depth positioning). Higher is better.
Feasibility / Access (1–5) — can you start now with what you have? 5 = inputs are all public, no gated data or GPU. Higher is better.
Hardness (1–5) — effort to push to visible output (a shared, citable artifact). 5 = very hard. Lower is better.
Priority = Importance + Feasibility + (6 − Hardness). Range 3–15. A quick-win ranking, not destiny — sort on any column.
