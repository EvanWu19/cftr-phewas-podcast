"nf-core/crisprseq: a versatile pipeline for comprehensive analysis of CRISPR gene editing and screening assays." NAR Genomics and Bioinformatics 2026;8(1):lqaf214. Ships nf-core/crisprseq, the first generic, open-source Nextflow DSL2 pipeline able to analyze both targeted CRISPR editing (knockouts, knock-ins, base editing, prime editing) and large-scale CRISPR screens (via MAGeCK RRA, MAGeCK MLE, BAGEL2, and DrugZ) inside a single, nf-core-community-engineered framework. Benchmarked against CRISPR-A (editing) and MAGeCK-VISPR (screening), it matches accuracy while cutting CPU usage roughly nine-fold on a real 6,196-sample dataset. The buildable artifact for tonight borrows the pipeline's "intersect two independent noisy classifiers, then network-refine the survivors" pattern — not the CRISPR biology itself — for a registry data-quality anomaly-flagging tool.

Plain-English glossary

  • sgRNA (single guide RNA) — A short RNA sequence complementary to a target DNA site that directs the Cas9 enzyme to cut there.（中文：单链引导RNA，一段与目标DNA位点互补的短RNA序列，用于引导Cas9酶在该位点切割。）
  • Knockout (KO) / knock-in (KI) — KO disrupts and depletes a gene via a Cas9 cut; KI instead repairs the cut via homology-directed repair to insert new DNA.（中文：基因敲除通过Cas9切割破坏并耗尽目标基因；基因敲入则通过同源重组修复的方式插入新的DNA。）
  • CRISPRa / CRISPRi — Modified, non-cutting Cas9 systems that turn gene expression up (activation) or down (interference) instead of cutting DNA.（中文：CRISPR激活/干扰系统，使用经改造、不切割DNA的Cas9来调高或调低基因表达。）
  • Base editing / prime editing — Techniques that make precise single-nucleotide substitutions or small insertions/deletions without creating a double-strand break.（中文：碱基编辑/引导编辑，能在不产生DNA双链断裂的情况下实现精确的单碱基替换或小片段插入删除。）
  • CRISPR screen / essential gene — A screen uses an sgRNA library to perturb many genes at once and measure fitness effects; a gene is "essential" if its loss meaningfully compromises cell viability.（中文：CRISPR筛选使用sgRNA文库同时扰动大量基因并测量其对细胞适应性的影响；若敲除某基因明显损害细胞存活能力，则该基因为"必需基因"。）
  • tracrRNA (trans-activating CRISPR RNA) — The scaffold RNA piece that lets the guide RNA actually load onto the Cas9 enzyme.（中文：反式激活CRISPR RNA，是让引导RNA能够真正装载到Cas9酶上的支架RNA片段。）
  • UMI (unique molecular identifier) — A short random DNA tag added to each original molecule before amplification, used to collapse PCR duplicates and count true original reads.（中文：唯一分子标识符，扩增前加到每个原始分子上的一小段随机DNA标签，用于折叠PCR重复序列并统计真实的原始read数。）
  • CIGAR string — The compact code in a sequence-alignment file describing exactly how a read matches the reference, insertion by insertion and deletion by deletion.（中文：CIGAR字符串，比对文件中的一种紧凑编码，逐个插入、逐个删除地描述read与参考序列的匹配方式。）
  • PPI network (protein-protein interaction network) / Hitselection — A graph where genes/proteins are nodes and interactions are edges; Hitselection refines a ranked hit list by checking how densely candidate genes cluster on this network.（中文：蛋白质相互作用网络，基因/蛋白质为节点、相互作用为边的图谱；Hitselection模块通过检查候选基因在该网络上的聚集密度来优化排序后的命中列表。）

Methods / tools to lift

  • nf-core/crisprseq — the full pipeline itself: two Nextflow DSL2 subworkflows (targeted editing, screening), containerized and CI-tested per release. GitHub: nf-core/crisprseq (MIT license); Zenodo DOI 10.5281/zenodo.7598496.
  • Hitselection module — a BIOGRID-PPI-network-based hit refinement step (an implementation of RNAiCut) that scores candidate-gene interconnectivity against a randomly-matched null network via a Poisson simulation.
  • Four-algorithm screening consensus (MAGeCK RRA / MAGeCK MLE / BAGEL2 / DrugZ) — running multiple independent gene-essentiality scorers side by side and intersecting at an FDR threshold, rather than trusting a single scorer.
  • FluteMLE / MultiQC — standardized QC and enrichment-visualization reporting bolted onto both subworkflows.

Where it lands + buildable artifact

Lands on Liz / CFFPR registry data quality (method only) — the CRISPR biology itself is not the transferable part; the pipeline's intersect-two-noisy-classifiers-then-network-refine pattern is. Buildable: Registry Anomaly-Flag Consensus Refiner — take registry height/weight records already carrying multiple independent implausible-value flags (z-score outlier check, cross-field consistency rule, visit-to-visit trajectory-jump detector), intersect the flags the way this pipeline intersects BAGEL2 and MAGeCK MLE, then build a lightweight similarity graph connecting records by shared clinic/time-window/data-entry pattern and use a Hitselection-style interconnectivity check to separate clustered flags (likely systematic data-entry issues) from isolated flags (likely genuine clinical outliers worth closer review). Difficulty: M (flag intersection is trivial; the similarity graph and interconnectivity check are the real engineering). Strictly a borrowed method — no claim made about how CFFPR itself is structured.

What to verify first

  • Whether a "patient similarity network" built from shared clinic/visit pattern is a sound analog to a curated gene PPI network — it would need its own validation before trusting a Hitselection-style density signal from it.
  • Whether Nextflow's parallelism, which clearly pays off at sequencing scale, buys anything meaningful for tabular, pandas-scale registry data that doesn't need a compute cluster.
  • The paper's Hitselection module requires Entrez-ID-mapped human genes specifically — any non-gene use case has to be re-derived from first principles, not assumed to carry over.

ALEX CRISPR-Cas9 editing works by guiding the Cas9 enzyme to a specific DNA sequence using a complementary single guide RNA, or sgRNA; Cas9 then cuts the DNA at that site. JORDAN And where do you want to push back? 你想在哪里提出异议？

ALEX Right there in Hitselection. 就是Hitselection这个地方。 It requires the sgRNA library to map to genes via a human Entrez ID, and it leans entirely on BIOGRID's existing network completeness to judge interconnectivity. 它要求sgRNA文库必须通过人类Entrez ID映射到基因，而且完全依赖BIOGRID现有网络的完整性来判断互联程度。 That's a reasonable design, but it quietly biases the refinement step toward well-studied genes that already have a rich, well-curated interaction network, and away from understudied genes whose real biology might be just as important but whose network entry is comparatively thin. 这是一个合理的设计，但它悄悄地把这个优化步骤偏向了那些已经有丰富、精心整理的互作网络的高研究度基因，而冷落了那些真实生物学意义可能同样重要、但在网络中条目稀疏的研究较少的基因。 Any network-based refinement step — not just this one — inherits whatever blind spots already exist in the reference network it's built on. 任何基于网络的优化步骤——不只是这一个——都会继承它所依赖的参考网络本身已经存在的盲点。
