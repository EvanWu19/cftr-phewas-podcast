How did this episode land for you?

Blurb

This episode is a single-paper deep dive on Schubach et al., "CADD v1.7: using protein language models, regulatory CNNs and other nucleotide-level scores to improve genome-wide variant predictions" (Nucleic Acids Research, Jan 2024). CADD has been the field's default genome-wide variant deleteriousness scorer for about a decade, trained by contrasting real human variants that survived natural selection against computationally simulated variants that never had to. Version 1.7 adds six new annotation features — most notably a protein language model (ESM-1v) and a lightweight regulatory CNN (RegSeq) — on top of the same stable logistic-regression architecture. This lands primarily as an AI-tooling/career pick: CADD ships open-source code, a webserver, an API, and a reproducible Snakemake pipeline, making it a strong candidate to wrap into a reusable variant-annotation tool. The episode proposes a concrete buildable artifact: a Snakemake-based CADD v1.7 offline-scoring wrapper for any gene's VCF. Note: this paper contains no CF-specific gene findings — F9/Factor IX and hemoglobin appear only as generic benchmark examples, not CF-modifier results.

Glossary (Beat 2 terms, alphabetical)

  • C-score — The PHRED-scaled version of CADD's raw logistic-regression output; represents a variant's percentile rank among all possible human SNVs (20 = top 1% most deleterious-looking, 30 = top 0.1%).（中文:CADD 评分系统输出的标度化分数,表示某变异在所有可能的人类SNV中有害性排名的百分位。）
  • CADD — Combined Annotation Dependent Depletion; a decade-old, widely used genome-wide tool that scores SNVs and short InDels across coding and non-coding DNA.（中文:综合注释依赖消减评分,一种全基因组变异有害性评分工具,适用于编码和非编码区域。）
  • de novo variant — A variant that arises fresh in an individual rather than being inherited; CADD's simulated "proxy-deleterious" set is built from these.（中文:个体中新发生、而非遗传而来的变异。）
  • Deep Mutational Scanning (DMS) — An experimental method that mutates every position in a protein and measures the functional effect directly in the lab, used here to validate protein-level scores like ESM-1v.（中文:深度突变扫描,一种逐一突变蛋白质每个位点并在实验室直接测量功能影响的实验方法。）
  • ESM-1v — Meta's 650-million-parameter protein language model, trained unsupervised on protein sequence databases, that scores how "surprising" a mutated protein sequence looks.（中文:Meta公司开发的6.5亿参数蛋白质语言模型,以无监督方式在蛋白质序列数据库上训练,用于评估突变后蛋白序列的"意外程度"。）
  • InDel — Insertion/Deletion; a short insertion or deletion variant, as opposed to a single-nucleotide substitution.（中文:插入缺失变异,指基因组中短片段的插入或缺失,区别于单个碱基替换。）
  • MPRA (massively parallel reporter assay) — An experimental technique that tests many regulatory DNA sequence variants in parallel using reporter genes, used to validate regulatory scores like RegSeq.（中文:大规模平行报告基因实验,一种利用报告基因并行测试大量调控DNA序列变异的实验技术。）
  • natural selection — The evolutionary process by which harmful variants tend to be filtered out of a population over generations; CADD's "proxy-neutral" variants are ones inferred to have survived it.（中文:自然选择,指有害变异在世代更替中逐渐被淘汰的进化过程。）
  • PHRED — A log-scaled quality/rank scoring convention (familiar from sequencing quality scores) that CADD reuses to express a variant's percentile rank as a single number.（中文:一种对数刻度的评分方式,常见于测序质量分数,CADD借用它来表示变异的百分位排名。）
  • primate whole-genome alignment — Comparing whole genome sequences across primate species to infer which human variants arose and persisted in the lineage, the basis for CADD's proxy-neutral set.（中文:灵长类全基因组比对,通过比较灵长类物种的全基因组序列,推断哪些人类变异在谱系中产生并存留下来。）
  • protein language model — A model (like ESM-1v) trained on large protein sequence databases, unsupervised, to learn the statistical patterns of "normal" versus "surprising" protein sequences.（中文:蛋白质语言模型,在大规模蛋白质序列数据库上以无监督方式训练,用于学习"正常"与"异常"蛋白序列的统计规律。）
  • proxy-deleterious variant — A computationally simulated de novo variant, matched in substitution/indel statistics to real variants but never filtered by selection, used as CADD's stand-in for "potentially harmful."（中文:代理有害变异,一种计算模拟生成的新生变异,其突变统计特征与真实变异匹配,但从未经过自然选择过滤,被用作CADD中"潜在有害"的替代标签。）
  • proxy-neutral variant — A real human variant inferred (via primate alignments) to have arisen and survived millions of years of selection, used as CADD's stand-in for "probably harmless."（中文:代理中性变异,一种通过灵长类比对推断出的、在数百万年自然选择中产生并存活下来的真实人类变异,被用作CADD中"可能无害"的替代标签。）
  • SNV — Single Nucleotide Variant; a change at a single base position in the genome.（中文:单核苷酸变异,指基因组中单个碱基位置发生的变化。）
  • transformer — The deep-learning architecture underlying ESM-1v, built to learn long-range patterns in sequential data (here, protein sequences).（中文:一种深度学习架构,是ESM-1v的基础,用于学习序列数据(此处为蛋白质序列)中的长程模式。）

Methods/tools to lift

  • ESM-1v — protein language model score for missense, inframe indel, and frameshift/stop-gain variants.
  • RegSeq — small custom CNN (3 conv + 2 dense layers, 500bp window) predicting regulatory-element membership; a deliberate speed/accuracy tradeoff against Enformer.
  • Zoonomia — 241-mammalian-genome conservation score (up from 43 in prior CADD versions).
  • Roulette — sequence-context-aware local mutation-rate/mutability score.
  • APARENT2 — deep-learning score for variant impact on 3' polyadenylation/cleavage.
  • CADD-scripts / Snakemake pipeline — the open-source, reproducible offline-scoring pipeline (GitHub: kircherlab/CADD-scripts), plus webserver, REST API, and bigWig genome-browser tracks.

Where it lands + buildable artifact

Priority: AI-tooling/career. CADD v1.7 is a reusable, open-source, genome-wide annotation engine — exactly the kind of tool worth wrapping into a standing pipeline rather than a one-off script.

Paste-ready MVP: Build a Snakemake-based CADD v1.7 offline-scoring wrapper that takes any gene's VCF as input and, in one reproducible pass, annotates every variant with both the coding-side ESM-1v deleteriousness score and the regulatory-side RegSeq score, outputting a single ranked summary table. Difficulty: Medium.

What to verify first

  • Whether CADD's non-coding performance is good enough for CFTR-specific regulatory and deep-intronic variants (the paper's own non-coding validation is thinner than its coding validation).
  • The compute cost of running ESM-1v/RegSeq-based offline scoring at scale, including the environmental-footprint concern the authors themselves raise.
  • Version-pinning: CADD updates roughly annually, and v1.7 may be the last version to support GRCh37 before a shift toward GRCh38/pangenome representations.
  • Whether ESM-1v- and RegSeq-derived features would need re-validation on a CF-specific variant set before trusting their rankings for our own work.
