T-rex: standardized analysis of germline variants in whole-exome sequencing trios

Reh SL, Walter C, Lohse J, Ghete T, Metzler M, Hauer J, Auer F. Scientific Reports 2026.

T-Rex (Trio Rare variant analysis of EXomes) is a free, precompiled, cross-platform desktop application that runs a complete trio whole-exome sequencing (WES) pipeline — alignment through dual-variant calling, annotation, rare-variant filtering, and family-based statistical testing — entirely locally, without requiring programming knowledge or sending raw sequencing data anywhere. Its headline design choice is a precision-first dual-caller strategy (GATK HaplotypeCaller + VarScan2, intersected), benchmarked on the GIAB Ashkenazim reference trio at 99.2% precision and 91.1% sensitivity versus GATK alone's 95.5% sensitivity with far more false positives. Applied to a real cohort of 121 pediatric cancer trios, it reproduced 100% of previously reported clinically actionable variants with zero new false positives. It lands on the AI-tooling/career priority — the open-source code (GitHub, Zenodo-archived) is a clean example of accessible, reproducible genomics tooling — and this episode's buildable artifact is a T-Rex Dual-Caller Consensus Replica (S-M): rebuilding just the GATK+VarScan2+BCFtools intersection logic against public GIAB data to reproduce its precision/sensitivity numbers independently.

Plain-English glossary

De novo variant — A variant present in a child but absent in both parents, indicating it arose newly in that generation; a strong signal in pediatric disease with no family history to follow.（中文：存在于孩子体内但父母双方都没有的变异，表示该变异是这一代新出现的，在没有家族史可循的儿科疾病中是重要信号。）

Dual-caller consensus — Running two independent variant-calling algorithms on the same sequencing reads and keeping only the variants both agree on, trading some sensitivity for higher precision.（中文：对同一组测序读长独立运行两种变异检出算法，只保留两者一致认定的变异，以牺牲部分灵敏度换取更高的精确度。）

GIAB (Genome in a Bottle) — A U.S. National Institute of Standards and Technology-led reference trio dataset with independently confirmed "true" variants, used as the standard benchmark for variant-calling accuracy.（中文：由美国国家标准与技术研究院牵头建立的参考三人组数据集，其真实变异已经过独立确认，是变异检出准确性的标准基准。）

TDT (Transmission Disequilibrium Test) — A statistical test asking whether a variant is transmitted from heterozygous parents to affected children more often than the expected 50%, robust to population-stratification confounding.（中文：传递不平衡检验，检验某变异从杂合型父母传递给患病子女的频率是否显著高于预期的50%，对人群分层混杂因素具有稳健性。）

Trio sequencing — Sequencing an affected child together with both biological parents to distinguish inherited variants from those that arose new in the child.（中文：对患病儿童及其父母双方同时进行测序，以区分遗传变异与孩子体内新出现的变异。）

Full citation: Reh SL, et al. "T-rex: standardized analysis of germline variants in whole-exome sequencing trios." Scientific Reports 2026. — PMID: 42675100 — PMCID: PMC13529699 — DOI: 10.1038/s41598-026-67762-w

Methods / tools to lift

  • Dual-variant-caller consensus (GATK HaplotypeCaller + VarScan2, intersected via BCFtools) — a reusable precision-first pattern for rare-variant calling.
  • SNPEff/SNPSift annotation against gnomAD v4.1 (including ancestry-specific subsets) and ClinVar.
  • Transmission Disequilibrium Test (TDT) plus Fisher's exact/chi-square case-population testing, with Bonferroni multiple-testing correction.
  • Open-source, precompiled, cross-platform (macOS/Linux/Windows) desktop packaging pattern — Python + Tkinter/CustomTkinter, MVC architecture, headless/parallel server mode for advanced users.
  • Code: github.com/SaraLuisaReh/trex; archived release: 10.5281/zenodo.19135261.

Where it lands + buildable artifact

AI-tooling/career (not Karen or Liz — no CFFPR-specific claim made). Buildable artifact / tool sketch: T-Rex Dual-Caller Consensus Replica (S-M) — pull public GIAB HG002 Ashkenazim trio FASTQs, run GATK HaplotypeCaller and VarScan2 independently, intersect with BCFtools, and reproduce the paper's precision (99.2%), sensitivity (91.1%), and F1 (95.0%) numbers end to end as an independent validation exercise.

What to verify first

  • Whether a precision-first dual-caller tradeoff is actually right for a given use case, versus a single higher-sensitivity caller.
  • Whether the GIAB benchmark numbers (one reference trio, one ancestry) generalize across sequencing centers, capture kits, or ancestries.
  • Whether the TDT's case-parent statistical assumptions, validated here in a cancer-predisposition cohort, transfer cleanly to a recessive, non-cancer disease context.
  • Scope boundaries as shipped: short-read Illumina WES and germline calling only — no WGS, long-read, somatic calling, or direct HPC scheduler integration.
