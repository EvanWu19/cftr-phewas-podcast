How did this episode land for you?

Track B — AI for Registry/Bioinformatics Tooling

Blurb

We read Palchuk et al. (JAMIA Open, 2023), the paper describing TriNetX, a commercially funded global federated network of real-world EHR data. It has more than 220 HCOs under contract across 30 countries, and patient data stays inside each institution's own data center. We treat it as a system-design case study. We cover the industry-pays, HCO-contributes business model and why the authors set it against grant-funded networks like caBIG and EHR4CR that stalled when funding ran out. We also cover syntactic harmonization into a common data model and a domain-by-domain semantic crosswalk: ICD-10-CM, SNOMED, RxNorm plus OMOP extensions, LOINC via RELMA and UCUM, and HGVS/HGNC scoped to observed variants. The last piece is privacy-preserving token-based record linkage. The results are operational, not benchmarked: 56 billion facts, sub-second count queries and 99.5%+ uptime. We close with a buildable mapping-confidence QA checker that flags lossy many-to-one collapses and implausible value distributions.

Glossary

  • Common data model (CDM) — A shared schema that fixes tables, fields, and event representation so one query runs identically at every site.（中文：通用数据模型，统一各机构数据结构的标准表结构）
  • Crosswalk / terminology mapping — A lookup table that translates codes from a source vocabulary into a target standard (e.g., local lab code → LOINC).（中文：对照表／术语映射，把源编码体系转换为目标标准编码）
  • De-identification — Removing direct identifiers, or expert certification of very low re-identification risk, so data can be used for research under HIPAA.（中文：去标识化，去除或认证可识别个人身份的信息）
  • Federated network — A network where data stays at each site, queries travel to the data, and only aggregate results return.（中文：联邦式网络，数据不出本地、只返回汇总结果）
  • Limited data set — A HIPAA category that keeps some indirect identifiers (such as certain dates) and is shared under stricter conditions than de-identified data.（中文：有限数据集，保留部分间接标识符、共享条件更严格的数据）
  • Privacy-preserving record linkage — Linking the same real person across separately de-identified datasets with third-party cryptographic tokens instead of direct identifiers.（中文：隐私保护记录链接，用加密令牌跨数据集链接同一患者而不暴露身份）
  • Semantic harmonization — Mapping the meaning of codes and values onto common target terminologies, domain by domain.（中文：语义协调，把编码含义映射到统一的目标术语）
  • Syntactic harmonization — Loading source data into the common data model's structure, regardless of what the codes mean.（中文：句法协调，把源数据导入统一的数据结构）

Methods/tools to lift

  • RELMA (Regenstrief LOINC Mapping Assistant) — the tool used to map local lab/vitals codes to LOINC, targeting at least 80% of each site's most frequent observation codes.
  • UCUM (Unified Code for Units of Measure) — the standard used to convert lab units automatically during mapping.
  • RxNorm ApproximateTerm API — semi-automated medication mapping that breaks national drug catalogs down into ingredient, route, brand and strength.
  • OMOP RxNorm Extensions — extend RxNorm beyond the US market so ex-US medications can be mapped.
  • String-matching ICD crosswalks — match WHO ICD-10 to ICD-10-CM by identical descriptions even when the codes sit in different hierarchy branches.
  • Nearest-common-ancestor collapse — maps more-specific national codes (e.g., ICD-10-AM) up to a coarser ICD-10-CM parent, a deliberate one-way loss of granularity.
  • Distribution-based mapping QA — checks that lab result value distributions look plausible for the proposed target code.
  • Data-driven (observed-only) terminology scoping — adds HGVS/HGNC-named variants to the terminology only when they are seen in contributed data.
  • Unmapped-concept tracking with refresh cadence — re-evaluates unmapped codes as targets update (quarterly for meds, yearly otherwise).
  • Privacy-preserving cryptographic token linkage — third-party tokens join records for the same person across HCOs, claims and mortality data.
  • Multi-format ingestion connectors — move from i2b2-only ingestion to OMOP, FHIR, HL7, direct-to-EHR and API pipelines.
  • Open-source OPS-to-SNOMED mapping — the German procedure crosswalk built with Averbis, released at open.trinetx.com.

Where it lands + buildable artifact

Priority: AI-tooling / career (RWE methods & registry/CDM harmonization tooling).

Why it's relevant: This is a production-scale worked example of common-data-model harmonization across six or more clinical domains, with a specific tool choice for each domain, plus federated privacy-preserving linkage. That is the core skill set for senior RWE × genomics data-science roles. It is an architecture paper, not an open-source tool release (the platform is proprietary; only the OPS-to-SNOMED mapping is open), so what you can take from it is the harmonization pattern and the tool choices. There is no repo to clone.

Buildable artifact (paste-ready MVP): A mapping-confidence QA checker for a registry→CDM harmonization pipeline (e.g., an internal OMOP mapping). It reads a proposed source-code→target mapping table (local code → ICD-10-CM / LOINC / RxNorm) plus per-concept summary statistics of observed values. It outputs a ranked human-review list with two kinds of flag: (a) many-to-one collapses, where several distinct source codes map to one coarser target (potential information loss, modeled on the ICD-10-AM → ICD-10-CM pattern); (b) lab/vitals mappings whose observed value distribution looks implausible for the claimed LOINC code (modeled on TriNetX's distribution-based validation). Difficulty: S–M. It is a rules and summary-statistics script over an existing mapping table, not new modeling. The main effort is sourcing plausible reference ranges for each target code.

What to verify first

  • Portability: RELMA, the ApproximateTerm API and string-matching ICD crosswalks are specific to TriNetX's vendor stack. We'd need to check which of them map onto tools/APIs already available for the relevant CDM or terminology work, and which would need different tooling entirely.
  • Scale mismatch: 56B facts, 100M+ patients and 220+ HCOs make a very large network. We'd need to check which lessons scale down (refresh cadence, unmapped-concept tracking and distribution QA likely do) and which don't (federated query performance and infrastructure may not transfer to a smaller single-registry context).
  • Record-linkage applicability: Cryptographic-token linkage solves cross-institution linking of de-identified data. We'd need to check whether that problem is even relevant in a single-registry context.
  • Maintenance burden: Quarterly medication refreshes, yearly refreshes for other terminologies and ongoing unmapped-concept review are continuous processes. We'd need to check what ongoing capacity any adopted approach would actually require before committing.

JORDAN What about procedures and medications? 那手术操作和药物呢？

JORDAN Can that catch subtle errors, though? 但这能发现细微的错误吗？

ALEX That's my second skepticism. 这是我的第二个质疑。 It should catch gross errors, like mapped values that are clearly implausible for the analyte. 它应该能发现明显的错误，比如映射后的数值对该分析物来说明显不合理。 But two analytes with overlapping ranges could slip through, and the paper doesn't quantify how well the check performs. 但数值范围相互重叠的两种分析物可能会漏网，而且论文并没有量化这项检查的效果。

JORDAN And genomics? 那基因组学呢？

ALEX Variants are named with HGVS under HGNC gene symbols. 变异按HGVS（人类基因组变异命名规范）命名，并归属于HGNC（人类基因命名委员会）批准的基因符号之下。 To keep the terminology tractable, only variants actually observed in contributing HCOs' data get added. 为了让术语体系保持可控，只有在贡献数据的HCO中实际观察到的变异才会被加入。 Unmapped concepts are tracked and re-evaluated as target standards refresh, quarterly for medications and yearly otherwise. 未能映射的概念会被跟踪记录，并随着目标标准的更新而重新评估：药物术语每季度更新一次，其他术语每年更新一次。

JORDAN Last piece, linking patients across sites. 最后一部分，跨站点链接患者。
