Outlier detection for questionnaire data in biobanks

Sakurai, Ueki, Makino and colleagues (International Journal of Epidemiology, 2019) propose two linked unsupervised methods for biobank data cleaning: kurPCA, which runs PCA across epidemiologic/questionnaire variables and flags components whose score distributions show excess kurtosis (heavy tails) as outlier-bearing, surfacing the extreme-scoring records as candidates; and RAMP, a regression-adjustment approach that groups records by their systematic (questionnaire-skip-driven) missingness pattern so that a legitimate skip-logic subgroup doesn't get mistaken for an outlier cluster. Applied to Tohoku Medical Megabank epidemiological record data, the combination is reported to "effectively detect known errors or inconsistent patterns," with simulation and real-application results both described as showing good performance — though the abstract gives no sensitivity/specificity numbers and this paper is closed access (no PMC record, and the Unpaywall PDF link returned HTTP 403 on request), so everything here is abstract-level and flagged as such on-air. For Runyu, this is primarily a candidate-generation idea: a multivariate, joint-field outlier scan that's complementary to a single-trajectory spline/mixed-effects flagger, plus a transferable vocabulary — stratifying by structural missingness pattern before judging anything anomalous.

Plain-English glossary

  • kurtosis — a measure of how heavy-tailed a distribution is relative to a normal distribution; used here as the trigger statistic for flagging a principal component as outlier-bearing.（中文:衡量一个分布相对于正态分布有多"厚尾"的统计量;本文中用作判断某个主成分是否携带异常值的触发统计量。）
  • principal component analysis (PCA) — a technique that re-expresses correlated variables as a smaller set of uncorrelated components; here applied across epidemiologic/questionnaire fields rather than growth measurements.（中文:将相关变量重新表达为一组较少的不相关成分的方法;本文中应用于流行病学/问卷字段,而非生长测量数据。）
  • regression adjustment — using a fitted regression relationship to correct or standardize values before further analysis; RAMP applies this within groups defined by missingness pattern.（中文:使用拟合的回归关系在进一步分析之前对数值进行校正或标准化;RAMP在按缺失模式划分的组内应用这一方法。）
  • skip logic (questionnaire branching) — survey design where a response to one question determines whether a whole subsequent block of questions is asked; produces missingness that is structural, not random.（中文:一种问卷设计,某一题的回答决定是否要问后面整整一块问题;这会产生结构性而非随机的缺失。）
  • systematic missingness pattern — a block of fields missing together because of structural (e.g. skip-logic) reasons rather than random dropout.（中文:因结构性原因(如跳题逻辑)而一起缺失的一块字段,区别于随机脱落造成的缺失。）

Methods / tools to lift

  • kurPCA — PCA across correlated fields + kurtosis of component scores as an unsupervised multivariate outlier signal.
  • RAMP — regression adjustment stratified by systematic missingness pattern, to keep legitimate skip-logic subgroups from being flagged as outliers.

What to verify first

  • Whether the kurtosis threshold used is specific to Tohoku Medical Megabank's questionnaire structure and would need recalibration for a differently structured registry.
  • How finely RAMP stratified missingness patterns in practice, since very small strata make within-stratum regression adjustment unstable.

Pipeline stage: (a) candidate generation — a multivariate complement to single-trajectory flagging; secondarily (e) vocabulary/framework — the missingness-pattern-stratification idea.

Error types covered / not covered: Covered (in spirit, per abstract): multivariate/joint-field inconsistency that doesn't show up in any single value alone. Not covered / unknown from the abstract: unit conversion errors, digit transposition, decimal-shift errors, carry-forward errors, and distinguishing a true outlier from a real but unusual clinical event — none of these are addressed or ruled out by the available text.
