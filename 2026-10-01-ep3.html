How did this episode land for you?

A rigorous algorithm to detect and clean inaccurate adult height records within EHR systems

Muthalagu and colleagues (2014) address a problem growthcleanr-style pediatric tools were never built for: cleaning adult height, where the data-generating process isn't a flat line but a slow, real, age-related decline (disc compression, osteoporotic vertebral changes, mild kyphosis — roughly a centimeter per decade after midlife). Using only height values and recorded ages — no weight, no other vitals — they built an algorithm sensitive to that normal decline, implemented it as a freely available open-source tool, and tested it against 33,937 height records from the Northwestern biobank, flagging 1,262 (3.7%) as erroneous. Correcting those values shifted the median recorded height by 7.6 cm and median BMI by 2.9 kg/m², and — the strongest part of the design — cleaned values matched true observer-measured height within 3.5 cm for 94.5% of records (95% CI 93.8–95.2%), a genuine external gold standard rather than a distributional assumption. The approach was partially replicated at the Marshfield Clinic biobank via the eMERGE consortium. This episode is built entirely from the structured abstract: the publisher blocks full-text XML download even through PMC, so the algorithm's exact decision logic and thresholds are not described on-air. For the registry-QC track, this is a pipeline-stage (a) paper, primary — an independent, lightweight candidate generator for the adult-measurement population specifically — with a secondary touch on (d) evaluation via its observer-measured validation template.

Plain-English glossary

Conformance (vs. plausibility) — a data-quality distinction: conformance asks whether a value matches its expected type/format/range; plausibility asks whether that value is believable as a fact about this specific patient at this specific time — a value can conform perfectly and still be implausible.（中文:数据质量中的一个区分:一致性[conformance]问的是数值是否符合预期的类型/格式/范围;合理性[plausibility]问的是这个数值作为关于该具体患者在该具体时间点的事实是否可信——一个数值可以完全符合格式要求,却仍然不合理。）

eMERGE consortium — a US network linking biobanks to electronic health record data specifically to support genomic research; supplied this paper's replication cohort (Marshfield Clinic).（中文:一个美国研究网络,专门把生物样本库与电子健康记录数据关联起来以支持基因组学研究;本文的复现队列[Marshfield Clinic]即来自该联盟。）

Kyphosis — an exaggerated forward curvature of the upper spine; one of the normal age-related postural changes that contributes to gradual adult height decline.（中文:上背部过度向前弯曲;是导致成人身高随年龄缓慢下降的正常姿势性变化之一。）

Observer-measured value (external gold standard) — a measurement taken directly by a person as ground truth, as opposed to a value pulled from another EHR entry; used here to validate cleaned height values independently of the cleaning algorithm's own internal logic.（中文:由真人直接测量得到的、作为金标准的数值,区别于从另一条EHR记录中提取的数值;本文用它来独立于清洗算法自身逻辑,对清洗后的身高数值进行验证。）

Research-ready data — data that is not just correctly formatted ("recorded") but believable as a fact about a specific patient's trajectory over time — the harder, within-patient judgment this paper automates for height.（中文:不仅格式正确["已记录"],而且作为关于某具体患者长期轨迹的事实本身可信的数据——这正是本文针对身高这一变量所要自动化实现的、更难的患者内部判断。）

Methods / tools to lift

  • Height-and-age-only candidate generator — a two-column, lightweight flagging approach requiring no other vitals or covariates, usable against any registry with minimal schema requirements.
  • Observer-measured external validation design — comparing cleaned values against true physical remeasurement, a reusable validation template beyond this specific algorithm.
  • Cross-biobank replication via a shared consortium (eMERGE) — a pattern for testing generalization of a cleaning method across independent data sources.
