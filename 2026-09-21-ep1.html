Blurb

A worked reclassification case, the direct follow-on to yesterday's noncoding-variant review: two Turkish girls with brachyolmia type 4 carried homozygous PAPSS2 missense variants — c.227T>A p.(Leu76Gln) and c.143C>G p.(Thr48Arg) — both sitting as VUS in ClinVar. Bozlak, Yavas, and Eslamkhah (2026, Medicina) ran both through an integrated multi-modal pipeline — AlphaMissense, REVEL, CADD, seven-species evolutionary conservation, AlphaFold2 structural modeling, and Grantham/Kyte-Doolittle physicochemical scoring — and combined the results with family segregation and previously published functional data under 2015 ACMG/AMP criteria to reclassify both variants from VUS to Likely Pathogenic, with no new wet-lab assay of their own. A notable methodological discipline: the whole computational stack was bundled into one PP3 code rather than counted as several independent supporting lines, avoiding correlated-evidence inflation. A genuinely interesting negative finding: despite carrying the same p.(Thr48Arg) variant as the 2009 index patient with androgen excess, these prepubertal probands showed completely normal androgens — pathogenicity at the molecular level doesn't fix penetrance. PAPSS2 causes a skeletal/endocrine disorder, not CF, and CFTR is never mentioned in the paper; the transfer to Karen Raraigh's CFTR VUS work is this podcast's own framing, built around a proposed CFTR VUS evidence-stacking worksheet.

Plain-English glossary

  • ACMG/AMP evidence codes — The 2015 joint American College of Medical Genetics and Genomics / Association for Molecular Pathology framework for combining named, weighted evidence lines (e.g. PS3, PM1, PM2, PP1, PP3, PP4) into a final variant classification.（中文：2015年ACMG/AMP联合框架，通过组合一系列命名的、有权重的证据类别得出变异的最终分类。）
  • AlphaMissense — A deep learning model built on the AlphaFold2 architecture that scores missense variant pathogenicity on a 0–1 scale.（中文：一个建立在AlphaFold2架构上的深度学习模型，以0到1量表给错义变异的致病性打分。）
  • CADD (Phred-scaled) — A genomic deleteriousness score; values above 20 mark the top 1% most damaging changes genome-wide.（中文：一种基因组有害性评分，Phred缩放值超过20即代表在全基因组范围内最有害的前1%。）
  • Grantham distance — A numeric score for how chemically different two amino acids are; a larger value means a more radical substitution.（中文：衡量两个氨基酸化学性质差异大小的数值分数，数值越大代表替换越剧烈。）
  • Missense variant — A DNA change that substitutes one amino acid for another in the resulting protein, without truncating it.（中文：错义变异，指DNA变化导致蛋白质中一个氨基酸被替换为另一个，但蛋白质本身不被截断。）
  • PP3 / PS3 / PM1 / PM2 / PP1 / PP4 — Individual ACMG/AMP evidence codes: PP3 = computational evidence supportive of damage; PS3 = strong functional-assay evidence; PM1 = variant in a critical functional domain/hotspot; PM2 = rare/absent in population databases; PP1 = co-segregates with disease in a family; PP4 = phenotype specifically matches the disease.（中文：ACMG/AMP的具体证据代码：PP3为支持性的计算证据；PS3为强功能实验证据；PM1为位于关键功能域/热点；PM2为在群体数据库中罕见或缺失；PP1为在家系中与疾病共分离；PP4为表型与该疾病特异吻合。）
  • REVEL — An ensemble pathogenicity score aggregating 13 independent computational prediction tools into one consensus number.（中文：一种集成致病性评分，汇总13个独立计算预测工具得出一个共识分数。）
  • VUS (variant of uncertain significance) — The ACMG/AMP classification bucket for a variant with insufficient evidence to call pathogenic or benign.（中文：意义未明变异，指证据不足以判定为致病或良性的ACMG/AMP分类类别。）

Methods / tools to lift

  • The full ACMG/AMP evidence-code assembly pattern: assign each computational/structural output to a named code rather than treating "the scores look bad" as a verdict.
  • Bundling correlated computational tools (AlphaMissense, REVEL, CADD, conservation) into a single PP3 code rather than double- or quadruple-counting correlated evidence as independent supporting lines.
  • AlphaFold2 structural modeling plus Predicted Aligned Error as a confidence check before drawing mechanistic conclusions from a predicted structure.
  • Grantham distance and Kyte-Doolittle hydropathicity as independent physicochemical evidence lines, separate from deep-learning scores.
  • Requiring a PS3 functional-evidence citation to be at the exact same residue, not merely nearby or homologous, before it counts.

Priority served: Karen Raraigh / CFTR variant interpretation (one only).

Artifact: CFTR VUS evidence-stacking worksheet. Difficulty S.

MVP line: a one-row-per-variant spreadsheet template with AlphaMissense/REVEL/CADD bundled into a single explicit PP3 field, a PM1 column checking membership in a predefined CFTR functional-domain/hotspot list, a PM2 column auto-pulling gnomAD frequency, a PP1 column for segregation data when a family is available, and a PS3 column filled in only when a published functional assay exists at that exact residue, citation attached.

Every input already exists as a public API or download; the discipline is entirely in the bundling rule and the citation requirement, not new modeling.

What to verify first

  • Does bundling AlphaMissense/REVEL/CADD into one PP3 code match current ClinGen guidance, or has that guidance since split into weighted tiers?
  • Is there a published, version-pinned CFTR functional-domain/hotspot list usable for a PM1 column, or would that require new curation?
  • For CFTR VUS candidates, how many have a published functional assay at the exact same residue versus only a nearby/homologous one?
  • Are we keeping "variant is pathogenic" and "patient outcome is predictable" as separate claims, given this paper's own negative penetrance finding in prepubertal carriers?
