How did this episode land for you?

Ep4 (Track C 2/2 — registry QC): How many subjects does a trustworthy growth reference curve actually need?

Tim Cole — originator of the LMS method for growth charts — asks a design question nobody had rigorously answered: how many subjects, and at what ages, does a growth reference centile study need to achieve a given precision? Using a GAMLSS (BCCG) model fit to 6,878 boys from the Fourth Dutch Growth Study, he simulates alternative age-sampling schemes defined by a single parameter λ (sampling uniformly on age^λ) and measures precision as the standard error of a centile in z-score units (SEz), which turns out to be nearly identical across weight, height, BMI, and head circumference. The optimal λ depends on which centile you're designing for: the median wants heavy infant oversampling (λ≈0.38), while the outer 2nd/98th centiles — the ones with the widest, most consequential confidence bands — want much closer to uniform sampling (λ≈0.76). Smoothing itself "borrows strength," quantified here for the first time at roughly 2.3× the naive sample size. Bottom line: 7,000–25,000 subjects per sex for a well-designed reference study. This is substrate-reliability material: any z-score-based outlier flag silently trusts that the reference curve's own precision is small and roughly constant, an assumption this paper shows can fail at the edges of the sampled age range. Buildable artifact: a Reference-Curve Precision Auditor. Paired today with ep3's applied LLM-surveillance workflow-efficiency paper as a deliberate applied-vs-foundational contrast.

Plain-English glossary

  • BCCG (Box-Cox Cole-Green distribution) — the GAMLSS distribution equivalent to the original LMS method, modeling only skewness (not kurtosis) in age-varying reference curves.（中文：与原始LMS法等价的GAMLSS分布，只对偏度建模而不对峰度建模，用于构建随年龄变化的参考曲线。）
  • "Borrowing strength" — the effect by which smoothing a centile curve across age increases the effective sample size at any given age by using information from neighboring ages.（中文：在跨年龄平滑百分位曲线时，通过利用邻近年龄的信息，提升某一特定年龄下有效样本量的效应。）
  • GAMLSS (Generalized Additive Models for Location Scale and Shape) — a model family that fits smooth age-varying curves for a distribution's moments (median, variability, skewness, and optionally kurtosis).（中文：广义位置-尺度-形状加性模型，一类针对分布各阶矩（中位数、变异性、偏度，可选峰度）拟合随年龄变化的平滑曲线的模型家族。）
  • LMS method — Cole's original method for constructing growth reference centiles from three smooth age-varying curves: median (M), coefficient of variation (S), and skewness (L); now a special case within GAMLSS.（中文：Cole最初提出的生长参考百分位曲线构建方法，基于三条随年龄变化的平滑曲线：中位数（M）、变异系数（S）和偏度（L）；现已成为GAMLSS框架下的一个特例。）
  • SEz — the standard error of a centile estimate, expressed in z-score units rather than raw measurement units, which is nearly constant across different measurement types and symmetric centile pairs.（中文：以z分数单位（而非原始测量单位）表示的百分位估计标准误，在不同测量类型和对称百分位对之间几乎保持恒定。）
  • Worm plot — a diagnostic plot of detrended residuals within age bands used to reveal where along the age range a fitted reference curve is systematically off.（中文：一种在各年龄段内绘制去趋势残差的诊断图，用于揭示拟合参考曲线在年龄范围的哪个位置存在系统性偏差。）

Methods / tools to lift

  • GAMLSS BCCG model (R package gamlss) — fits smooth median/CV/skewness curves against age; the standard engine behind LMS-style growth references.
  • age^λ sampling-composition function — a one-parameter way to specify how much a study design should oversample infancy versus later childhood.
  • SEz as a unifying precision metric — collapses what looks like separate design problems per measurement/centile into one.
  • Generalized AIC / worm plot — model-selection and fit-diagnostic tools used alongside the precision framework.

Where it lands + buildable artifact

Pipeline stage (a), candidate generation, primary — the substrate reliability behind any z-score-based flagging threshold; secondary (e), framework/vocabulary. Buildable artifact: Reference-Curve Precision Auditor — given a published LMS/GAMLSS reference table plus per-age sample-size documentation (where available), estimate an approximate SEz-vs-age curve and flag age windows where flagging thresholds are least trustworthy. Difficulty: S–M.

What to verify first

  • The framework is restricted to cross-sectional (one-measurement-per-subject) designs; it explicitly excludes longitudinal/repeated-measures studies, where correlated visits reduce effective information and visit-timing bias can creep in (echoes the visit-process concerns from earlier Track C episodes).
  • All simulation results are derived from boys-only data; the paper argues, but does not test, that girls should behave similarly.
  • This is a theoretical/simulation result from one national dataset's shape — whether CDC, WHO, or any other specific published reference was actually designed with anything close to this optimal sample composition is an open empirical question about that reference, not something this paper settles generally.
  • Any practical precision claim for a specific reference curve needs that curve's actual per-age-group sample sizes, not an assumed-uniform-precision stand-in.

Pipeline stage

(a) Candidate generation — primary (substrate reliability of any z-score-based threshold). (e) Framework/vocabulary — secondary (SEz metric, age^λ sampling-composition concept).

Error types covered / not covered

This is a pre-flagging substrate-design paper, not an error-detection method, so it doesn't address specific error types (unit conversion, digit transposition, decimal shift, carry-forward, real-event confusion) directly. Its relevance is upstream: it determines how reliable the reference z-score itself is at a given age, which bounds how confidently any downstream flagging rule — of whatever error-type specificity — can treat a z-score as evidence.

ALEX Second Track C paper today, and a bit of a different register — this is Tim Cole, 2021, in Statistical Methods in Medical Research, "Sample size and sample composition for constructing growth reference centiles." 今天第二篇Track C论文，风格有些不同——作者是Tim Cole，2021年发表于《Statistical Methods in Medical Research》，题为《构建生长参考百分位曲线所需的样本量与样本构成》。 Cole is the person who originally proposed the LMS method for growth charts over 30 years ago, so this isn't someone applying a method — it's the inventor stepping back to ask a design question nobody had rigorously answered: how many children do you actually need to measure, and at what ages, to trust the reference curve you build from them? Cole正是三十多年前最初提出LMS法用于生长曲线构建的人，所以这不是某人在应用一种方法——而是方法的发明者本人回过头来，提出了一个此前从未被严谨回答过的设计问题：到底需要测量多少名儿童、在哪些年龄段测量，才能真正信任由此构建出来的参考曲线？

JORDAN Let's set up the growth-chart vocabulary first. 我们先把生长曲线相关的术语讲清楚。 The LMS method (LMS method，Cole提出的一种生长参考曲线拟合方法) fits three smooth curves against age — the median (M), a coefficient of variation (S), and a skewness parameter (L) — and uses them to convert any raw measurement into an age-standardized z-score; it's since been absorbed into a broader family called GAMLSS (GAMLSS, Generalized Additive Models for Location Scale and Shape，广义位置-尺度-形状加性模型), where the specific version equivalent to the original LMS method is called BCCG (BCCG，Box-Cox Cole-Green分布，一种只调整偏度、不调整尾部厚度的GAMLSS分布), short for Box-Cox Cole and Green, with two further extensions — BCT and BCPE — that additionally model kurtosis, or how heavy the distribution's tails are. LMS法（Cole提出的一种生长参考曲线拟合方法）针对年龄拟合出三条平滑曲线——中位数（M）、变异系数（S）和偏度参数（L）——并用它们把任意一个原始测量值转化为按年龄标准化的z分数；该方法后来被纳入一个更大的模型家族，叫做GAMLSS（广义位置-尺度-形状加性模型，Generalized Additive Models for Location Scale and Shape），其中与原始LMS法等价的具体版本叫做BCCG（Box-Cox Cole-Green分布，一种只调整偏度、不调整尾部厚度的GAMLSS分布），此外还有两个进一步的扩展——BCT和BCPE——会额外对峰度（即分布尾部的厚重程度）进行建模。 CDC and WHO each publish their own population reference curves built this same general way, which is exactly why this paper's question — how much data does a defensible reference curve actually need — applies well beyond the one Dutch dataset used here. CDC和WHO各自发布的人群参考曲线也都是用这种大体相同的方式构建的，这正是为什么这篇论文提出的问题——一条可靠的参考曲线到底需要多少数据——其适用范围远不止这里所用的这一个荷兰数据集。

ALEX Here's why this needed a dedicated paper. 这就是为什么这个问题需要专门一篇论文来回答。 Dedicated growth reference studies have varied wildly in size — from 14,500 children in the Fourth Dutch Growth Study up to 55,000 in the Cuban and First Dutch studies, with no convincing, generally accepted sample-size calculation driving any of those numbers. 专门的生长参考研究在样本规模上差异巨大——从第四次荷兰生长研究的14500名儿童，到古巴研究和第一次荷兰研究的55000名，背后都没有一个令人信服、被普遍接受的样本量计算方法来支撑这些数字。 There are really two separate design questions tangled together here: how many measurements total, and at what ages should they be collected — the sample composition — since growth velocity is far higher in infancy than later in childhood, meaning a flat, uniform sampling scheme across age wastes precision where it's least needed and starves it where it's needed most. 这里实际上纠缠着两个相互独立的设计问题：总共需要多少测量数据，以及应该在哪些年龄段采集这些数据——也就是样本构成——因为婴儿期的生长速度远高于儿童期后段，这意味着如果在各年龄段上均匀、平坦地采样，就会在最不需要精度的地方浪费精度，而在最需要精度的地方却供给不足。 Two further complications had made this hard to resolve cleanly before: measurements like weight have a non-normal distribution, so standard formulas for the precision of most centiles simply don't exist, and the whole process of smoothing a centile curve across age — which is what both LMS and GAMLSS do — artificially boosts the effective sample size at any given age by borrowing information from neighboring ages, an effect long suspected to roughly double or triple precision but never actually quantified. 还有两个因素让这个问题此前一直难以被干净地解决：像体重这样的测量值分布并非正态，因此大多数百分位的精度并不存在标准公式；而整个跨年龄平滑百分位曲线的过程——这正是LMS和GAMLSS共同在做的事——会通过向邻近年龄"借用"信息，人为地提升某一特定年龄下的有效样本量，这种效应长期以来被怀疑大约能让精度提升两到三倍，但此前从未被真正量化过，这种现象被称为"借力"（borrowing strength）。

JORDAN So what's the actual simulation setup — how do they pin down the precision at each age? 那实际的模拟设置是怎样的——他们如何确定每个年龄段的精度？

ALEX They start from a real base model — a BCCG GAMLSS fit to height, weight, BMI, and head circumference from 6,878 boys in the Fourth Dutch Growth Study, an open-source dataset — and then simulate repeated study designs from it, each defined by a single sampling function: f(age) equals age raised to the power λ, sampling ages uniformly on that transformed scale. 他们从一个真实的基础模型出发——用荷兰第四次生长研究中6878名男孩的身高、体重、BMI和头围数据拟合出的BCCG GAMLSS模型，这是一个开源数据集——然后基于这个模型模拟一系列重复的研究设计，每一种设计都由单一的采样函数定义：f(age)等于年龄的λ次方，在这个变换后的尺度上对年龄进行均匀采样。 At λ=1 you get equal numbers across the whole age range; as λ falls below 1, younger ages get progressively oversampled, which is exactly the shape real growth studies already use informally. 当λ=1时，整个年龄范围内的采样数量相等；当λ小于1时，低龄段会逐渐被过采样，这恰恰是现实中的生长研究一直以来非正式采用的形状。 The outcome measure they optimize is SEz — the standard error of a given centile, expressed in z-score units rather than raw measurement units — because on the z-score scale, precision turns out to be nearly identical across weight, height, BMI, and head circumference, and identical for any pair of centiles equally spaced above and below the median, which collapses what looks like four separate design problems into one. 他们要优化的结果指标是SEz——某个百分位的标准误，以z分数为单位而不是原始测量单位来表示——因为在z分数尺度上，体重、身高、BMI和头围四种测量值的精度几乎完全一致，而且任意一对在中位数上下对称分布的百分位，其精度也完全相同，这就把看起来是四个独立的设计问题，一下子压缩成了一个问题。 Here's where I'd push back a little: the entire bootstrap-based precision estimation, and the recommendation that follows from it, is built on one base dataset of boys only, and the paper is explicit that it hasn't separately verified any of this for girls — it just argues there's no obvious biological reason the two sexes should behave differently, which is a reasonable assumption but still an assumption, not a tested one. 这里我想提出一点质疑：整套基于bootstrap的精度估计，以及由此得出的建议，都建立在单一的、仅包含男孩的基础数据集之上，而论文也明确说明并未单独对女孩的情况进行验证——它只是主张说，没有明显的生物学理由认为两性在这方面会表现不同，这是一个合理的假设，但终究只是一个假设，而不是一个经过检验的结论。

JORDAN And what's the headline finding — does one λ win for everything? 核心发现是什么——是否存在一个对所有情况都最优的λ？

ALEX No, and that's actually the paper's most useful result. 不存在，而这恰恰是这篇论文最有价值的发现。 Optimal λ depends entirely on which centile you care about: the median wants λ around 0.38, meaning heavy range. 最优的λ值完全取决于你关心的是哪一条百分位：中位数需要λ约为0.38，也就是对婴儿期进行大量过采样，而2nd和98th百分位——大多数生长图表实际印刷的最外侧曲线——则需要λ约为0.76，更接近于在整个年龄范围内均匀采样。 That's because the median depends only on the location curve, which is steep and needs infancy data to pin down, while the outer centiles depend as much on the variability curve, which turns out to be far less sensitive to age transformation. 这是因为中位数只取决于位置曲线，而位置曲线在婴儿期变化剧烈、需要婴儿期数据才能确定，而外侧百分位同样依赖于变异性曲线，而后者对年龄变换的敏感度要低得多。 Since the widest, most consequential confidence bands belong to those outer centiles, Cole's practical recommendation is to design the sampling scheme around the 2nd/98th centile rather than the median — a moderate, not extreme, infant oversampling. 由于那些最宽、最具实际影响的置信区间恰恰属于这些外侧百分位，Cole给出的实用建议是：围绕2nd/98th百分位而不是中位数来设计采样方案——即适度而非极端的婴儿期过采样。 On sample size, the smoothing-driven "borrowing strength" effect was quantified for the first time: at the optimal design, a classic textbook calculation calling for 1,000 eight-year-olds to achieve a given precision on the 97th centile actually only needs 452 subjects once proper curve-smoothing and 25,000 subjects per sex for a well-designed reference study, depending on how tight a precision target you're willing to pay for. 综合来看，样本量与SEz的−1.85次方成比例关系，而不是简单随机抽样下预期的−2次方，论文给出的总体实用建议是：一项设计良好的参考研究，每个性别需要7000到25000名受试者，具体取决于你愿意为多紧的精度目标买单。

大致难度：S到M（小到中等）——SEz的核心公式论文中已经给出，但真正耗费精力的部分是为实际使用的那条参考曲线整理出按年龄分层的样本量文档。

JORDAN What's left open — what would we need to check before leaning on any of this? 还有哪些开放问题——在依赖这些结论之前，我们需要先核实什么？
